# 方案：方波 HFI 位置辨识与 SMO 对接（2026-09-13）

**对象**：STM32G474RET6_MOTOR，N5065（7 极对，凸极率 ≈1.47，`Ld≈59µH` / `Lq≈87µH`）  
**实例 ID**：`hfi_low_speed`（规划）  
**前置基线**：中高速 I/F→SMO V1 已结档 — [结档_SMO中高速无感V1与HFI开干_2026-09-12.md](./结档_SMO中高速无感V1与HFI开干_2026-09-12.md)  
**本文角色**：可执行实施方案（步骤 / 原因 / 目的 / 可验证效果）；**不替代**联调日报与 CSV 签收包。

---

## 0. 一句话目标

> **零速～低速用 10 kHz 脉振方波 HFI 出角/速；中高速继续 SMO；重叠区用现有 `obs_soft_switch` 做 HFI↔SMO 软切。**  
> 外环始终走 `|ω|` + 分级限权，不为 HFI 另写「只认正转」的速度环。

---

## 1. 背景与分工

| 转速区 | 观测源 | 原因 |
|--------|--------|------|
| 零速 / 低速 / 重载启动 | **HFI** | EMF 弱，SMO 不可靠（约 &lt;数百 rpm 真空带） |
| 中高速巡航 | **SMO（已 V1）** | EMF 足够；2154 等已证限权正反巡航 |
| 重叠带（约 400–800 rpm，实测标定） | **软切 BLEND** | 避免硬切摔矩；复用 ENC/I/F→SMO 的 ARM/BLEND/OBS 骨架 |

**产品链（终态）**：`HFI →(软切)→ SMO`  
**调试链（H0～H2）**：Park / 真值可用编码器；HFI/SMO 可旁路对照。  
**I/F**：HFI 成熟前可作备援爬升；成熟后降级为失败兜底，不再与 HFI→SMO 长期双主路径并行。

## 2. 已锁定参数（开干默认）

| 参数 | 取值 | 原因 |
|------|------|------|
| 控制频率 \(f_s\) | 20 kHz | 现网 |
| 方波注入 \(f_h\) | **10 kHz**（\(f_s/2\)，每拍翻极性） | 经典脉振方波标准做法 |
| VOFA | JustFloat **×12**，**D=2 → 10 kHz** | 与注入同量级；看 MCU 解算 + 支持 Python 粗离线 |
| ISR 负载通道 | **首期不做** | 12 ch 优先给物理量；以后再宏切换腾位 |
| 多点姿态 | **Ud 开环 MOVE → SETTLE → HFI_MEAS** | 可重复扫角；手拨仅备份 |
| 转动中连续辨识 | **H0 不做** | 先静置把解调做对 |
| **有感稳速旁路（现行）** | **H1 CRAWL 后改道** | Park=enc + 有感速度环 ~150 rpm；HFI 只估角对照；`MOTION_BYPASS=1` |

### 2.1 VOFA×12 布局

**静置 H0/H0.5**（历史）：ch1=`θ_cmd`，stage 1–5。

**现行有感旁路（`MOTION_BYPASS`）**：

| ch | 名 | 用途 |
|----|-----|------|
| 0 | `theta_enc` | 真值 |
| 1 | `ω_ref` | 速度指令 [rpm]（RUN≈150） |
| 2 | `theta_hfi` | HFI PLL 估角 |
| 3 | `theta_err` | wrap(θ_hfi−θ_enc) |
| 4 | `eps` | 解调误差 |
| 5 | `di_q` | 半周 Δi |
| 6 | `id` | |
| 7 | `iq` | 速度环力矩 |
| 8 | `ud` | PI + 方波 |
| 9 | `uq` | PI + 方波投影 |
| 10 | `vh_sign` | ±1 |
| 11 | `stage` | 0=IDLE **7=RUN** 5=DONE |

**离线**：用 HFI 段的 `id/iq/vh_sign/θ_enc` 粗复算 ε，与 MCU `eps/di_*` 对照；逐半周咬死可临时 D=1。

## 4. 分步方案

### 步骤 A — 工程骨架

| 项 | 内容 |
|----|------|
| **状态** | **已落地（2026-09-13）**：`m1_hfi_standstill` + `hfi_sqwave` IDLE；`bringup_active` 默认切 HFI；Keil 0 Error |
| **做什么** | 新增 `config/profiles/m1_hfi_standstill.profile.h`；`motor/observer/hfi_sqwave.c/.h`；`bringup_active` 互斥切入；VOFA 宏切 ×12 / D=2；关 I/F、关 SMO 进环、关速度环 |
| **实现原因** | 与 `m1_if_100rpm` 隔离，避免污染已结档中高速路径 |
| **实现目的** | 有独立编译/烧录入口，后续步骤只改 HFI 模块与 profile |
| **可验证效果** | Keil **0 Error(s)**；上电 `stage=IDLE`、电流环可转、编码器 θ 进 VOFA ch0；无注入时电机静止 |

统一观测出口（为 H3 预留，H0 可先内部用）：

```c
typedef struct {
    float theta;       /* rad */
    float omega_rpm;   /* mech */
    float conf;        /* 0..1 或等效置信 */
    uint8_t valid;
} obs_out_t;
```

---

### 步骤 B — H0：Ud 挪点 + 10 kHz 方波静置辨识（旁路）

| 项 | 内容 |
|----|------|
| **状态** | **已落地（2026-09-13）**：自动 `MOVE→SETTLE→MEAS→LOG`×7 点（0°..180°）；`INJ_MODE=1` 固定 θ_inj；MEAS 纯电压方波 |
| **做什么** | 状态机 `MOVE → SETTLE → HFI_MEAS → LOG → 下一 θ_cmd`。MOVE：Park 用 `θ_cmd`，直流 `Ud=U_move`、`Uq=0`。SETTLE：`Ud→0`。MEAS：Park=θ_enc，±Vh @10 kHz，半周 `di_q`→`eps` |
| **实现原因** | 「动」与「辨」分离；固定注入轴才能扫出 2θ |
| **实现目的** | 证明凸极可观测；MCU↔Python 对照基线 |
| **可验证效果** | ① stage 按 1→2→3→4 循环后到 5=DONE；② MEAS 段 `vh_sign` 翻转、`eps` 非零；③ 各点 `eps` vs `θ_enc` 呈双周期/电周期趋势 |

**实验子模式（profile 宏切换）**

| 模式 | 注入轴 | 用途 |
|------|--------|------|
| A | 跟 `θ_enc`（`M1_HFI_INJ_MODE=0`） | 可观测性：对齐轴上 Δi 合理 |
| B（**主验收，默认**） | 固定 `θ_inj=0`（`INJ_MODE=1`） | 扫姿态看 2θ |

**明确不做**：边大直流 Ud 边 HFI；转动中连续位置闭环。

---

### 步骤 C — H0.5：PLL / 积分出连续角 + 极性

| 项 | 内容 |
|----|------|
| **状态** | **已落地（2026-09-13）**：`INJ_MODE=2` 注入跟 θ̂；MEAS 0.8 s；`eps→PI PLL`；`POLARITY_ENC` 消 π |
| **做什么** | MEAS 初值 `θ̂=enc+0.4`；半周 eps 驱动 PLL；\|err\|>π/2 持续 20 ms 则 θ̂+=π |
| **实现原因** | 凸极 eps∝sin(2δ)，需闭环出连续角；π 模糊用有感辅助先消（产品后再换脉冲法） |
| **实现目的** | 旁路 θ_hfi 可跟 enc，为 H1 进 Park 铺路 |
| **可验证效果** | 各点 MEAS 末段 \|θ_err\| 收敛（建议 &lt;0.2 rad）；VOFA ch2 拉向 ch0；不随机跳 π |

---

### 步骤 D — H1：θ_hfi 进 Park（弱力矩）

| 项 | 内容 |
|----|------|
| **状态** | **已落地（2026-09-13）**：`PARK_ENABLE`；MEAS 锁相后 `CRAWL` 6 s，`Iq_ref=0.8 A`；PI+ d 轴方波 |
| **做什么** | MEAS/CRAWL：Park=`θ̂`；CRAWL 给弱 Iq；enc 仅对照 |
| **实现原因** | 旁路角再准，不进环无法证明可驱动 |
| **实现目的** | 零速/蠕动无感可控 |
| **可验证效果** | stage=6 时 enc 缓慢单向变化；\|θ_err\| 有界；Iq 跟得住、不失控 |

---

### 步骤 E — H2：低速 `|ω|` 速度环（纯 HFI）

| 项 | 内容 |
|----|------|
| **做什么** | `ω_fb` 取 HFI PLL（或 θ 差分+LPF）；复用外环 `|ω_ref|/|ω_fb|` PI 与 regen/drive 限权；目标数百 rpm 内正反（DIR 只乘转速目标） |
| **实现原因** | 与 SMO V1 外环语义一致，H3 软切时无需改速度环哲学；低速重载本就不归 SMO |
| **实现目的** | 产品低速段可独立运行 |
| **可验证效果** | `|ω_ref|` 阶跃/巡航（如 100–400 rpm）：稳态误差与超调可接受；正→反不靠拧负 Iq 启动（保持 V1 教训）；编码器对照可选关闭 |

---

### 步骤 F — H3：与 SMO 对接（软切泛化）

| 项 | 内容 |
|----|------|
| **做什么** | 扩展 `obs_soft_switch`：底角/底速由 ENC/I/F 改为 **HFI**；高速 `theta_hat/ω` 仍为 **SMO**；门限改按 `|ω|` + SMO `emag/conf` + HFI `conf`；加速 HFI→BLEND→SMO，掉速 SMO→HFI（FALLBACK 语义改为回 HFI，调试宏可回 ENC） |
| **实现原因** | 现网已有 ARM/BLEND/OBS/回退；重写切换易丢 2154 经验。HFI 与 SMO 物理有效区互补，必须重叠软切 |
| **实现目的** | 一条无感链覆盖零速到中高速 |
| **可验证效果** | ① 重叠带双角 `|wrap(θ_hfi−θ_smo)|` 有界且相对 enc 可解释；② 一次加速穿过软切：`ss_state` 经 ARM/BLEND→OBS，Iq/ω 无崩溃；③ 减速回落回 HFI 不失步；④ **无编码器进环** 完成正反低速 HFI + 中高速 SMO（enc 仅录波）；⑤ 与 V1 限权巡航不回归 |

**建议门限起点（须实测重标）**

| 门限 | 起点草案 | 备注 |
|------|----------|------|
| `RPM_ENTER`（进 SMO） | ~600–900 | 现网 IF→SMO 偏高；HFI 重叠可略降 |
| `RPM_EXIT`（回 HFI） | 低于 ENTER 150–200 | 滞回防抖 |
| `BLEND_S` | ~0.1–0.2 s | 对齐现网量级 |
| SMO `emag` 最小 | 沿用/略调 | 假 ω̂ 问题在零速仍在，回 HFI 靠 \|ω\|+emag |

## 6. 联调操作提纲（H0）

1. 切 profile，烧录；VOFA 6 Mbps，JustFloat×12，采样率 **10000**。  
2. 确认 ch0 `θ_enc` 手转正常。  
3. 跑自动序列：多点 `θ_cmd`（如 0°–180° 电角度每隔 30°）。  
4. 只截 `stage==HFI_MEAS` 画 `eps`–`θ_enc`。  
5. Python：同段复算 ε，与 ch4 对比。  
6. 通过 → 进 H0.5；失败 → 先调 `V_h` / 死区 ON·OFF 对照 / 采样对齐，不进 Park。

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| 10 kHz 半周仅 1 拍，Δi 小/死区敏感 | 提 `V_h`；对照死区 OFF；必要时刻 D=1 查对齐 |
| Ud MOVE 拉过头发热 | 限 `U_move`、限 MOVE 时间；SETTLE 必卸直流 |
| π 模糊进环拧矩 | H0.5 极性未过禁止 H1 |
| 软切重叠不足 | H2/SMO 两边先拉重叠再 BLEND；门限用 \|ω\| |
| 与 IF 路径互相踩踏 | profile 互斥；结档 IF 包不默认开 HFI |
