## 2. 对象与失败机理（为何不能一步放开）

- 空轴 **轻惯量、粘滞 B≈0**。速度环近似 `1/(Js)`，负向权威一放大就容易极限环。  
- 浅刹 `iq_min=−0.25` 是拐杖：掐掉「重刹半周」，能活但不等于环调好。  
- **无感反馈有滞后**（SMO/滤波）；有感编码器反馈快，故有感能开更满权威、无感要更慢放。  
- 1652 教训：在 **1300 hold 中途** 把 `iq_min` 放到 −0.9 → late std≈180、贴地板抽振。  
- 工业习惯：**HP 阻尼 → 门控 → iq_min 分级斜坡 → 最后爬 PI**；时间只作最短等待。

## 6. 半成功边界（诚实清单）

**算过的**

1. 纯无感（可无编）交接并稳住约 1000 rpm。  
2. 限权下同向大阶跃 900–1300。  
3. 空轴轻扰动 / 手拖（加负载）不轻易崩。  
4. 权威必须分级；中途放开会晃（已用延期修复）。  
5. 正→滑行→反 ±1000（2154）；反转腿 `|ω|` PI、+Iq。

**不算过的**

1. `iq_min=−0.9` 的 **地板命中** 与空轴稳定性（探针需加大减速，如 1300→900）。  
2. −1.2 及满 ±Iq。  
3. 正常 PI 增益与 `open_seq=248`。  
4. 滑行段 ω̂ 假挂根治（2154 已用 emag/超时兜底）。  
5. 交接抖的专项收口。
