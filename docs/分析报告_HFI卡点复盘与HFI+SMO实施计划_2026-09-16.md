## 0. 结论摘要（先给答案）

1. **公式没错。** 9/13 以来的解调链（`x=prev_sign·Δid`、`y=prev_sign·Δiq`、`ε=½atan2(y_lp, x_lp−A_cmd)`、`x=A+B·cos2δ`、`y=C·sin2δ`）在**每一个** δ 网格包上都与理论自洽：实测 `|B|/A = 0.167…0.194`（理论 `Δ/Σ = 0.1918`），`|x|max/|x|min = 1.454…1.482`（理论 `Lq/Ld = 87/59 = 1.4745`），`|C|/|B| = 0.921…0.924`，`φy−φx ≡ 45°±1°`，拟合残差 rms < 1%·A。**不是"公式有问题"，是"尺子坏了"。**

2. **真正的卡点：θ_enc（HFI 的唯一参考系）会静默冻结。** 9/16 的 15 个包里 **8 个** 的 `θ_enc` 在整段录波内**逐位不变**（uniq=1~2，最长 164.6 s），而同一天另有 7 个包 `θ_enc` 活性 ~8.3 kHz。HFI 的注入轴是 `θ̂ = θ_enc + δ`（已用 390 k 样本验证 `θ̂−θ_enc ≡ δ`，误差 ≤1e-4°），所以**尺子一死，μ 上一切角度量（φ、ε、θ_err、Δθ_enc、极性、A/B 标定）全部失去意义**，而录波看上去完全正常。

3. **本报告最有价值的单条证据**：`161217` 同一次上电、同一个夹持、连续 3 轮 13 点网格，`θ_enc` 三个字面值**完全相同**（78.46319°，全段 uniq=1），而拟合峰值轴 φ = **+73.5° / −55.8° / +27.8°**。前后两轮之间是**故意用开环 Ud（2 V×1.5 s）把转子摆到 θ_cmd = 0°/60°/120°** 的 MOVE 段。该包在自身口径内就是**自相矛盾**的，无法用于任何结论。

4. **为什么一直没被发现**：冻结是**静默**的——它不报错、不置 lock、不改变任何已有 12 通道的形态；而 9/15 铁律里的"窗卫生"判据（`ω_enc` 中位 <20 rpm、`θ_enc` std 小）**恰好把死编码器判为最干净的窗**。判据与故障模式反相关，所以死包的 φ 被当成"真物理"。

5. **距离完整 HFI 还差 8 项**（§5）：可信参考系门禁、φ 跨上电复现、极性(π)判定、ε 零点/增益过线、θ̂ 进 Park、低速 `|ω|` 环、HFI↔SMO 软切（重叠带 800–900 rpm）、带载 Δ(|Iq|) 策略。**其中第 1、2 项没通之前，后面 6 项的任何数据都不必采。**

6. **SMO 成功的可复制经验**（§6）：G0–G6 关卡制、一包只改一个量、先旁路证明角质量再进环、数据驱动门限（`emag` 地板 / `|err|p95`）、`|ω|` 语义与限权约定、`obs_soft_switch` 复用。HFI 9/14 之后**丢掉的正是"关卡制"**：一天里同时改 sweep + ident + PLL + 极性 + 增益。

### 2.2 五个定量自洽点

1. **比值 1**：`|B|/A = 0.167…0.194`，理论 0.1918（±15% 内，差额可归因于半个死区窗/采样损耗/电流环在 10 kHz 带的衰减）。

### 3.2 "DEAD" 怎么判？——用"活编码器在静止轴上的 LSB 抖动"做对照

关键反例：`161433` 全段机械位置只变了 **2.92° 电角**（≈0.42° 机械），但 `θ_enc` 更新 **219 360 次**；`161253` 全段只变 19.2° 电角，更新 **509 417 次**。也就是说：

> **AS5047P 在静止轴上的输出逐拍仍在 ±1…±5 LSB 抖动（1 LSB = 0.022° 机械 = 0.157° 电角），所以"轴不动"绝不能解释"字面值 60–165 s 一位不变"。**

`161253` 的实际序列（每 0.157° 一档）：`289.796 / 289.950 / 290.104 / 290.257 / 290.411 / 290.565 / 290.719 / 290.873 / 291.027 / 291.180 / 291.334` —— 典型的"静止 + 抖动"。反观 `161243`：全程 **294.41052**（1e-5 度都不动）。

### 3.3 为什么尺子一死，HFI 就必然崩（公式层面）

固件链路（已逐行核对）：

```
motor_current.c: theta_enc_park = as5047_raw_to_theta_el(raw)   // 用上一次成功的 SPI 读
                 dbg.enc_theta_el = theta_enc_park
                 hfi_sqwave_on_angle(theta_enc_park, dt)
hfi_sqwave.c:    MEAS 段 s_theta_hat = wrap(θ_enc + δ)          // :3744 / :2202
                 park_theta() = s_theta_hat + s_park_off        // :4182
                 注入电压沿 θ̂ 施加（s_park_off 只转电流环帧，不转注入轴）
解调：           x,y = 在 θ̂ 帧里的半周 Δid/Δiq
```

因此 `x(δ)` 的峰值恒在 **φ = wrap(θ_d_axis − θ_enc)**，即"**编码器零偏 ↔ 转子 d 轴**"的固定夹角。它是**位置无关的常数**（这才是"尺子"的含义）。而：

- `ε = ½atan2(y_lp, x_lp − A_cmd)` 的**零点**就在 φ 上（与 A_cmd 取值无关，A_cmd 只影响增益/线性度）⇒ φ 不可复现 ⇒ ε 的"零"在漂 ⇒ PLL 追着一个每包换一次的目标；
- `θ̂ − θ_enc = δ` 只是**固件内部的算术恒等**（本次已验证误差 1e-4°），它**不能**证明 θ_enc 是真的 —— 这解释了为什么"θ_err 看着很规矩"却没有意义；
- `hfi_dq_decide()`（极性/轴向判定）的**唯一输入是 `Δθ_enc`**（Id/Iq 脉冲前后编码器的中位差）⇒ 尺子死时判定必然是噪声，而代码在"判不出"时**仍然起速**（`s_park_off = 0`，`_freeze_dq_ident` 自述"undecidable Δ → Δ=0 still speeds"）⇒ 一个**随机的 0/±90°/180°** 被塞进后续电流环坐标。这是"只翻 x 没用""±90° 假锁"的机制来源。

### 3.4 为什么会一直没发现（三条"静默"叠加）

1. **不报错**：`as5047_chip_kick()` 在 `phase != IDLE` 时只 `ENC_EVT_KICK_SKIP_BUSY` 计数后 `return`（`as5047_async.c:94-97`），**不发错误事件**；链推进完全依赖 DMA1_Ch2 的 TC 中断（`as5047_chip_on_rx_complete` 两次推进 FRAME1→FRAME2→IDLE），**没有任何超时/看门狗/重试**。一次漏事件 = 永久冻结到断电。
2. **遥测无位**：12 个 VOFA 通道全被物理量占满（`θ_enc/δ/θ̂/θ_err/ε/ω_enc/x_lp/y_lp/x_raw/y_raw/stage/Id`），**没有"参考系活性"位**；离线脚本看到的只是一条"很干净的直线"。诊断量（`g_telem_dbg.enc_dma_phase / enc_cplt_cnt / enc_kick_skip_busy / enc_err_cnt`）是有的（`debug/app_uart_dma_debug.c:135-176`），但只有 Keil Watch 能看。
3. **判据反向**：9/15 铁律第 5 条要求"窗卫生：`ω_enc` 中位 <20 rpm + `θ_enc` std"，而死编码器恰好 `std=0、ω=0` ⇒ **死包得分最高**。

MOVE 段是**开环 Ud = 2.0 V 持续 1.5 s**，专门用于"把转子摆到 θ_cmd"（`M1_HFI_A0_MOVE_UD_V`，`hfi_sqwave.c:4252`）。两种可能都指向同一结论：

- 若 MOVE 真的摆动了转子 ⇒ 转子动了而 `θ_enc` 一位不变 ⇒ **尺子死**；
- 若 MOVE 没摆动转子（转子静止）⇒ 在 `θ̂ = θ_enc+δ`（已证）且 `θ_enc` 常数的前提下，φ **必须**是常数、不可能漂 130° ⇒ **固件内部口径自相矛盾**，该包无解释能力。

无论哪一种，**该包作废**；再叠加"θ_enc 逐位冻结 164.6 s"与 §3.2 的抖动对照，结论唯一指向尺子死。

**（b）161243 / 161253：尺子复现实验的两枪，一死一活**

`_freeze_A0_20260916.txt`（12:33）的要求是：**"Hold the clamp. Do not move the shaft. 上电录到 stage 5，断电，再重复一次；比较两包 δ=−90 的峰值与 ε。"**

| 枪 | 时刻 | `θ_enc` 状态 | 冻结/实测位置 | φ |
|---|---|---|---|---|
| 第 1 枪 161243 | 12:43 | **DEAD**（uniq=1） | 294.4105° | **−30.13°** |
| 第 2 枪 161253 | 12:53 | **LIVE**（7.6 kHz 抖动） | 289.80…291.33°（中位 290.72°） | **−10.23°** |

按"未动轴"前提，两者应给同一 φ；实测相差 **19.9° 电角（≈2.8° 机械）**，远超编码器 LSB 抖动量级。这既说明**该次"尺子复现"未成立**，也说明**冻结值 294.4105° 并不等于当时转子的真实位置**（很可能是上电时阻塞读/半帧数据，或过早冻结的陈旧值）——这正是最危险的一种失效：**值看起来完全合法**。

**结论**：9/16 唯一可信的 φ 是 `161253` 的 **−10.23°**（且我们要承认它只被采到 1 次）。**"φ 跨上电可复现"这件事，到今天为止从未被有效验证过。**

## 4. 多角度反证：我如何排除其他解释

| # | 备选解释 | 判据 | 结论 |
|---|---|---|---|
| A1 | 解调公式/2δ 模型错 | `|B|/A`、`|x|max/min`、`φy−φx≡45°`、|C|/|B|、rms 五项同时与理论吻合（§2.1） | **排除** |

| A7 | 20 kHz ISR 过载把编码器链"饿死" | 7/13 确有"decim=2 时 ISR 过重诱发"的前例；但 9/16 的死包**从 t=0 第一帧就死**（捕获起点即 uniq=1），更像上电竞态；无法从 CSV 判别 | **待测**（§7-R0 加 `isr_delta` 观测量；不排除两者叠加） |
| A8 | 编码器硬件/接线坏 | 同日 8 活 7 死交替出现，同一硬件能跑 8.3 kHz | **次优**（按软件链卡死处理；若 R0 反复失败再查硬件） |

**权衡后的定论**：**"参考系（θ_enc）静默冻结"是 9/14 之后绝大多数异常的唯一自洽解释**；它同时解释了"为什么调参没用"——因为每次标定对象都在换。

## 6. 从 SMO 成功经验提炼的方法论 → 映射到 HFI

来源：`docs/验证方案_IF爬升步步为营_2026-09-11.md`（G0–G6 关卡表）、`docs/总结_OBS_SMO中高速软切签收_2026-09-11.md`、`docs/结档_SMO中高速无感V1与HFI开干_2026-09-12.md`。

| SMO 的做法（成功因素） | 为什么有效 | HFI 里的对应动作 |
|---|---|---|
| **G0 安全 → G1 ALIGN 可重复 → G2 100 rpm → … → G6 才接软切** | 每关只引入一个新自由度，失败可归因 | **R0 参考系门禁 → R1 φ 复现 → R2/R3 解调 → R4 锁相 → R5 极性 → R6 出力 → R7 低速环 → R8 软切** |
| **一包只改一个量**（G2 失败只允许"Iq 0.5→0.8 或 ALIGN 0.2→0.4 s"） | 排除混淆变量 | 9/14–9/16 的失败正是反面：一天里同时动 sweep + DQ_IDENT + atan2 + 极性 + 增益 |
| **先旁路证明角质量，再进环**（@800 ~11°、@1000 ~8° p95 旁路，闭环 @800 变 ~30° ⇒ 量到"闭环放大"） | 把"观测器问题"与"闭环耦合问题"分开 | HFI 对应：`|ε|`、`θ̂−θ_enc` 必须先**静置旁路**过线，才允许进 Park |
| **atan→PLL 是转折点**（@1000 p95 23°→15°） | 用线性鉴相替代非线性 atan | HFI 已等价做到（`ε=½atan2(y, x−A)` + PLL），但需在**活参考系**下重签一次 |
| **数据驱动门限**：`emag` 地板 1.82@1000 / 0.94@800 / 0.55 停；OBS 可用区 ≥900，800 勉强，≤750 失效 | 门限来自实测而非模型 | HFI 侧：`|ε|` 门限、`A±B` 走满判据、`C/B` 增益、φ 复现 ±5°，全部来自拟合 |
| **约定统一**：阈值一律用 `\|ω\|`；DIR 只乘转速目标；Iq 恒为 +\|Iq\|；限权 `[−regen,+drive]`；失锁回退语义 | 避免"正反两套逻辑"的补丁森林 | HFI 的 H2/H3 直接沿用，不再新写速度环 |
| **软切复用 `obs_soft_switch`**（ENC/ARM/BLEND/OBS/FALLBACK） | 不重写已验证状态机 | H3 只把**底源**换成 HFI，`FALLBACK` 语义改为回 HFI |
| **重叠带要实测**（HFI 必须在 ≥800–900 rpm 仍可用） | 两条曲线必须真重叠才能软切 | 这是 HFI 中高速上限的**硬指标**：R8 之前必须测出 HFI 有 conf 的最高 `\|ω\|` |

**"为什么失败"的一句话总结**：SMO 是**先建可复现的可观测性，再一步步加自由度**；HFI 在 9/14 之后变成了**先加自由度（sweep/ident/atan2/极性一起上），可观测性（尺子）从未被门禁检查**。所以 SMO 有 6 个签收关卡，HFI 只有一个"看波形"。

## 7. 实施与验收计划：R0 → R9

> 通用规则：**每关不过不进下一关**；**一包只改一个量**；**每包必须能离线复算**；每包记录 git HEAD + 相关文件 SHA256 + VOFA 通道口径。
> 通用作废条款（任一命中 → 本包作废、原样重跑，**不许在同一包内加补丁**）：
> (V1) `θ_enc` 活性 <1 kHz 或包内最长冻结 >0.2 s；(V2) 网格段内 `θ_enc` 漂移 >0.5° el；(V3) 2δ 拟合 rms/A >2%；(V4) 出现 `|B|>|A|` 或 x 在网格内变号；(V5) stage 序列与 freeze 记录不符。

### R0 —— 参考系门禁（不是实验包，是**每个包的入场券**）

| 项 | 内容 |
|---|---|
| 做什么 | ① 上电、停在 `stage=IDLE`，**手转轴 ±30° 机械**再回原位；② Keil Watch 看 `g_telem_dbg`：`enc_dma_phase`（应 0/1/2 翻转）、`enc_cplt_cnt`（≈20 kHz 增长）、`enc_kick_skip_busy`（**停增**）、`enc_err_cnt`（=0）、`isr_delta`；③ 录完用 §8 脚本判活性 |
| **PASS** | 手转后 `θ_enc` 变化 ≈7×机械角（±10%）且回位一致 ≤1° el；`enc_cplt_cnt/tick ≈1`；`enc_kick_skip_busy` 不增；离线活性 ≥1 kHz、最长冻结 ≤0.2 s |
| **FAIL** | 断电重上；**连续 3 次 FAIL → 转查硬件/接线**（并考虑给编码器链加超时重试，见 §9） |
| **代表什么** | **HFI 的"尺子"活着。** 没有这一步，后面所有角度量都是自证自话（9/13 方案 §6.2 本就要求，9/14 起被跳过） |

### R1 —— φ 跨上电复现（"尺子刻度"，锁轴）

| 项 | 内容 |
|---|---|
| 固件 | `DELTA_SWEEP=1`、`DQ_IDENT=0`（**先不引入 ident**）、`ATAN2=0`、无 RUN、无 Ud MOVE；网格 `−90…+90 / 15° / HOLD 3 s`；`PARK_ENABLE=1`；`A_CMD=0.238` 不动 |
| 台架 | **锁轴/夹持**，两枪之间**不许动轴**（同 9/16 A0 口径），每枪单独上电 |
| 做什么 | 每枪录 MEAS 13 档 → DONE；两枪都先过 R0 |
| **PASS** | 两枪 `θ_enc` 均 LIVE；各枪网格内 `θ_enc` 漂 ≤0.5° el；两枪**位置差 ≤2° el**；`\|φ_1−φ_2\| ≤ 5° el`；A 差 ≤3%；`\|B\|` 差 ≤10% |
| **FAIL** | 任一枪 DEAD → 作废重跑；两枪都 LIVE 但 φ 不复现 → **停**，查参考系（编码器零偏/极对数/`M1_ENCODER_OFFSET_RAD` 是否被别的路径改），**禁止**去调 Kp/Ki 或翻号 |
| **产出** | 冻结 `φ*`、`A_fit`、`B_fit`、`C_fit`（写入 profile 注释与下一关的天条） |
| **代表什么** | φ 是"**编码器零点 ↔ 转子 d 轴**"的物理常数；它复现 ⇒ 参考系刻度可跨上电复现 ⇒ **后面的 PLL/极性/出力才有唯一解**。这是整个 HFI 的地基 |

### R2 —— 解调门禁（离线，零硬件）

| 项 | 内容 |
|---|---|
| 做什么 | 对 R1 的两包做相位感知拟合 + 决策表：`x = A + B1cos2δ + B2sin2δ`，`y = C1cos2δ + C2sin2δ` |
| **PASS（六条全中）** | ① `\|A\|>\|B\|`；② `\|B\|/A = 0.192 ± 30%`；③ `\|x\|max/\|x\|min = 1.47 ± 30%`；④ `\|C\|/\|B\| = 1.0 ± 0.15`；⑤ `rms/A < 2%`；⑥ `\|φy − φx\| ≡ 45° ± 5°`（mod 90°） |
| **FAIL** | 不过线 → **回 R1/查 θ_enc 与 `di_d` 污染**；**不许**加 EPS_SIGN/AXIS_SEL/死区补丁 |
| **代表什么** | 证明 x/y 是**纯凸极 2δ 响应**（而非电流环 DC 污染或坏测量）。`A>|B|` 是电感定理，`|B|>>|A|` 是坏测量 |

### R3 —— ε 零点与增益（离线 + 一个宏）

| 项 | 内容 |
|---|---|
| 做什么 | 令 `A_cmd = A_fit`（现网 0.238 已合格，仅为口径统一）；用 `Kp/Ki = f(ωn, ζ, C/B)` 反算，**禁止**用 `C/(A+B)` |
| **PASS** | `ε(δ)` 过零落在 `φ* ± 5°`；`max\|ε\| ≈ 90°`（无饱和塌陷）；`dε/dδ` 与 `C/B` 一致（±20%）；由 `C/B=0.92` 得 `ωn=√(Ki·0.92)=18.9 rad/s、ζ=1.04`（或按目标带宽重算并记录） |
| **代表什么** | ε 是"真角误差"的**线性化**且零点是凸极轴 ⇒ 可以进 PLL；同时确定 PLL 增益的**物理**依据（斜率），而不是试凑 |

### R4 —— 静置 PLL 锁相（锁轴，闭环但不进 Park）

| 项 | 内容 |
|---|---|
| 固件 | 同上 + `PLL_ENABLE=1`；初值策略：`θ̂₀ = θ_enc + δ_last`（seed 用末档 δ，**不用 INIT_OFF 硬贴**）；`INT_MAX=200 rad/s` |
| 做什么 | 录 RUN 15 s；看 ε、`x_lp`、`θ̂−θ_enc` 时间序列 |
| **PASS** | `\|ε\| ≤ 15°` 连续 ≥0.5 s 且保持 ~10 s 无漂移；`x_lp` 走满 `A±B`（最小值接近 `A−B`）；`wrap(θ̂−θ_enc)` 收敛到 `φ* ± 5°` 且 std ≤3° |
| **FAIL** | 典型失败：`x_lp` 停在 `A−B`（±90° 假锁）⇒ **回 R2/R3**；`θ̂` 停在 `φ*±90°` ⇒ 查 seed/`park_off`，**不许**改 `INIT_OFF` 硬贴 |
| **代表什么** | θ̂ 跟踪的是**凸极轴**且已被线性化 ⇒ 可以拿它当 Park 角（H0.5 签收） |

### R5 —— 极性（π 模糊）判定（**自由轴** + 活编码器）

| 项 | 内容 |
|---|---|
| 固件 | `DQ_IDENT=1`；双轴脉冲：轴0 沿 θ̂（Id=+1.6 A / 40 ms）、轴1 沿 θ̂+90°（Iq=+1.6 A / 40 ms）；脉冲前 1.6 ms 与末 1.6 ms 取 `θ_enc` 中位差 `Δθ_enc` |
| **前置门禁（必须新增）** | Δθ_enc 判定前**必须**确认：参考系活性 OK（R0）、静摩擦背景下 `\|Δθ_enc\|` 可分辨（>2×LSB 抖动）；**判不出 → 禁止起速**（现行"判不出也起速、Δ=0"必须改） |
| **PASS** | 单轴 `\|Δθ_enc\| ≥5° el` 且另一轴 `≤2° el`；决策表给出**唯一** `park_off ∈ {0, ±90°, 180°}`；**反向再测一遍结论一致**；两枪一致 |
| **FAIL** | 两轴都动/都不动 ⇒ 停（提高脉冲、改善夹持），**不许**"Δ=0 也起速" |
| **代表什么** | 解决 N/S 磁极极性（π 模糊）与轴归属 ⇒ 允许 HFI 角**出力**（否则 50% 概率反向拧矩） |

### R6 —— 弱 Iq 破粘 + θ̂ 进 Park（H1）

| 项 | 内容 |
|---|---|

## 8. 关键实验的设计模板（"可以验收通过"的那种）

每一包都按下面 6 段写 freeze 记录，缺一段不准开跑：

```text
[包名/时刻]  R__ 关卡名
1) 唯一变量   ：本包相对上一包只改 ____（其余宏列出显式值）
2) 参考系门禁 ：R0 结果（手转 OK/计数 OK/活性 Hz）——FAIL 则本包不成立
3) 台架       ：锁轴 or 自由轴；夹持方式；两枪之间是否动轴
4) 观测口径   ：VOFA 12ch 逐通道含义 + stage 编码 + 采样率
5) 判据       ：PASS/FAIL 的**数值门限**（照 §7 抄）
6) 作废条款   ：§7 通用 V1–V5 + 本关特有条款
```

**离线复算脚本必须做到**（这是"能验收"的核心）：

1. **先判活性**：`uniq(θ_enc)`、更新率、包内最长冻结时长 ⇒ 未过则直接 `VOID`，不再算后面的量；
2. 再按 δ 分档取**驻留末 1.5 s 中位数**（跳过前 1.5 s 建立时间）；
3. 拟合 `x = A + B1cos2δ + B2sin2δ`、`y = C1cos2δ + C2sin2δ`，输出 `A/|B|/φ/|C|/rms`；
4. 输出 §2.2 的五个比值与六个门禁判据，**机器判 PASS/FAIL**，人只看结论；
5. 把 `git HEAD`、`hfi_sqwave.c` SHA256、profile SHA256 一起写进 JSON。

**这一步代表的含义**：把"复现性"从**人的记忆**搬进**脚本**。9/14–9/16 的失败不是缺努力，是缺"机器判生死"。
