# 验证方案 — I/F 爬升步步为营（2026-09-11）

**文档编号**：TECH-IF-VERIFY-STEP-20260911  
**目标**：用最小风险验证「电流闭环 + 强制电角度斜坡」能拖动转子；**不要求一次到 1000 rpm**，更不要求首轮就软切 OBS。  
**电机**：N5065，`pp=7`。终点远期对齐软切 `M1_OBS_SS_RPM_ENTER=900`。  
**基线**：中高速 OBS 已有条件签收（[签收总结](总结_OBS_SMO中高速软切签收_2026-09-11.md)）；本方案只补**启动段**。

---

## 0. 先对齐概念（避免走错路径）

| 名称 | θ 来源 | 电流 | 本仓库现状 |
|------|--------|------|------------|
| **真 I/F** | `θ += ω_e·Ts` 斜坡 | `Iq_ref` 恒定，**电流环闭环** | **尚未实现**（`startup-strategy.md` 描述的是这个） |
| 现有 `motor_startup` | 同上斜坡 | **固定 Uq**，电流环旁路 | 有骨架；`M1_STARTUP_*` 宏未在 `motor_params_m1.h` 配齐，默认关 |

**本方案只验真 I/F。** 不要用「拧大 Uq」冒充通过——那测的是电压开环，和后面接 EMF 软切的交接形态不一致。

换算（必背）：

\[
f_e=\frac{n\cdot p}{60},\quad
\omega_e=2\pi f_e
\]

| 机械 rpm | \(f_e\) | \(\omega_e\) |
|----------|---------|--------------|
| 100 | 11.7 Hz | ≈73.3 rad/s |
| 300 | 35 Hz | ≈220 |
| 600 | 70 Hz | ≈440 |
| **900** | **105 Hz** | ≈660 |
| 1000 | 117 Hz | ≈733 |

---

## 1. 总原则

1. **一关只改一个量**：要么终点转速，要么斜坡时间，要么 Iq；不要同包三改。  
2. **关卡未过 → 禁止进下一关**；允许同一关内加长斜坡 / +0.2 A Iq。  
3. **编码器全程只监督**（转速、丢步、角差）；Park 在 I/F 段用 `θ_if`。  
4. **OBS / 速度环软切一律关掉**，直到 G5 通过后再开 G6。  
5. 轻载、轴可自由转；手摸轴仅作紧急停，不作「通过标准」。

---

## 2. 建议最小实现（验证用，可后补产品态）

验证固件只需：

```text
IDLE → ALIGN → IF_RAMP → IF_HOLD → (STOP / 以后再接软切)
```

| 宏（建议名） | G2 初值 | 含义 |
|--------------|---------|------|
| `M1_IF_ENABLE` | 1 | 开验证模式 |
| `M1_IF_ALIGN_S` | 0.2 | 对齐时长 |
| `M1_IF_IQ_A` | 0.5 | 拖动电流 |
| `M1_IF_ID_A` | 0.0 | 一般保持 0 |
| `M1_IF_TARGET_RPM` | **按关卡改** | 斜坡终点机械转速 |
| `M1_IF_RAMP_S` | 见各关 | 0→目标 线性时间 |
| `M1_IF_HOLD_S` | 2.0 | 到顶后保持 |
| `M1_IF_OBS_SS_ENABLE` | **0** | G6 前必须为 0 |

每拍：

```c
omega_e = (target_rpm * pp * 2π / 60) * saturate(t / ramp_s, 0, 1);  /* RAMP */
/* HOLD: omega_e = omega_tgt */
theta_if += omega_e * Ts;
iq_ref = M1_IF_IQ_A;  id_ref = M1_IF_ID_A;
Park(theta_if);  /* 电流 PI 照常 */
```

VOFA 建议（可挤进现有 ×12，或临时改 ch）：

| ch | 量 | 用途 |
|----|----|------|
| 0 | `ω_enc`（rpm） | 是否跟上 |
| 1 | `ω_cmd`（rpm） | 指令斜坡 |
| 2 | `Iq` / `Iq_ref` | 电流是否咬住 |
| 3 | `θ_if − θ_enc` wrap | 同步误差（丢步看这个） |
| 5 | `startup_state` 或 if_state | 0ALIGN/1RAMP/2HOLD |
| 6 | emag（若 SMO 仍在跑旁路） | 后期 G5/G6 用 |

**丢步判据（建议）**：RAMP 过半后，连续 300 ms `|ω_enc − ω_cmd| > 0.4·ω_cmd`（低速用绝对阈值，如 `|Δn|>40 rpm`）→ FAULT，Iq=0，记包。

## 3. 关卡表（步步为营）

### G0 — 安全与遥测（不上大斜坡）

| 项 | 要求 |
|----|------|
| 配置 | `IF` 开；`OBS_SS` 关；速度环可关或 Iq 仅由 IF 给 |
| 动作 | 上电 → 只 ALIGN 200 ms → **强制 STOP**（不要自动进 RAMP） |
| 通过 | Iq≈设定；θ 固定；电机轻微吸住可接受；无过流 |

**未过**：先修电流环 / 使能 / 极性，不要谈拖动。

---

### G1 — ALIGN 可重复

| 项 | 要求 |
|----|------|
| `TARGET` | 无斜坡 |
| 动作 | ALIGN 0.2 s × 3 次（中间断电或 arm 复位） |
| 通过 | 每次转子被拉到附近稳定；编码器电角变化后趋于平稳 |
| 失败调 | Iq 0.5→0.8 A；ALIGN 0.2→0.4 s |

---

### G2 — 拖到 **100 rpm**（第一道真拖动）

| 参数 | 值 |
|------|-----|
| `TARGET_RPM` | **100**（\(f_e≈11.7\) Hz） |
| `RAMP_S` | **3.0** |
| `IQ` | **0.5 A** |
| `HOLD_S` | **2.0** |

| 通过标准 | 数值口径 |
|----------|----------|
| 跟上 | HOLD 末 1 s：`mean(ω_enc)` ∈ 80～120 rpm |
| 同步 | `|θ_if−θ_enc|` 不持续单调爬到 >90° |
| 电流 | `Iq` 均值接近 0.5 A，无持续限幅打满 |
| 无 FAULT | 全程无丢步保护 |

**失败优先序**：① `RAMP_S`→5 s → ② Iq→0.7 A → ③ 再查相序/θ 定义。  
**本关通过即可认为「I/F 物理链路通」**；后面只是抬终点。

---

### G3 — **300 rpm**（对齐旧 startup 文档量级）

| 参数 | 值 |
|------|-----|
| `TARGET_RPM` | **300**（35 Hz） |
| `RAMP_S` | **4.0**（若 G2 用过 5 s，这里也从 5 s 起） |
| `IQ` | 沿用 G2 成功值 |

| 通过 | HOLD 末 `ω_enc` ∈ 270～330；角差不失控 |
| 失败 | 只加长斜坡或 +0.2 A；**不要**为冲 G3 把 Iq 一下加到 2 A |

录一包：`IF_G3_xxx.csv`。

---

### G4 — **600 rpm**（进入旁路 EMF「能看」区）

| 参数 | 值 |
|------|-----|
| `TARGET_RPM` | **600** |
| `RAMP_S` | **5.0～6.0** |
| `IQ` | G3 成功值 |

| 通过 | HOLD 稳；可选看旁路 `emag` 是否明显上升（对照 0910） |
| 说明 | 600 仍低于闭环 OBS 推荐地板；**本关不切 OBS** |

若 G3 轻松、G4 中段丢步：多半是加速度偏大，先 `RAMP_S+=2`。

---

### G5 — **900 rpm** + HOLD（与软切入点重叠）

| 参数 | 值 |
|------|-----|
| `TARGET_RPM` | **900**（105 Hz） |
| `RAMP_S` | **6.0～8.0** |
| `HOLD_S` | **3.0～5.0** |
| `IQ` | 仍优先小电流；不够再加 |

| 通过 | HOLD 全程 `ω_enc` 跟得住；`|err_θ|` 有界；无过流 |
| 加分 | 同包旁路 PLL `\|err\|p95` 与 `2048@~900` 同量级（约十余度内） |

**到这里才具备「用 I/F 代替编码器爬升」的资格。**  
仍 **不要** 默认切 OBS。

---

### G6 —（可选）I/F → 现有软切 OBS

**前置**：G5 连续 2 包通过。

| 步骤 | 动作 |
|------|------|
| 1 | HOLD@900，SMO+PLL **旁路**已在跑 |
| 2 | 开 `OBS_SS`，ENTER=900；θ 从 `θ_if` **blend** 到 `θ̂`（或先 θ̂、速仍 IF 一拍——以 bumpless 为准） |
| 3 | Iq_ref 从 IF 恒流 **交给速度环**（先有感速度环也行） |
| 4 | 再开「速度反馈=观测速」 |

| 通过 | ch11→OBS；soak ≥30 s；对照 1548 量级 |
| 失败 | 回 G5；禁止在 G4 以下强行 G6 |
