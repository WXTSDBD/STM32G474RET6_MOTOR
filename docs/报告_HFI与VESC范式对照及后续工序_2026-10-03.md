## 0. 结论（先读）

1. **主要矛盾（控制）**：减速进入 SMO 不可观区时必须保留持续激励 Vh；Vh 作为电压扰动又必须与 **基波 Id 环（Id\*=0）** 共存。Id 环不能在交接当事件突然合上（IDUP 失步），必须全程跟进。而现有 HFI 解调吃的就是这条被调节到 0 的 Id，观测与调节代数对立。改 HFI 是这条链的结果，不是另起炉灶。台架：关环踢前约 0.03 rad；84 开环 FEED 约 1.25 rad；89 约 2.14 rad。  
2. **VESC 的 HFI 在「开着电流环」这个约束下明显更强**，强在范式：环后注入、载波单独解调、发布角与关载波分开。不是凸极更强——关环已经证明本电机可观。  
3. **高速观测不必换成 VESC 磁链。** SMO 与 Ortega 磁链是两类电压/反电势模型，中高速都可以跟转子。本板 IF→SMO 已签收，HFI→SMO 关环加速能守 1500。缺的是与 HFI 的电压记账和切换语义，不是另一套 ψ 方程。  
4. **产品形态可以定为**：低速用 VESC 范式的脉振 HFI（Id\*=0、环常开）；高速继续 SMO（`u−u_hfi`）；切换学 VESC 调度（两角近 + 滞回换发布角 + 旋 PI）。不上 FFT、不换 `flux_observer`，直到开环锁相触顶。  
5. **工序**：先把 84 类 FEED 开环锁相从 1.25 rad 收下来，再谈 1500。GATE72/91/92 的加速通过 **不能** 当作 Id=0 HFI 已完成。GATE93 把 89 叠到 92 梯速上，是反序，不要采 1500 包。

## 2. 主要矛盾（控制理论）

问题不是「想做成 VESC」。起点是 **SMO 减速失步**，后面才逼出 Id\*=0 和改 HFI。

### 2.1 因果（工程上实际发生的顺序）

1. SMO 是反电势观测。可观性依赖 \(|e|\propto\omega\lambda\)。减速到低速，SMO 单独不可观，轴易丢。
2. 为在不可观区仍有信息，减速仍要 **Vh 持续激励**（凸极 Δi）。Vh 是叠在电压上的方波扰动。
3. 不减干净时，SMO 把载波当基波电压 → 假锁 / 2147 类挂。减干净（91）只解决观测器输入，**电流环仍看见 Vh**。
4. 与 Vh 接轨需要 **基波 Id 被调节到 0**：否则 d 轴电流漂、电压余量被载波占满、Park 误差时 Vh 进 q 出矩。Id\*=0 是和载波共存的条件，不是调参口味。
5. Id 环 **不能在进 SMO 那一拍才合上**（58/62/64 IDUP）：混合系统切换，积分与植物同时变，失步。无扰切换要求调节器在切观测器之前已经在环里、指令已经是 Id\*=0。
6. 于是 Id\*=0 必须从 HFI 段全程跟进 → 现有半周解调与 PI 抢同一条 Id → **HFI 必须改成两时间尺度分离**（基波环 + 环后载波）。这才接到 VESC 范式。

```
SMO 减速不可观
    → 必须留 Vh（持续激励）
    → Vh 是电压扰动，要与电流环共存
    → 共存条件：基波 Id*=0 且 PI 常开（不能 IDUP）
    → PI 常开会掐掉「吃 Id 的解调」
    → 必须改 HFI（环后注入 + 解调离开 Id）
```

### 2.2 控制命题

**可观性。** SMO：输出对转子角的灵敏度随 \(\omega\) 降到 0。HFI：高频电流响应对 \(2\theta\) 的灵敏度在零速仍在。减速要两者交叠，交叠窗口里 **Vh 必须还在**。

**扰动分离（两时间尺度）。** 电流环带宽应压在载波之下，只调基波；Vh 加在环后，作为外生持续激励。本实现把 ±Vh 加进 Ud 再让 Id PI 去跟 Id\*=0，等于让调节器 inversion 掉激励，解调 \(x,y\) 被闭环零化。关环能锁（0.03 rad）是因为去掉了这个 inversion；开环 1.25 rad 是 inversion 与解调还耦合。

**无扰切换。** 发布角从 θ̂_HFI 换到 θ_SMO 时，电流环的植物（Park 方向）变了，但调节器状态应连续：Id\*=0 事先成立，电压矢量旋到新坐标（92 旋 PI 只做了切帧，没做「环从未断过」）。IDUP 是把开环植物突然改成闭环，不是切换观测器。

**内部模型冲突。** 同一测量 Id 不能同时当 (i) PI 误差（要 →0）和 (ii) 凸极传感器（要 Δi≠0）。这是结构矛盾，拧 LPF/HP（85–90）消不掉。

### 2.3 和台架怎么对上

| 控制点 | 台架 |
|--------|------|
| SMO 低速不可观 + 残 Vh | 2147 减速挂 |
| 观测器输入含载波 | 91 减 `u_hfi` 后静置不炸；加速仍像 72 |
| Id 环当事件合上 | IDUP 塌速 |
| Id 环全程开但解调仍吃 Id | 84/89 FEED 能转、角差 1 rad 级 |
| 关环加速 | 72 能守 1500，**没有** Id–Vh 接轨，不能当产品减速解 |

72 加速做得再好，只说明关环时交接状态机能过。产品减速要的「Vh + Id\*=0 + SMO」三条同时成立，必须先拆开观测与 Id 调节。

VESC 不是另一套凸极，是已经按 §2.2 做了：环后注入、解调离开 Id、发布角与关载波分开、磁链减 Vh。高速仍可用本 SMO，不必换 Ortega 方程。

## 3. HFI 完全对照

### 3.1 信号流

**本实现（当前能转的关环路径）**

```
ADC → Clarke → Park(θ̂) → Id, Iq
        ├─ Id PI 常旁路（72）或与解调抢同一条 Id（84）
        ├─ 半周 di_d, di_q → x,y LPF → ε = ½ atan2(y, x−A) → PLL → θ̂
        └─ Ud_pi + (±Vh 在 d) → 反 Park → SVPWM
```

**VESC / `别人的代码` 调用面**

```
ADC（常含载波相位上的成对样本）
  → 基波 Id/Iq PI（全程开，Id*=0）
  → 反 Park 得 uαβ_fund
  → uαβ += Vh·(cos φ_inj, sin φ_inj)     // 环后注入
  → SVPWM

并行：
  注入轴电流 / FFT → θ̂_HFI（Type-2 PLL）
  磁链：u − u_hfi（同 PWM 周期记账）
```

Park=θ̂ 时，「d 轴 ±Vh」与「αβ 加在注入方向」**代数等价**。GATE88 的失败是极性/`s_sign` 与是否进桥，不能写成「αβ 注入更差」。真正不等价的是：**PI 会不会去对消 Vh**。环后注入则 PI 只调节基波。

### 3.2 分项

| 维度 | 本实现 | VESC / 别人的代码 |
|------|--------|-------------------|
| 物理量 | 凸极，半周 Δi | 凸极，载波谐波 / FFT bin 或成对样本 |
| 注入位置 | 估计 d，进 Ud | 电流环后 αβ |
| 采样 | G4 JEOC 与电流环同一拍 | 常与 PWM 边沿成对；半周 comb 对齐完成的 PWM 电压 |
| 解调坐标 | 默认 Id/Iq 差分 | 注入轴 / FFT，不走 PI 的 Id |
| 角度环 | ε→PLL（死区 / HOLD / SKIP） | Type-2 PLL，带宽压在解调极点下；scan→tracking |
| Id 环 | 关环能锁；开环锁差 | 全程开，Id\*=0 |
| 极性 | q 踢 + 静置 2θ | 扫描轴双向标定符号；IPD 可关 |
| 载波幅值 | 固定 VH；交接 FADE/VH0 收 scale | start / run / max |
| 与高速观测 | 72 常 hold SMO；91 减 u_hfi 后继续 | 磁链一直跑，减 `sample_hfi_voltage` |
| 切换 | QUAL(转速+x)→灭 Vh→旋 Park→VH0 | 只调度载波与发布角；**不改电流环坐标系**（见 `sensorless_vesc_hfi_schedule`） |
| 切帧 | 92 一次性旋 Ud/Uq | `sensorless_native_seed_rotor_current`：电压、电流、指令、积分都旋 |
| 本仓库 | 可编译可烧 | **无 `vesc_hfi.c`**，不能当库 |

### 3.3 「VESC 是不是全面更好」

| 问题 | 答案 |
|------|------|
| 开着 Id 环还能锁吗 | **是，结构上就是为此设计的。** 本板无并排 VOFA，不能吹它在 N5065 上也能到 0.03 rad。 |
| 电流环稳定性 | 赢在 **没有旁路/IDUP 换植物**，不是 VESC 的 Kp/Ki 在本板上相位裕度更大。辨识过的环应留下。 |
| 切换裕度 | 赢在发布角 ≠ 关载波、滞回、切前两角近。直接针对 VH0 Iq 台阶和用转速当唯一门。 |
| 工况泛用 | 通用电调现场更经打磨。低凸极机 FFT 也锁不住。G4 不是 VESC 双边沿，克隆工程不会自动变好。 |
| 关环静置锁相 | 本实现已经很好（0.03 rad），这里 **没有**「VESC 公式碾压」。 |

## 4. 高速观测完全对照：SMO vs Ortega 磁链

### 4.1 方程

**本 SMO**（`emf_smo_update`）

- 电流滑模：`z = k·sat(î − i)`，`î` 按 `(u − z)/L` 离散推进。  
- `e ≈ LPF(z)`（默认约 200 Hz，可按转速调度）。  
- `θ = atan2(−eα, eβ) − THETA_OFF`（偏置约 −0.40 rad，补偿 LPF 相移）。  
- 产品角再经 `emf_pll`（Type-II，正交鉴相）。SMO 结构体里的 `omega_el` 是 **传入机械转速的换算**，不是 e 的微分；速度由 PLL 出。  
- 电感用一个 `Ld`（当隐极）。

**VESC 磁链**（`flux_observer_update`，头文件写明 VESC-style nonlinear voltage-model）

- `ψ̇_s = u − R i + γ_half · ψ_r · correction`（Ortega 单边 λ 补偿：正误差不进 `x_dot`）。  
- `ψ_r = ψ_s − L_eff i`，`L_eff` 含 Ld−Lq。  
- `θ = atan2(ψβ, ψα)`；`phase_velocity` 由相差分 + 约 10 Hz / 100 Hz 滤波。  
- 零速不可观：未达反电势区则 **seed 到已知 I/F（或 HFI）坐标系**，不标 `locked`。  
- HFI 载波：同周期 `sample_voltage − sample_hfi_voltage`，再 4-tick comb，避免用晚一拍的 `hfi_volt`（注释写明那是 HFI/磁链边界相漂的原因）。

### 4.2 分项

| 维度 | 本 SMO + PLL | VESC 磁链 |
|------|----------------|-----------|
| 观测对象 | 反电势方向 | 转子磁链方向 |
| 零速 | e→0，不能扛；必须 HFI | 同样不能扛；seed，不 locked |
| 参数 | Rs、L、k、sat、e-LPF、角偏置 | Rs、L、Ld−Lq、λ、γ、幅值门、可观最低转速 |
| 载波 | 91 起 `u−u_hfi` | 显式减同周期 HFI 电压 + comb |
| 凸极 | 一个 L | 有效电感随电流/相角 |
| 低速失败模式 | 假锁、LPF 滞后；2147 残 Vh 减速 | Rs 误差、积分饱和；靠滞回回 HFI |
| 本板证据 | IF→SMO 曾签收；关环 HFI→SMO 守 1500 | **未在本板跑过** |

两者都是 **中高速模型**，不是第二套 HFI。稳态都可以跟转子。磁链对 Rs 和电压积分更敏感；SMO 对 e-LPF 相位更敏感。没有对照包，不得声称磁链比本 SMO 更稳。

### 4.3 为何高速继续 SMO

- 电流环、死区、SVPWM、SMO/PLL 偏置已经在本电机上调过。  
- VESC 磁链的可借鉴处是：**减载波、HFI 段不停、可观门、切角前 seed/对齐**。这些是接口，可以接到 `emf_smo` 的 `uαβ` 与交接门上。  
- 换 `flux_observer` 要重辨识 λ/γ、重做加减密，且缺与本 FOC 的采样对齐。复利低。

## 5. 推荐产品结构（不是新仓库）

```
电流环：Id/Iq PI 一直算，Id*=0
注入：  invPark(ud_pi, uq_pi) 之后  αβ += Vh·注入方向
HFI：   注入轴电流半周差分（脉振先留）→ 现有 PLL
SMO：   全程 update，输入电压 = u − u_hfi（91 已有一刀）
切换：  两角近 + 速度滞回 → 发布角从 θ̂_hfi 换成 θ_smo
        载波可晚关；切帧旋一次 PI
        关载波 ≠ 改电流环坐标系
        禁止 IDUP / HFI 旁路
```

明确 **不搬**：整份 VESC、`mcpwm`、`vesc_hfi.c` FFT、`flux_observer.c` 五件套进 MDK、GATE85–90 的 HP/Park 顺序、用转速到点当唯一 QUAL 门。

## 9. 用旧版 HFI 的真实梯子重做 VESC 范式

旧版不是「开环 → 有感 → 力矩 → 交接」四字口令，而是 9/13 方案的 H0→H3，9/26 用 `M1_HFI_GATE` 重验收后签收过的那一串。VESC 范式必须 **按同一门禁重走**，不能跳到 84/72。依据：[规划_HFI四步重验收](./规划_HFI四步重验收与后续计划_2026-09-26.md)、[C4o 签收](./签收_C4o静置无感捕获_GATE29_2026-09-28.md)、[9/30 速度环总结](./调试报告_HFI无感速度环完成_GATE38_2026-09-30.md)。

### 9.1 旧版实际怎么走的（含翻过的坑）

原计划四步（9/13、9/26 未改意图）：

| 步 | 意图 | 编码器 |
|----|------|--------|
| 1 | Ud 开环摆姿态，HFI 开环辨识 | 真值 + MEAS 的 Park/注入参考 |
| 2 | 有感闭环 ~100 rpm，HFI 只估角 | 托速度环和 Park；HFI PLL **自己**出角 |
| 3 | HFI 无感起动 | 只录波 |
| 4 | HFI↔SMO | 只录波监督 |

9/13 曾以为 H0/H1「过了」：1638 跟到 1000 rpm，但是 \(\omega_{hfi}\) 与 \(\omega_{enc}\) 二阶差分相关 ~0.99，**HFI 在抄编码器 ω_ff**。9/14 拿掉前馈才第一次自持。所以 9/26 重跑时 S2 门禁写了：\(d^2(\omega_{hfi})\) 与 \(d^2(\omega_{enc})\) 相关必须 **< 0.3**。

铁律（旧文原文，V 系列沿用）：一包一变量；编码器 LIVE 否则整包作废；**1、2 未签收不准做 3；3 未签收不准改交接**；禁 enc ω_ff；禁动 `M1_ENCODER_OFFSET_RAD` 修标签；S1 FAIL 不许翻 XY / 改 A_cmd。

S3c0（1305）说明：旧梯子在 **Park=θ̂ 之后才允许小 Iq**，而且第一次大力矩爬是 FAIL。V 系列不得在 V3 没过时上 FEED，更不能上 1500。

C4o 的 Id 旁路是捕获路径后来加的。S2（1136）已经是有感三环，Id 在录波里。VESC 要证的不是「S2 才第一次开 Id」，而是 **环后注入 + 注入轴解调** 在同一套 Park 权威下，x/ε 不差于这些签收包。

### 9.2 V 系列（逐步替换注入/解调，不换门禁）

每步对照上表同一 Park/速度环/是否进 RUN。唯一增量：环后 αβ ±Vh、解调走注入轴 Δi。Id\*=0 从 **V2 起保持开**（有感 FOC 本就如此），V3 以后禁止再 `ID_PI_OFF`。

| **V1** | S1 | 0005；`_analyze_hfi_s1.py`：IDLE 8 s→13×3 s MEAS→LOG→DONE | 开环电压下注入轴 Δi 与旧 `di_d` 能对上 2θ | \|A\|>\|B\|，极值比 ~1.4，θ̂≡enc+δ，enc LIVE。**不进 RUN** |
