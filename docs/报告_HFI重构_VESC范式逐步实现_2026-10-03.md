## 0. 一句话

> **脉振方波、PLL、FOC、SMO 都留下。** 按当年 S1→S2→S3a→S3b→捕获/FEED→速度环→交接 的同一套 Park 权威重跑；每步只把「Ud 上叠 ±Vh + 吃 Id 的 Δi」换成「环后 αβ 注入 + 注入轴电流解调」。Id\*=0 从有感 S2 起就保持开，禁止再 IDUP、禁止用 72 关环加速当重构验收。

现行固件若停在 GATE93（开环叠 1500），**不要烧来跑重构**。回退对照用 GATE1 / 2 / 3 / 4 / 29 / 84。

## 1. 为什么重构（不是另写一套 HFI）

起点是 SMO 减速不可观，要留 Vh；Vh 要与基波 Id\*=0 共存；Id 环不能在交接才合上。现解调吃被 PI 掐的 Id。VESC 同是脉振方波，好在环后注入和解调离开 Id。  
重构 = 把这两件接到 **已经签收过的梯子** 上，不是从 84 或 72 中途改注入。

留下：`hfi_sqwave` 状态机、10 kHz 方波、`ε=½atan2(y,x−A_cmd)`、XY 落盘规则、q 踢、C4o 捕获时间线、SMO。  
换掉：Vh 进 Ud 且 PI 与解调抢 Id；QUAL→FADE→VH0 当「关载波=改电流环」；高速才 `id_pi_release`。

## 3. 目标结构（每一步都朝这里长，不要一步到位）

```
Id/Iq PI 一直算，Id*=0
invPark(ud_pi, uq_pi) → uαβ += Vh · (cos φ_inj, sin φ_inj) → SVPWM
φ_inj = 注入轴（S1：enc+δ；S2：enc d；S3 起：θ̂）
解调：注入轴上的半周 Δi（先不用 FFT）
ε、PLL、极性踢：沿用现公式与 C4o 时间线
SMO：u − u_hfi，HFI 段就跑（挂在 V3 以后复核，V7 才当 Park 源）
切换：两角近 + 滞回换发布角；关载波不改电流环坐标系；切帧旋 PI
```

## 5. 逐步实现（打算怎么改代码）

原则：新宏默认 0；只在当前 GATE overlay 里置 1。热路径仍在 `motor_current.c` 出桥前、`hfi_sqwave.c` 解调。CubeMX 文件不动。

### 5.1 公共能力（94 引入，之后各 GATE 只开不开）

1. **`u_hfi_αβ` 记账**  
   `ua_hfi = Vh_scale * vh_sign * cos(φ_inj)`，`ub_hfi` 同 sin。SVPWM 用 `uαβ_pi + u_hfi`。禁止再 `ud_pi += Vh`。  
   φ_inj：S1 用 enc+δ（与旧 MEAS 注入轴一致）；S2 用 enc；S3 起用 θ̂。

2. **注入轴解调**  
   `i_inj = iα·cosφ + iβ·sinφ`，`i_quad = −iα·sinφ + iβ·cosφ`。半周差分 → 现有 `x_raw/y_raw` 符号链（S1 仍 XY=+1 原始落盘，S2 起 XY=−1）。**不要**先上 GATE87/90 那种 Park(θ̂) 后再差分。  
   离线：`x ≈ (−vh_sign)·Δi_inj` 与落盘重合，同旧 S1 复核口径。

3. **Id 环**  
   V1 开环电压，可不跑 PI。V2 起：`ID_PI_OFF=0`，`Id*=0`，交接代码不得每拍 `release=0`。

4. **VOFA**  
   该步通道表与旧 S1/S2/S3 **同名同序**，便于拿 0005/1136 脚本改一列对照。可加一通道 `Ud_pi`（确认 V1 开环≈0、V2 起非恒 0 且不含方波主项）。

### 5.2 GATE94 / V1 — 开环尺

**改：** overlay = 现 GATE1 全部宏（`DELTA_SWEEP`、网格 −90…+90 / 15° / HOLD 3 s、IDLE 8 s、不进 RUN）+ 上述 1、2。  
**不改：** A_cmd、Kp/Ki、XY 开环 +1、死区、PLL 更新角、进 RUN。  
**烧录后：** 与 0005 同一操作。  
**过线：** 0005 表：LIVE、13 档齐、\|A\|>\|B\|、极值比 ~1.4、θ̂≡enc+δ、决策表可 `flip_xy`。φ 跨姿态差仍 <15°。  
**FAIL：** 只查 φ_inj 是否等于旧 MEAS 轴、Δi 是否用对了 αβ。不许翻 XY、改 A_cmd。  
**若几乎等于 0005：** 开环尺仍成立，下一包直接 95，不必反复扫网格。

### 5.3 GATE95 / V2 — 有感 100 rpm（分水岭）

**改：** overlay = 现 GATE2 + 94 的注入/解调。Park=enc，速度环 enc，ω_ff=0。Id PI 开。  
**不改：** 速度环增益、100 rpm 指令、A_cmd=+0.10（S2 签收值；此处不提前改 0.216）。  
**过线：** 1136 口径 + 反作弊相关 <0.3；x 在 A 附近不钉 A−B；ch11 Id 均值近 0、但半周 Δi_inj 仍在。  
**FAIL：** 相关 0.99 → 前馈又漏了，修配置。x 没了 → 环后注入相位/解调轴，**不要调 Kp、不要进 96**。

### 5.4 GATE96 / V3 — 静置 Park=θ̂

相对 95 **只换** `park_uses_hat`。Iq*=0。对照 1146：锁真 d，不钉 q（x 不要停在 A−B）。  
比 84 的 1.25 rad 好是目标，但本步门禁先对齐 1146，不拿 FEED 包否决静置。

### 5.5 GATE97 / V4 — q 踢

复制 GATE4 踢参数。Id 积分踢时保持。对照 1252：有 Δθ_enc；不要 C4n 那种 −Iq 刹车回摆（C4o 已否决对称刹车）。

### 5.6 GATE98 / V5 — 捕获后 FEED

时间线学 C4o（PRE 门禁、踢完 Iq=0 滑行再 FEED），**不要** `ID_PI_OFF`。FEED_A 先 0.5（旧 GATE30）再 0.8，仍一包一变量。  
过线：1930 的 G1–G7 + FEED 段 \|θ_err\| 相对 1225 下降（先打过 1 rad）。出现 1305 自指（反转、x→A−B、ε→0）= FAIL，回 96，加 Iq 权威而不是加 Vh。

### 5.7 GATE99 / V6 — 无感速度环

复制 GATE38 在 **ε 可用之后** 的收尾，不是复制 9/29 的 GATE52。

- 反馈 = 完整 ω（Kp·ε + 积分），从进 RUN 就替换，禁止只吃 `pll_int`。  
- `A_cmd` = 闭环圆心（0.216），禁用 0.238 与圆外 0.10。  
- 热路径只读 `s_run_rpm_cmd`，加档不得写进每拍 `get_speed_ref_rpm`（GATE51）。  
- ω* 先 0 再 `set_mode`，避免积分预载成 −Kp·目标。  
- SMO 可旁路录波，不进 Park。  
- 禁止冻 θ̂ 当「探查枪」（0014 AUTH 自扰）。

### 5.8 GATE100 / V7 — 交接

新状态机，不复用 72 的 FADE/VH0 改环：

- SMO 全程 `u−u_hfi`（91 已有，挂到本号复核）。  
- 发布角：两角近 + 速度滞回才从 θ̂ 换到 θ_smo；旋一次 PI。  
- 载波另用滞回关；关载波时电流环坐标系不变。  
- 禁止 IDUP。  

验收：先加速守速（72 只说明关环能过，本号必须 Id 环开着过）。再采减速，才对 2147。
