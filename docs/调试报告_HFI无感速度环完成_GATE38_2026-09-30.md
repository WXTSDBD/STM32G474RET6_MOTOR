## 0. 一句话

这半个月里，唯一让后面所有实验开始有意义的改动，是 ε。

固件里 ε 一直是

\[
\varepsilon = \tfrac12\operatorname{atan2}(y_{\mathrm{lp}},\; x_{\mathrm{lp}} - A_{\mathrm{cmd}}).
\]

9 月 30 日把 `A_cmd` 从 0.10 改成闭环圆的圆心 0.216。零点从圆外挪进圆内，ε 才从「最大大约 0.18 rad 的残差」变成能把估计角拉回 d 轴的角度误差。没有这个 ε，PLL 没有纠偏量，速度环、拔编码器和手摸恢复都没有对象。

现行枪是这次改完之后的 GATE 38：踢后速度环，ω* 从 0 以 50 rpm/s 走向 1800 rpm。电流上限 11 A。末次编译 Code=61476，0 Error / 0 Warning。人在约 1510 rpm 断电，断电前仍锁着，1800 rpm 没有守住。

## 1. ε 改了什么

闭环时 (x, y) 近似一个圆：圆心约 0.216，半径约 0.033（1715 / 1627 / 1435）。y 近似 −0.026·sin(2φ)。atan2 的原点就是 `A_cmd`。原点必须落在圆内，φ 从 −90° 走到 +90° 时，ε 才能跟着走满大约 ∓90°，并且符号是拉回（ε ≈ −φ）。

两个坏零点，9/14 之后都踩过：

| `A_cmd` | 原点在哪 | ε 变成什么 | 台架 |
|---------|----------|------------|------|
| 0.238（开环拟合，GATE 27 又烧过） | 在闭环 x 的上方 | 钉在 ±90°，只剩 y 的符号。静置也会积出假速度 | 1411 失败；9/16 闭环 x 中位 0.193，从未越过 0.238 |
| **0.10（9/26 起的签收值，直到 9/30 上午）** | 在圆外（0.216−0.033=0.183 > 0.10） | \|ε\| 被压在大约 0.18 rad。滑差一大，PLL 拉不回来，θ̂ 多走大约一圈电角 | 1715：0.8 A 末速约 383 rpm |
| **0.216（9/30，只改 GATE 38）** | 在圆心上 | ε 重新有动态范围。偏差不大时圆仍罩住原点 | 2041：同样 0.8 A 末速约 770 rpm，无丢电角 |

PLL 的 Kp=39.2、Ki=389、低通 a=0.05、XY 符号 −1/−1 都没有为这件事改。改的是 ε 的零点，也就是 ε 这个信号本身。

理论圆心 0.284 不能烧。它比闭环的圆还高，ε 会再次钉死。9/15 已经写过禁用模型 0.284，这条仍然对。

高速时圆心还会漂：约 100 rpm 时 x≈0.22，300≈0.25，1000≈0.28，1500≈0.31。0.216 是低速失败带的圆心。这几枪能锁住，是因为角度偏差一直不大（爬速大约 7°–18°）。偏差再长大，原点会再次出圆，这是留下的风险。

## 2. 从 9/14 到这个零点

### 2.1 9/14：环第一次自己转，当时没有把账记在 ε 上

9/13 记录里的「HFI 阶梯到 1000 rpm」（1638）后来被 9/18 拆开：那批包的 ω_hfi 高频和编码器逐点同构（二阶差分相关约 0.99）。相位是编码器前馈推进的。9/14 起前馈拿掉，PLL 第一次真自持。

当天的现象是 θ̂ 相对编码器偏大约 25°–40°，并且随 |Iq| 加大（2042 / 2125：约 −23° 到 −43°）。当时记成带载凸极轴相对磁钢轴的 Δ(|Iq|)。扫注入电压和死区压不下去。把这个偏置减进 Park（2054）PLL 崩；冻住 θ̂ 再扳（2125）瞬间对齐、随后又被拉回去。结论写成：PLL 锁凸极是对的，要求它对齐磁钢是错目标。维持电流低于约 1.5 A 转不动，1.6 A 只能到大约 30 rpm，θ_err 不平。功能性捕获没有过。

这件事里有真的：空载和带电流时凸极轴确实会挪。但它不是后来丢整圈的原因。9/14 还没有把「atan2 的零点在不在圆内」当成主故障，所以后面两周都在电流、极性、限幅上打转。

### 2.2 9/15：ε 的式子定下来，同时写下了一句后来害人的话

鉴相收成 `ε = ½atan2(y, x−A_cmd)`。决策表规定符号改在 x/y 落盘上，禁止只翻 ε。开环拟合的 A 大约 0.24，|B| 大约 0.04，|A|>|B|。

稳定性写成单边条件：`A_cmd < A+B` 就只有一个稳定点，**A_cmd 偏小（包括 0）没有风险**。`|A_cmd−A|<|B|`（原点在圆内）被降成充分条件，不当必须。模型 0.284 禁用，这条是对的。

「偏小就安全」在开环圆上成立：圆心 0.24、半径 0.04 时，0.10 仍在圆内。它没有给闭环留位置。闭环电流环会把脉动均值整个往下搬，圆会挪。零点只要落到圆外，ε 的幅度就被圆的张角卡住，不需要出现第二个稳定点，PLL 已经纠不了大滑差。9/30 的丢转就是这句判据漏掉的那一侧。

### 2.3 9/16–9/18：零点太高，ε 钉死

9/16 的 δ 网格证明式子本身和电机是合的：A≈0.238–0.240，|B|/A≈0.17–0.19，和 Ld/Lq 的静态比一致。公式没有写错。

同一天的闭环把 `A_cmd` 设成开环拟合 0.238。闭环 x 的中位停在约 0.193（就是 A−B），从来没有越过 0.238。`x−A_cmd` 恒为负，ε 百分之百钉在 ±90°。轴不动时 PLL 仍报大约 −80 rpm，那就是 Kp 乘一个常数 ±90°。9/15 的「停，重定标签」当时没有执行，而是把 XY 一起翻成 −1/−1（那是 180°，修不了零点）、再叠极性踢和辨识。

9/16 还有一半包的编码器静默冻死，φ 不可复现。那些包作废。ε 钉死这一条在编码器活着的闭环包上仍然成立，不是尺子冻死造成的。

9/18 把两件事写清：开环电压方波量到的 A，和闭环电流环量到的 A，不是同一个数。9/15 只要求 `A_cmd < A+B`，0.238 对开环的 A+B 满足，对闭环的 x 不满足。

### 2.4 9/26：为了躲开 ±90°，零点被放到圆外

1123：开环 0.238 大于闭环 x，ε 被切在 ±90°（切口）。GATE 2 的注释就是这句。按 9/15「偏小安全」，从 C4k 起 `A_cmd=+0.10`，写进 9/26 的四步计划，当作不再改的签收值。S1 开环尺仍用原始 XY；闭环 XY=−1/−1 保持。

0.10 确实让 ε 离开了 ±90° 的钉子，环能转、能爬。代价是原点在圆外，|ε|≤约 0.18 rad。小偏差时看起来锁得住，一有滑差就丢大约一圈电角。1715 就是这个形态：同样 0.8 A、同样时间，末速约 383 rpm。

GATE 27 把 0.238 再烧回去，1411 失败，冻结。于是两个坏零点都有实验：太高则 ε 钉死，太低则 ε 没幅度。中间的闭环圆心一直没有写进固件。

### 2.5 9/27–9/29：后面的关卡都建在这个 ε 上

静置捕获、q 轴踢、有感速度环，是在 0.10 上逐项签收的。有感速度环能转，是因为 Park 或反馈里还有编码器，ε 的幅度不够被尺子补上了。9/29 把速度反馈改成只吃 PLL 积分项（GATE 52），冷启动正反馈、角钉 q 轴。积分项在捕获时几乎是 0；真正在拉角的是 Kp·ε。那时的 ε 又已经被 0.10 压扁，所以「无感速度环失败」里有 PI 的问题，也有 ε 根本没有动态范围的问题。先修 PI、不修 ε，环没有误差可用。

### 2.6 9/30：零点放回圆心

只在 GATE 38 把 `A_cmd` 改成 0.216。2041 同一 0.8 A 末速约 770 rpm，相对角留在大约 −53° 到 +41°，结束约 −6°，没有丢电角。电流环变快，是因为电流留在转矩轴上。

这一包之后，速度环、PLL 钳位、拔编码器和手摸才有资格讨论。那些改动解决的是「ε 已经能用」之后的环，不是 ε 本身。

## 3. ε 可用之后才成立的收尾

### 3.1 速度环

反馈用完整 ω = Kp·ε + 积分，从进入 RUN 起就替换，不回编码器 PLL。只吃积分项会把正在纠偏的 Kp·ε 当成速度 0。

PI：Kp=0.015 不动。Ki 从 0.002 改到 6.5e-6，β 从 0.4 改到 1。旧 Ki 大约每 1 rpm 误差积 4 A/s，马上顶满。β=0.4 在转速已经跟上时比例项仍是大的负电流。6.5e-6 来自 2041 的空载斜率：Kt≈229 rpm/s/A，wn≈1.7 rad/s，ζ=1，连续 Ki≈0.013 A/(rpm·s)，固件每 500 µs 积一次。斜坡 50 rpm/s。500 rpm/s 会把电流打进限幅。

无扰：ω* 已经写成目标再 `set_mode`，积分会被预载成 −Kp·目标（300 rpm 时 −4.5 A），小 Ki 卸不掉。改为先把 ω* 写成 0，`set_mode(0, 0)`，再写回目标。

电流上限 11 A，与 SMO 相同。不加 ±2 rpm 钳位，不用「角差大于 90° 就停」。

2101 守住 300 rpm（末 4 s 编码器 300.3±7.9，HFI 300.2±3.6，Iq* 均值 0.26 A）。2109 以 50 rpm/s 到 1000 再保持，约 22 s 起守在 1008 rpm，Iq* 均值 0.63 A，角差中位 −7.9°，5%–95% 为 −14.6° / −2.3°。把 2109 重算，只有用 ch1（HFI ω）当反馈才和记录里的 Iq* 重合（相关 0.993，误差 0.06 A）；用编码器 PLL 是 0.68 / 0.29 A。

### 3.2 看记录时的尺子

编码器指令、SPI、ANGLEUNC 都没改。分析上踩过：20 ms 角度差在大约 200 rpm 以上卷绕，假天花板约 214 rpm；一个大于约 30° 的单步会把 10 ms 平均抬高约 90 rpm（2101 约 4.9 s 那一下到约 390 rpm，不是超调）；ch6 是编码器自己的 PLL，不能拿来判 HFI。有一版未调用的 MAG/ERRFL 遥测和头文件不一致，编译 19 个错误，已从 `as5047_async.c` 删掉。

### 3.3 PLL 钳位和「2 A」

钳位原为 1100 rad/s 电角，约 1501 rpm，估计会先于电机被夹平。改到 1700 rad/s，约 2320 rpm。PLL 增益没动。

2120 朝 1800 爬，约 1530 rpm 时人为断电，角差仍约 −13°，Iq* 约 5.8 A。2 A 是 50 rpm/s 还在加速时的电流。第一次超过 2 A 在约 988 rpm。同一斜率的 2109 在 1000 rpm 保持时只有 0.63 A。1500 rpm 以上没有保持段，巡航电流未知。

### 3.4 拔编码器

速度环转起来之后不吃编码器，但 `INIT_FROM_ENC=1` 会在进 RUN 时用编码器给 θ̂ 播种，电流重构也用编码器角选扇区。拔线后这个初值是 0 或浮空。SPI 阻塞读最多 1 秒超时，运行中不在中断里等。

GATE 38 改为不播种，θ̂ 从 0 起，2 s 预锁靠 ε 和 x 找 d 轴。进入 RUN 后扇区和速度反馈只用 HFI。预锁门本来就不看编码器。2144：7.7 s 起正向爬。凸极仍有 180° 模糊，这一枪方向是对的，没有做成极性保证。

### 3.5 手按

2144 在大约 100、190、260、370 rpm 按了四次。每次 ε 顶到 ±90°，x 掉到约 0.17，松手后大约 0.2 s 回到斜坡，没有翻极。比 I/F 开环强，因为 ε 还在，松手能拉回 d 轴。

软是因为速度反馈用的是完整 ω。ε 顶满时读数在积分转速两边各偏大约 80 rpm，Iq* 只到 2–3 A，还出现过约 −0.7 A。积分器本身是稳的。这是 ε 可用之后的速度环问题，留给无感优化。

38.4 s、约 1510 rpm 之后 x 掉到 0、ε 钉死，是断电。断电前一拍 x≈0.33，ε 仍然很小。

## 5. 下一步

SMO 闭环地板以 2026-09-11 为准：900 rpm 以上稳定，800 勉强，750 回退。9/13 方案里 400–800 rpm 的重叠区不能用。

| 转速 | 谁出力 |
|------|--------|
| 低于 800 rpm | 只 HFI。这里靠的就是现在这个 ε |
| 900–1100 rpm | 融合。\|ω_hfi\|≥900 且 \|θ_hfi−θ_smo\|<15° 连续 0.4 s 才进入 |
| 不低于 1100 rpm | SMO |
| 回到 800 rpm 以下 | 交回 HFI，相对进入点 100 rpm 回差 |

先做的一步：HFI 仍单独闭环，SMO 只在旁边算，在 900–1100 rpm 记下两角之差。

无感优化与交接分开：

1. 手按时速度反馈改吃积分项，或在 \|ε\| 顶满时保持上一拍积分转速。完整 ω 里的 Kp·ε 继续只负责拉角。
2. 圆心随转速从 0.216 漂到约 0.31。偏差仍小可以不改；高速角差变大时，再让 `A_cmd` 跟着动，否则 ε 会再次出圆。
3. 拔线后的 180° 极性。2144 方向是对的，不能当成已经保证。

回退：ε 坏掉的上一形态是 GATE 38 且 `A_cmd=0.10`。再往前，零点太高的形态是 `A_cmd=0.238`（GATE 27 / 9/16）。速度环吃积分项的失败形态是 GATE 52。
