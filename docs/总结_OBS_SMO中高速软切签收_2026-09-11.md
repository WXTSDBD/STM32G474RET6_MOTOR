## 1. 一句话结论

**中高速无感软切（约 1000 rpm）已打通并可稳定浸泡；EMF 工作区地板约 800–850 rpm。**  
启动/低速仍靠编码器；&lt;750 强行 OBS 会崩。不是 Rs/Ld「估飞」，而是反电势 SNR + 闭环放大。

| 项 | 状态 |
|----|------|
| @1000 软切角+速到 OBS | ✅ |
| @1000 长浸泡（分钟级） | ✅ |
| 角差直流偏置（FF+残差） | ✅ 约 +0.6°（1548） |
| EMF 可用下限（闭环降速） | ⚠️ ~800 勉强 / 750 FAIL |
| 全转速无感 / 弱磁 / HFI | ❌ 未做 |
| 异响（1/rev、~8–10 Hz） | ⚠️ 品质项，不挡中高速签收 |

---

## 2. 实现要点（签收范围）

1. **SMO → EMF-PLL**：滑模残抖不再直接 `atan` 进角；PLL 鉴相积分。  
2. **软切**：`obs_soft_switch` 武装→融合→OBS；Park=θ̂，速度反馈=θ̂→`motor_pll`（可 LPF）。  
3. **相位**：e-LPF 模型前馈 \(-\mathrm{atan}(f_e/f_c)\) + 有感残差 `THETA_OFF`（本机约 +0.1147 rad）。  
4. **监督**：编码器角差默认不回切；过流 / 观测掉速仍可 FALLBACK。  
5. **探底**：1000 rpm 切入后每 10 s −50 rpm，找闭环保持下限。

VOFA×12（软切包）：

| ch | 含义 |
|----|------|
| 0 | `speed_fb`（OBS 时与速度 PI 一致） |
| 1 | `ω_ref` |
| 2 | `iq_ref` |
| 3 | `err = θ̂ − θ_enc`（rad→分析用 °） |
| 5 | 观测速 |
| 6 | `|e|` / emag |
| 11 | `ss_state + 0.1α`（3=OBS，4=FALLBACK） |

## 3. 关键数据

### 3.1 @1000 rpm 闭环浸泡（签收主档）

| 包 | 配置要点 | OBS 时段 | mean err | \|err\| p95 | 备注 |
|----|----------|----------|----------|-------------|------|
| **1548** | LPF 相位 FF + 残差 OFF；速度 LPF 25 Hz；KI=0.002 | ~7.0–66.1 s（~59 s） | **+0.59°** | **15.0°** | 末段手碰→FALLBACK |
| 1526 | 耦合切断后、FF 前 | 全程 OBS | **≈−10°** | ~19° | 锁定滞后，无 94 Hz |
| 1612 | KI×0.6 | ~49 s OBS，无 FALLBACK | +1.02° | 15.2° | Iq@16.6 Hz ↓，~8 Hz ↑ |
| 1626 | +θ̂ 1/rev notch | ~48 s OBS | −3.2° | 19° | 陷波对听感/1/rev 收益不明 |

**1548 干净窗（排除手碰）频谱**：角误差主峰 ≈ **16.57 Hz**（机械 1/rev @1000 rpm），不是失锁。

**相对 1526**：直流偏置 **−10° → +0.6°**（模型 FF + 残差），见 [分析报告_无感软切与LPF相位前馈](分析报告_无感软切与LPF相位前馈_2026-09-11.md)。

### 3.2 降速探地板 `1654`（1000→400，−50 rpm / 10 s）

- 触发：观测速崩溃低于 EXIT（350），伴随 Iq 冲击；属保护，不是软切状态机误跳。

### 3.3 与昨天旁路对照（有感 Park，不进闭环）

`2048` SMO→PLL 旁路（[报告](分析报告_OBS_SMO_PLL_vofa+202609102048_2026-09-10.md)）：

| rpm 附近 | PLL \|err\| p95（旁路） |
|----------|-------------------------|
| ~500 | 23–31° |
| ~600 | ~18° |
| ~800 | **~11°** |
| ~1000 | **~8°** |

同日有感控制下，编码器转速的机械 **1/rev（≈rpm/60）** 在多数 0910 包已存在（`rpm@1/rev` 典型 2–5），说明 **1/rev 不是无感独有**。

**闭环 vs 旁路 @800**：旁路 ~11°，`1654` 闭环 ~30° → **θ̂ 进 Park+速度环会放大低速劣化**；地板比旁路「可用区」更高一档是预期现象。

## 4. 原因判断（低速为什么不行）

| 因素 | 证据 | 属性 |
|------|------|------|
| EMF SNR ↓ | `1654` emag：1.82→0.94（1000→800） | 物理 / EMF 法极限 |
| 角质量 ↓ | \|err\|p95：15°→30° 仍在 OBS | SMO+PLL 低速 |
| 闭环放大 | 旁路@800~11° vs 闭环~30° | 控制耦合 |
| Rs/Ld 估错？ | 与 Veq 共用 R、L；Veq 旁路 PASS；median 可校到 ~0 | **次要**（只用 Ld 忽略 Lq 为近似） |

**不是**：软切没写完、或「只有模型参数错了」。  
**是**：中高速 EMF 无感已成立；再往下要 HFI / I/F / 有感过桥，并保证与 EMF 区**重叠**，避免真空带。

---

## 5. 签收声明与未覆盖项

### 5.1 有条件签收（⚠️）

- 工况：轻载附近、**约 900–1000 rpm** 稳态与降速保持至 ~800。  
- 编码器：启动与低速；OBS 后仅监督。  
- 配方：`m1_speed_1000rpm` + 当前 `THETA_OFF` / PLL / LPF 组合（换电机须重标残差）。

### 5.2 明确不在本次签收

- 零速 / 启动无感、HFI、弱磁扩速  
- 大负载阶跃、正反转、全温漂量产认证  
- 异响彻底消除（1/rev 植物量 + OBS 段 ~8–10 Hz 品质问题）  
- θ̂ 陷波作为标配（1626 未显示明确收益）

## 7. 下一步建议（不阻塞本签收）

1. 产品口径写清：无感工作区 **≥900 rpm**（或实测标定地板）。  
2. 低速：HFI 或 I/F，目标与 EMF 区重叠（避免 500–800 真空）。  
3. 品质：OBS 段 ~8–10 Hz / 听感另开课题；不必再指望单靠速度 LPF/KI。  
4. 换电机：只重标 `THETA_OFF` 残差；FF 公式可移植。
