### 1.2 机制结论（已钉死）

1. **缺口在无感捕获，不在「θ̂ 永远不能出力」。**  
2. **自指**：Park=PLL=θ̂ 时，错轴 + 大力矩 → ε≈0 自洽、\(x\approx A-B\)、钉真 q。  
3. **限 Iq**：适合「质量差 / 失锁」时的**临时**权威；巡航/带载应放到负载需要的上限。  
4. **产品路径**仍是低速 HFI → 中高速 SMO；编码器只录波验收。

### 1.3 不要混淆的映射

| 容易误读 | 正确读法 |
|----------|----------|
| S3c0 = 巡航、S3c0a = 起步 | **否**。S3c0=常值 Iq 爬（无速度环）；S3c0a=一进 RUN 就要 100 rpm（捕获+巡航绑死） |
| 过整枪 S3c0a 则一切 OK | **否**。1358 整枪 FAIL；真正欠的是可重复捕获 |
| 限死 0.25 A 就是产品方案 | **否**。1439 说明未咬住就限死 → 权威永不放 |

## 2. S3c0a（1358）细读——为何是「捕获问题」

**靴1（主证据）**，Park=θ̂，ω\*=100，ω_ff=0：

| 时段 | 现象 | 解读 |
|------|------|------|
| IDLE 末 | err≈−17°，x≈0.10 | 进 RUN 前锁不实 |
| 0–0.5 s | err→≈−96°，\|Iq\|~9 A，x≈0.18 | 速度环一要速，钉进真 q |
| 0.5–18 s | err≈−94°，x≈0.185≈A−B，\|ε\|≈5°，\|Iq\|≈10.5 A，ω 晃 | 假锁自洽；大电流硬拖 |
| 18–21.4 s | err 晃、Iq 偶发卸荷 | 盆地不稳 |
| **21.4 s–结束 ~3.7 s** | err≈−8°，x≈0.237≈A，\|Iq\|≈0.28 A，ω≈100 | **巡航形态成立** |

靴2：全程钉 q、轴不动 → 捕获**偶然**。  
d² 相关 ≈0 → **不是** 1638 抄编码器。

**结论：** 巡航在「已咬真 d」时基本成立；S3c0a 整枪 FAIL = **捕获不可靠**。

## 3. S3c0b（1439）细读——限 Iq 的边界

| 项 | 结果 |
|----|------|
| \|Iq\| | 全程钉 **0.25 A**（权威链路通） |
| x | 钉 **~0.12**，不到 0.218 → 永不放权 |
| ω | ≈0 |
| 相对 1358 | 不再顶 11 A，但也失去「大电流晃出盆地」 |

**结论：** 只限 Iq、一上来就要速 = 死锁。缺的是 **先咬住再放权/要速**，不是放弃权威门。

## 4. 之后怎么做：先捕获、后巡航

### 4.1 两段语义（产品）

| 段 | 目标 | Iq / 速度 |
|----|------|-----------|
| **捕获** | 无感进真 d；极性标志有效 | Iq≈0 或极低；ω\*=0；质量差则压权威 |
| **巡航** | 跟速/出力 | 质量过线后权威 → **正常上限**（带载可到额定需求） |

失锁 → 回到捕获同一套（信号条件，非固定时刻有感门）。

极性：上电/首次捕获做一次即可；`pol_valid` 有效则停转再起不必每踢；失锁清标志后再踢。

### 4.2 验收总原则

- **决策不用 enc**（\(x_{lp}\)、假锁指纹、质量标志）。  
- **enc 只事后验收**（θ_err≈0°/180°，非 ±90°）。  
- **一包一变量**；失败必须能回答「相对上一枪只多了什么」。

## 6. 明确不做

- 定时切有感 Park 当作产品捕获。  
- I/F / enc \(\omega_{ff}\) / 开死区 / 加大 Vh 赌过线。  
- 捕获未过就带载顶满 Iq 或冲 HFI↔SMO。  
- 用「1358 末段偶发变好」或「1439 Iq 被限住」冒充捕获 PASS。  
- 一包同时改：种子 + 权威阈值 + 速度环 + 极性踢。
