## 1. 今天一句话

**搞清了「θ̂ 对 enc 偏 ~25–40°」不是估角 bug，而是带载凸极轴相对磁钢轴的 Δ(|Iq|)；偏置标定中间层已证伪并关掉。CAPTURE 起转条件摸清（维持须 ≥~1.5 A），但功能性 PASS（θ_err 平直 + 稳到目标速）还没过，明天继续。**

## 3. 有什么问题（未结）

### 3.1 主问题（明天优先）

1. **CAPTURE 功能性未 PASS**  
   - θ_err 非常偏且仍有斜率（滑差/慢漂）  
   - 目标 ~100 rpm，实测稳态约 **30–40 rpm**  

2. **破粘时机**  
   - CAPTURE 开头常有 **~0.5–0.8 s Iq_ref=0**（软冷却），破粘窗口被吃掉  

3. **有效转矩不足到目标速**  
   - `Iq − Bv·ω` + 凸极 Park 上的 Δ → 平衡转速低于设计 ω_eq  
   - 台架静摩擦/齿槽：维持 **&lt;~1.5 A 转不动**（已确认）  

### 3.2 已搁置（今天明确不做）

- 再扫 Vh / dead  
- 再堆偏置状态机 / 双坐标系补偿  
- 用 \|θ_err\|&lt;12° 卡启动  
- SMO 交接 / 700–1100 双曲线（排后面）  
- 重测 HFI 上限（1638 已覆盖中高速）  

### 3.3 物理账（写进认识，不是 bug 单）

```
θ_HFI = θ_PM + Δ(|Iq|)
```

- 空载/ALIGN 时 Δ 小；带 Iq 后交叉饱和拉开主轴  
- PLL 锁凸极是对的；要求它对齐 enc/磁钢轴是错目标  
- Δ 的精确补偿留给交接段（慢融合或查表），不在今天 CAPTURE  

---

## 4. 明天建议做什么

按优先级：

1. **破粘贴 CAPTURE 起点**（`stage_t=0` 就出力，避免先空转 0.5–0.8 s）  
2. **维持固定 ≥1.6 A**，先盯 **θ_err 平直 + 同向稳转**（PASS 主判据）  
3. 若平直后转速仍停 30–40：再 **略抬 hold 或略减 Bv**，给 Δ 留余量去碰 ~100 rpm  
4. PASS 后再开 **ARM_RUN**，目标先 **~100 rpm 速环**，不要一次冲 1000  
5. 再往后：100→几百→对接 1638 已验证区；最后才 700–1100 定 SMO 交接点  

**不要**：恢复 BIAS_CAL；用 ω̂≈ω_cmd 判锁；为消 Δ 去加注入电压。

## 6. 对论文/结档的可用结论

今日并非「HFI 失败」，而是完成了一条可写进报告的认识：

> 带载时脉振 HFI 测的是凸极主轴，相对磁钢/编码器存在随 \|Iq\| 增大的确定偏置 Δ；启动应以功能性锁定（θ_err 平直、真速跟上）为门限，角偏置留到 HFI↔SMO 交接处理。
