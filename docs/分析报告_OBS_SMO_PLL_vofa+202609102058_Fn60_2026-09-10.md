## 1. 一句话

**降带宽有小幅收益：中低速 PLL p95 约降 1～3°；高速几乎不变（仍 ~8°）。**  
600 rpm 从 ~18° 收到 ~15°（贴 15° 门槛）；**仍不足以把首切安全降到 500。**

## 2. Cycle / 电流

与 2048 同量级：isr≈5963 / max≈6395，obs≈1478，ia 干净 → 改 Fn **无副作用**。

## 4. 对「能切多低」的含义

| 转速 | Fn60 结论 |
|------|-----------|
| 500 | p95≈20°，**仍不宜切** |
| 600 | ≈15.4°，**贴边**，可当实验切入点试，正式偏紧 |
| ≥700 | 更舒适（12.6°↓） |
| ≥800 | 仍建议作为**稳健首切** |

降 Fn **小幅下移**可用区，不是质变。

---

## 5. 判定与下一步

| 项 | 结论 |
|----|------|
| Fn=60 是否值得保留 | ✅ 中低速略好、高速不伤 → **可作默认** |
| 再降 Fn（如 40） | 可能再抠 1° 级，收益递减；加速跟踪会更钝 |
| 要明显压低切入转速 | 需动 **SMO（K/SAT/LPF）**，不单靠 PLL |

**建议**：默认维持 `Fn=60`；若还要冲 500～600 无感，下一刀改 SMO 侧参数并同布局复测。
