## 1\. 系统概述与框图

### 1\.1 设计目标

Foundation v1\.0\.0 是一块双路三相 PMSM 电机驱动验证平台，核心目标是：

- **双路独立 FOC 控制**：TIM1 和 TIM8 各驱动一路电机，支持双电机对拖验证

- **电流采样对比实验**：电机 A 使用 STM32G474 内部 OPAMP PGA，电机 B 使用外部 RS624XQ 独立运放。同等条件下对比噪声和采样精度差异，评估片上模拟前端对 SMO/HFI 等无感算法的适用性

- **全链路算法验证平台**：为 SMO、ESO、HFI、参数辨识、死区补偿自学习等算法提供统一硬件底座

- **单板成本 ≤ 100 元**：除 MCU（HRTIM\+OPAMP 暂无国产替代）和磁编码器（精度优先）外，全链路国产芯片

### 1\.3 电流采样双路对比架构

**电机 A（内部 OPAMP PGA）**：

- 采样电阻 → 100Ω×2 \+ 4\.7nF 差分滤波 → STM32G4 内部 OPAMP

- PGA ×8, VREF = 1\.212V, 输出直入 ADC

**电机 B（外部 RS624XQ 运放）**：

- 采样电阻 → 100Ω×2 \+ 4\.7nF 差分滤波 → RS624XQ CH1\-3

- 增益 ×10 \(Rin=1kΩ, Rf=11kΩ\), VREF = 1\.65V \(CH4 跟随器\)

- 输出经 0Ω 跳线入 ADC

## 5\. 电流采样设计

### 5\.1 差分滤波器拓扑

六路差分滤波器统一拓扑：

```Plain Text
VINP ── 100Ω ──┬── 4.7nF ──┬── (1kΩ增益电阻，仅 RS624XQ) ── OPAMP IN+
                │           │
VINM0 ── 100Ω ──┘           └── (1kΩ) ── OPAMP IN−
```

**关键设计约束**：4\.7nF 跨接在滤波电阻和增益电阻之间。若跨接在增益电阻之后，截止频率从 169kHz 骤降至 15\.4kHz，20kHz 信号衰减 23%。

### 5\.2 截止频率与建立时间

- 内部 OPAMP：$R_{diff} = 200Ω$

- RS624XQ：$R_{diff} = 200Ω∥2kΩ≈182Ω$（增益电阻并联）

截止频率：
$f_c = \frac{1}{2πR_{diff}C} ≈ 169-186kHz$

建立时间：
$7τ = 7×R_{diff}×C ≈ 6.0-6.6μs$

|PWM 频率|可用建立时间|7τ|裕量|
|---|---|---|---|
|20kHz|25μs|6\.6μs|✅ 18\.4μs|
|40kHz|12\.5μs|6\.6μs|✅ 5\.9μs|

### 5\.3 运放配置

|运放|VREF|增益|输出范围 @±13\.4A|ADC 量程|反向极限|
|---|---|---|---|---|---|
|OPAMP1/3/4 \(内部 PGA\)|1\.212V|×8|0\.15V \~ 2\.28V|64%|−15\.15A|
|RS624XQ CH1\-3 \(外部\)|1\.65V|×10|0\.31V \~ 2\.99V|81%|−16\.5A|

### 5\.4 VREF 跟随器

RS624XQ CH4 配置为电压跟随器：

```Plain Text
AVCC(3.3V) → 1kΩ → 1N5536 → 1kΩ → AGND (中点=1.65V)
                                   ↓
                          CH4 +IN → CH4 OUT → CH4 −IN (直连，无电阻)
                                   ↓
                              1μF → AGND (稳定输出)
                                   ↓
                              100nF ×3 → CH1/2/3 VREF输入去耦
```

**设计要点**：

- 1kΩ 分压（非 10kΩ）：减小运放偏置电流导致的偏置误差（1μA × 500Ω = 0\.5mV）

- OUT → −IN 直连，不串电阻：电压跟随器全负反馈

- 三路 100nF 各自去耦：防止通道间 VREF 串扰

## 6\. 栅极驱动设计

### 6\.1 FD6288 连接

```Plain Text
MCU TIMx_CHx  → FD6288 HINx  (PWM输入)
MCU TIMx_CHxN → FD6288 LINx  (互补PWM)

FD6288 HOx → 10Ω → 1N5819(反并) → MOSFET G 极
FD6288 LOx → 10Ω → 1N5819(反并) → MOSFET G 极

MOSFET GS 间：10kΩ 泄放电阻（上电关断，防dV/dt误导通）
MOSFET GS 间：2nF 预留焊盘不焊（避免增加开关损耗）

自举：12V → 1N5819WS → VB1/VB2/VB3
自举电容：1μF ×6（VBx-VSx）
```

### 6\.2 栅极走线约束

|参数|值|依据|
|---|---|---|
|FD6288 → MOSFET 走线长度|≤ 15\-28mm|28mm 时尖峰 2\.7V，离 Miller 平台 \&gt; 5V|
|线宽|8mil|和普通信号区分，方便检查|
|走线层|TOP 或 L3（参考 L2 GND）|不跨功率铜皮，不和相铜皮平行|
|阻尼电阻|10Ω|ζ≈6\.5，过阻尼无振铃|

## 7\. 保护电路

### 7\.1 急停按键

|按键|引脚|刹车目标|机制|
|---|---|---|---|
|KEY1 \(E\-STOP A\)|PC14|TIM1 电机 A|EXTI 下降沿 → TIM1\-\&gt;BDTR|
|KEY2 \(E\-STOP B\)|PC15|TIM8 电机 B|EXTI 下降沿 → TIM8\-\&gt;BDTR|

硬件刹车寄存器操作，响应时间 \&lt; 50ns。

### 7\.2 BOOT0 状态机

```Plain Text
上电瞬间：VCC上升 → 100kΩ 拉高 NMOS 栅极 → NMOS导通 → PB8 拉低到GND
           → STM32 采样 BOOT0=0 → Flash 启动 ✅

程序运行：MX_GPIO_Init() → PC13输出0V → NMOS关断
           → PB8 被 I2C 上拉电阻拉到 3.3V → I2C 正常通信
```

**Option Byte 方案被否决原因**：全片擦除会将 nBOOT\_SEL 清零，导致 PB8 恢复为 BOOT0 功能，调试阶段不可控。

### 7\.3 过流保护策略

软件设 14A 过流阈值，在运放饱和前关 PWM。反向电流 ≤ −14A 时直接刹车。

### 7\.4 母线过压

TVS SMBJ48A 一次钳位。软件监测 DCBUS 电压（180kΩ\+10kΩ 分压进 ADC），Vbus \&gt; 55V 触发保护。

## 9\. PCB 层叠与布局

### 9\.1 层叠

|层|功率域|控制域|
|---|---|---|
|TOP|DCBUS 铜皮 \+ 相铜皮 \+ 局部 PGND|元件 \+ 走线 \+ GND|
|L1|完整 GND 平面|完整 GND 平面|
|L2|GND \+ 栅极驱动线 \+ 采样差分线|VCC 铺铜|
|BOTTOM|整张 PGND|GND \+ 走线|

### 9\.2 三地架构

- **GND（L1 整张）**：所有 MCU、运放、通信、数字外设的参考地。模拟区和数字区在 L1 上共享同一张铜皮但电流路径被布局自然分离

- **PGND（BOTTOM）**：功率回流专用。MOSFET 电流 → 采样电阻下端 → 过孔 → BOTTOM PGND → XT60 负极

- **单点汇接**：PGND 和 GND 在 DCBUS 电解电容负极处单点汇接

### 9\.3 布局关键规则

|规则|约束|
|---|---|
|功率回路面积|TOP DCBUS ↔ BOTTOM PGND 垂直紧耦合，板厚 0\.2mm 回路高度|
|栅极走线|FD6288 → MOSFET G 极 ≤ 28mm，不和相铜皮平行|
|电流采样差分对|两腿等长 ≤ 0\.5mm，走 L2/L3 参考 L2 GND，远离 SW 节点|
|MCU 下方 L2 GND|完整不割裂，过孔打在模拟区外围|
|开窗|DCBUS 铜排焊接区、三相飞线焊盘 Φ3\.5mm、测试点|

### 10\.3 运放噪声 RMS 计算公式

PWM 不输出时，ADC 连续采 1000 点，在 MCU 内计算标准差：

$σ = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(x_i - \bar{x})^2}$

12\-bit ADC，3\.3V 参考，1LSB = 0\.8mV。内部 OPAMP PGA 期望 \&lt; 5 LSB RMS，外部 RS624XQ 期望 \&lt; 8 LSB RMS。
