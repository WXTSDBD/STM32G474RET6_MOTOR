# 启动状态机方案 · 对齐→开环拖动→切闭环

> ③号 Sio-Analyze 输出 · 2026-06-19
> 目标：用最小电流（0.3-0.5A）让电机从静止可靠启动，再切回正常电流闭环

---

## 一、核心思路

不靠大电流硬推齿槽转矩——靠旋转磁场牵引转子。电流只维持磁场强度，转速由磁场的旋转速率决定。

**电流环在所有阶段都是闭环的。** 「开环拖动」的「开环」指 θ 的来源是软件斜坡而非编码器——Park/PI/SVPWM 照常闭环运行。

---

## 二、三阶段状态机

```
┌──────────┐     ┌──────────────────┐     ┌───────────────┐
│  ALIGN   │────→│  OPENLOOP_DRAG   │────→│  CLOSED_LOOP  │
│  对齐    │     │  开环拖动         │     │  闭环运行      │
│  100ms   │     │  1.5s             │     │  永久          │
└──────────┘     └──────────────────┘     └───────────────┘

θ 来源：固定0      θ 来源：软件斜坡        θ 来源：编码器
Iq_ref：0.3A       Iq_ref：0.5A            Iq_ref：目标值（斜坡过渡）
电流环：闭环      电流环：闭环             电流环：闭环
```

---

## 三、阶段 1：ALIGN（对齐）—— 100ms

### 目的

把转子拉到一个已知的、确定的位置——为开环拖动建立统一的起点。

### 物理

定子磁场固定在 θ=0（A 相轴线方向）。转子永磁体 d 轴被磁拉力拉向 θ=0。齿槽转矩在 θ=0 附近形成势阱——转子最终停在「磁拉力 + 齿槽力」的平衡点上。停稳，位置已知。

### 参数

| 参数 | 值 | 调法 |
|------|-----|------|
| θ 来源 | 固定 θ=0 | 不变 |
| Iq_ref | **0.3A** | 转子不归位 → 提到 0.5A |
| Id_ref | 0 | — |
| 持续时间 | **100ms**（2000 tick @ 20kHz） | 高惯性 → 延到 200ms |

### 电流环在此阶段的工作

- 采样 Ia/Ib/Ic → Clarke → Park(θ=0) → PI(Iq_ref=0.3) → SVPWM(θ=0)
- PI 把 Iq 精确控制在 0.3A——定子磁场稳定指向 θ=0，不抖
- 编码器在读但不用于 Park——只记录初始位置

---

## 四、阶段 2：OPENLOOP_DRAG（开环拖动）—— ~1.5s

### 目的

让磁场旋转起来，转子被磁拉力牵引同步旋转。转子从静止过渡到旋转——静摩擦被绕过，不需要大电流硬推。

### 物理

电角度 θ_openloop 以斜坡从 0 累加到高速——定子磁场开始旋转。转子永磁体被旋转磁场牵引，像同步电机一样跟随。只要磁场转得不太快（转子机械能跟上）、电流够维持磁场强度（0.5A）、负载不突变——转子就会同步跟随。

**如果磁场转太快 → 转子落后 >90° → 磁拉力变成阻力 → 丢步。** 斜坡速率由丢步检测保护。

### θ 的生成

```
每拍累加：θ_openloop += ω_el_target × 50µs
ω_el_target = 斜坡(0 → 220 rad/s)  ← 220 rad/s ≈ 300 rpm 机械
斜坡时长：1.5s（30000 tick）
```

ω_el_target 从 0 线性爬升到目标值——不是阶跃。阶跃 = 磁场瞬间要求转子跟上高速 = 必丢步。

### 电流环在此阶段的工作

- 采样 Ia/Ib/Ic → Clarke → Park(θ_openloop) → PI(Iq_ref=0.5) → SVPWM(θ_openloop)
- PI 仍然在闭环调节 Iq——只是 θ 来自软件斜坡而非编码器
- PI 不知道也不关心 θ 是哪来的——它只管把 Iq 调到 0.5A
- 编码器在读但不用于 Park——用于转速监测和丢步检测

### 参数

| 参数 | 值 | 调法 |
|------|-----|------|
| Iq_ref | **0.5A**（恒定） | 丢步 → 提到 0.8A；仍远低于 Iq Boost 的 3A |
| 斜坡目标转速 | **300 rpm** 机械（220 rad/s 电） | 丢步 → 降到 150 rpm |
| 斜坡时间 | **1.5s** | 丢步 → 延长到 2.5s |
| θ 来源 | 软件累加（不读编码器） | — |
| 丢步检测 | 编码器转速 < 50rpm 持续 500ms → 回 ALIGN | 误触发 → 延长到 1s |

### 丢步检测

编码器实时监测实际转速。如果磁场转了 1s 以上但实际转速 < 50rpm 持续 500ms → 判定丢步 → 自动跳回 ALIGN 阶段重来。重试时可以提高 Iq_ref 或降低斜坡速率。

---

## 五、阶段 3：CLOSED_LOOP（切闭环）—— 永久

### 切换条件

两个条件**同时满足**才切换：
1. 编码器实测转速 > 200 rpm 机械
2. 开环拖动已运行 > 1s（防止误触发）

### 切换瞬间——四件事原子完成

| 动作 | 原因 |
|------|------|
| θ 切回编码器 | θ_openloop → encoder_theta_el。这是切换的核心 |
| 积分器清零 | pi_id.integrator = 0; pi_iq.integrator = 0。θ 跳变会导致 Park 算出的 Id/Iq 瞬态异常——积分器不能带着旧误差进闭环 |
| Iq_ref 斜坡过渡 | 从 0.5A 线性过渡到 target_iq_ref（用户想要的最终电流），过渡时间 200ms。防止 Iq_ref 突变 |
| 状态锁定 | 进入 CLOSED_LOOP——此后 θ 永远来自编码器，启动状态机完成使命 |

### 为什么 Iq_ref 要斜坡过渡而不是直接跳

开环拖动时 Iq_ref=0.5A 维持了 1.5s，PI 积分器刚被清零。如果 Iq_ref 突然跳到 0.3A → error=0.7A 阶跃 → Kp 瞬态输出大 → Uq 突变 → 电机可能抖一下。斜坡 200ms 让 PI 平滑跟上。

### 电流环在此阶段的工作

- 正常电流闭环——θ 永远来自编码器
- Iq_ref = 最终目标值
- 状态机已完成使命——之后全部由 PI 自主调节

## 六、参数汇总

| 参数 | 默认值 | 作用阶段 | 调大 | 调小 |
|------|--------|----------|------|------|
| ALIGN Iq_ref | 0.3A | ALIGN | 对齐更有力 | 更省电 |
| ALIGN 时长 | 100ms | ALIGN | 高惯性负载对齐更稳 | 启动更快 |
| DRAG Iq_ref | 0.5A | OPENLOOP_DRAG | 磁场更强→不易丢步 | 更省电 |
| 斜坡目标转速 | 300 rpm | OPENLOOP_DRAG | 切换时转速更高 | 更不容易丢步 |
| 斜坡时间 | 1.5s | OPENLOOP_DRAG | 转子跟得更稳 | 启动更快 |
| 切闭环转速阈值 | 200 rpm | 切换条件 | 切换更安全 | 切换更早 |
| 切闭环 Iq 斜坡 | 200ms | CLOSED_LOOP | 过渡更平滑 | 响应更快 |
| 丢步检测阈值 | 50 rpm | 丢步检测 | 更敏感 | 更容忍 |

## 七、和 Iq Boost 方案的对比

| | Iq Boost | 对齐→开环拖动 |
|------|----------|---------------|
| 原理 | 大电流硬推齿槽 | 旋转磁场牵引转子 |
| 最小启动电流 | 2-3A | **0.3-0.5A** |
| 启动冲击 | 有脉冲 | 平滑无冲击 |
| 对齿槽大小依赖 | 高——必须碾过 | 无——磁场旋转就转 |
| 代码量 | ~5 行 | ~40 行（状态机） |
| 失败模式 | 推不过→加电流 | 丢步→回对齐重来 |
| 适用场景 | bringup 快速验证 | 规范交付·毕设·面试 |

## 八、风险与保护

| 风险 | 触发条件 | 保护措施 |
|------|----------|----------|
| 丢步 | 磁场转速 > 转子能跟上的速度 | 丢步检测 → 回 ALIGN 重试 |
| 切闭环电流冲击 | θ 跳变 + 积分器残留 | 清零积分器 + Iq_ref 斜坡过渡 |
| 对齐失败 | 负载转矩 > 对齐磁拉力 | ALIGN Iq_ref 提到 0.5A |
| 无限重试 | 参数不匹配致反复丢步 | 建议加最大重试次数（如 3 次）→ 报故障 |
| 切换瞬态编码器读数为坏值 | SPI 通信偶发错误 | 切换前验证编码器数据连续 3 拍有效 |

## 九、调试顺序

| 步骤 | 做什么 | 看什么 | 通过标准 |
|------|--------|--------|----------|
| 1 | 只跑 ALIGN | Iq 波形、θ_el 是否停在固定值 | Iq=0.3A 平稳，θ_el 不跳变 |
| 2 | ALIGN + DRAG（不限时，手动停止） | 编码器转速是否跟上斜坡 | 转速线性增长，不丢步 |
| 3 | ALIGN + DRAG + 切闭环 | 切换点 Iq/Uq 波形 | 切换无冲击，Iq 平稳过渡 |
| 4 | 全程 + 目标 Iq=0.3A | 全过程 Iq/Uq/转速 | 启动成功，Iq 稳在 0.3A |
