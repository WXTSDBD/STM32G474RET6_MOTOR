### 作业卡（固定 7 步）

| 步 | 动作 | 产出 |
|---|---|---|
| 1 | 从 `docs/宏归属表_2026-10-07.json` 生成《182 行 `#undef` 分类表》（**只读脚本**） | `docs/宏归属表_undef_classify_2026-10-07.*` |

| 4 | `.\tools\quickcheck.ps1 <改过的文件>`（若有） | 0 error / 0 warning |
| 5 | Keil **`-b` 或 `-r`** → 读 `rebuild_log.txt` 末尾 → **`0 Error(s)` 且 `0 Warning(s)`** | — |
| 6 | **比 `Code/RO/RW/ZI` 四数 + `hex.sha256`** | **四数+hex 逐字相同 → 档 1，不烧**；有差异 → **档 2，进烧录窗口**，一包一验 |
| 7 | 出包 `MDK-ARM/_pkg/<日期>_pkg8_2_undef_<批次>/` | hex + rebuild_log + size + sha256 + `bringup_active.h` + `profile` 快照 + **`git.txt`** |

### 停止条件（满足任一 → 停，报告主人）

1. 某 `#undef` 的"强制值"与《宏归属表》**不符**（表过期 → 先重跑 `macro_map.py`）；
2. 本批出现**生效值改变**（= 档 2）→ 转入烧录窗口，**不继续下一批**；
3. 同一处改 **3 轮** quickcheck 仍不过；
4. 需要动 profile / 热路径结构 / 生成文件 → **超出本刀范围，停**。
