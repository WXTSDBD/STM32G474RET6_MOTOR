## 1. 一句话

**经典 SMO + LPF + atan 旁路在本机上可复现地达不到软切门槛；偏置已准、差在角抖 → 角提取改 EMF-PLL，而不是继续调趋近律/K/SAT。**  
Veq+atan 仍是可用基线；PLL 优先挂在 Veq 的 `eαβ` 上验证。

---

## 2. 证据链（为何必须换 PLL）

### 2.1 三包把现象钉死

| @1000 rpm 长稳态 | Veq \|err\|p95 / 去偏抖 | SMO \|err\|p95 / 去偏抖 |
|------------------|-------------------------|-------------------------|
| 1956 / 2009 / 2012 | **~7.2° / ~7.0°** | **~23.3° / ~23.1°** |

- SMO **median ≈ −1°**（与 Veq 同一套 `θ_off≈−23.2°` 后已对准）  
- 失败不是“没锁上偏置”，而是 **抖约为 Veq 的 3×**  
- 400 rpm SMO p95 **~96°**（三包同），低速 SNR 更差  

→ 再录同配置包不会改变结论。

### 2.2 责任归属（不是趋近律背锅）

| 环节 | 现状 | 对失败的贡献 |
|------|------|----------------|
| 滑模/趋近（`K·sat`） | `K=20`, `sat=0.3` | 次要：影响 `z` 毛刺强弱 |
| LPF 抽 EMF | 200 Hz | 中等：压抖必加滞后 |
| **`atan2(e)` 取角** | 每拍直接当 θ̂ | **主因**：残抖原样进角度 |
| ISR/cycle | isr≈6000≪8500 | 基本无关（三包电流干净） |
| 电机模型 Rs/Ld | 与 Veq 共用 | 次要（Veq 已 PASS） |

同一套 atan，Veq 的 `e` 更干净故 PASS；SMO 的 `e` 带滑模残抖故 FAIL。  
**拧趋近律/K/LPF 无法把 SMO 拉到 Veq 同级**；需要 **用 PLL 对 `e`（或 `z`）鉴相积分** 代替裸 atan。

### 2.3 与早前脏包的关系

| 包 | 含义 |
|----|------|
| 1438 | 双观测时电流脏、isr 有尖峰 → 曾怀疑 SMO 拖垮 ISR |
| 1446 | 关 SMO 后干净，obs≈−700 cycle |
| **1956/2009/2012** | 双观测也可干净稳态 → **角质量问题与“是否超时”脱钩** |

ISR 优化/关 SMO 解决的是负载与质变；**角 PASS 只能靠换提取器**。

---

## 3. 决策

| 做 | 不做 |
|----|------|
| 上 **EMF 正交 PLL / Type-II**，输入优先用 **Veq `eαβ`** | 再指望经典 SMO+atan 过软切门槛 |
| 带宽：高于速度环（~20 Hz），远低于电流环；相对编码器测速 PLL（~80 Hz）先同量级试 | 把 θ̂_smo / θ̂_pll 在未 PASS 前送进 Park |
| 旁路对比编码器；多转速复测写报告 | 为写报告无对照地狂录同配置 |
| SMO 可保留旁路对照或日常关掉省 ~700 cycle | 把“再调 K”当主路径 |

PLL 设计口径（摘要）：

- 鉴相：\(\varepsilon = -e_\alpha\sin\hat\theta + e_\beta\cos\hat\theta\)（符号与现 `atan2(-eα,eβ)` 对齐）  
- 环：与现 `motor_pll` 同型 Type-II（`Kp=2ζωn`, `Ki=ωn²`），工作在 **电角** 域  
- 起点：`Fn≈80～100 Hz`，`ζ≈0.7`；跟踪不够再升，抖则降或做 `|e|` 归一  
- 尽量让 PLL 承担滤波，避免再叠死 200 Hz LPF
