# 录波分析

CSV 回到本地之后的流程。

## 1. 先确认是哪个文件

```powershell
rg --files "VOFA+CSV/20261006"
```

（换成当天日期。**不要递归扫全盘。**）

**问主人**：哪一个是金样？本次要看哪几个？不要自己挑。

## 2. 先弄清通道含义

```powershell
rg -n "^def |^class |ch|CH|layout" tools/vofa_layout.py
```

12 个通道分别是什么，**不要猜**。同一个实验不同轮次的通道布局可能不同。

## 3. 用现成的库，不要自己写解析

- `tools/vofa_io.py`
- `tools/vofa_layout.py`
- `tools/vofa_analyze_lib.py`

先看有什么现成函数：

```powershell
rg -n "^def " tools/vofa_io.py tools/vofa_analyze_lib.py
```

## 4. 脚本放哪

- 当天一次性分析 → `VOFA+CSV/<YYYYMMDD>/_analyze_<主题>.py`
- 产出（json / txt / 图）→ 同目录、同前缀
- 跨实验复用 → 才放 `tools/`

**禁止**在仓库根和 `MDK-ARM/` 根堆文件。

## 5. 先摆数字，再下结论

先报：区间、点数、每通道 min / max / 均值、超限点数。

**先出 `【事实】`，再写 `【推断】`。**

不要把"看着不对"当结论。

## 6. 报告格式

```
【数据】文件、通道、时间区间
【事实】min/max/均值/超限点……
【推断】……
【待验证】需要主人或台架确认的
```

## 7. 别做的事

- 不要为了让曲线好看去过分的滤波 / 裁剪（那是造假）
- 不要只报一个总结数字，把原始统计量一起给
- 不要假设 CSV 一定是 12 通道、一定是什么采样率
