## 2. 铁律

1. 按**符号 / 使能位**删，不按旧行号、不用 `deadmap.json` 当依据。
2. profile：**公共默认必须留**；外层链收成 **单一 141 块**；嵌套 OR 按 141 取值留下，其余支删净。禁止「只改 6 个 `==141` 字面量」。
3. **QKICK 不能按前缀铲**：可删的是使能=0 的族（pre_gate/start/crawl/speed/sweep/brake…）。  
   **神圣**：`AFTER_LOCK` / `THEN_HFI` 主干 + `QKICK_IQ_A` / `KICK_N` / `PRE_S` / `HOLD_S`。
4. 验收默认：Keil **Rebuild（`-r`）** 0E/0W + **`-dD`**（行级活宏）+ 涉及删宏定义时 **`-Wundef` 探针**（工程未开 `-Wundef`，Keil 0W 证不了未定义 `#if`）。刀 C 再加 **`-dM`** 对 `M1_HFI_*` / `M1_EMF_*` / `M1_SPEED_*`。
5. 基线 **现编现取**，不用 `build_log.txt`、不用会话口述旧 Size。
