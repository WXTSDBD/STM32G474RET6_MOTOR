# 编译验收

改完固件后的固定流程。**不许跳步。**

## 1. 先确认没有残留 Keil 实例

```powershell
Get-Process UV4 -ErrorAction SilentlyContinue
```

有输出 → **停下来报告主人**，不要起第二个。历史上曾连起 8 个 UV4 互相抢 obj。

## 2. 编译（默认增量）

```powershell
Set-Location "D:\stm32\STM32G474RET6_MOTOR\MDK-ARM"
Start-Process -FilePath "D:\keil5\UV4\UV4.exe" -ArgumentList '-b','D:\stm32\STM32G474RET6_MOTOR\MDK-ARM\STM32G474RET6_MOTOR.uvprojx','-o','D:\stm32\STM32G474RET6_MOTOR\MDK-ARM\rebuild_log.txt' -Wait -NoNewWindow
Get-Content "D:\stm32\STM32G474RET6_MOTOR\MDK-ARM\rebuild_log.txt" -Tail 8
```

- `-b` = 增量 Build；`-r` = 全量 Rebuild（**只在主人明确要求时用**）
- **禁止 `-j0`**（并行编译）
- 必须 `-Wait`，否则留下孤儿进程

## 3. 判据

`rebuild_log.txt` **末尾汇总**必须同时满足：

- `0 Error(s)`
- `0 Warning(s)`

中间 ArmClang 往 stderr 吐的抱怨**不算数**，只看末尾。

## 4. 不过怎么办

自己修 → 回第 2 步。

**修不过 3 轮就停下来问主人**，不要硬顶、不要反复改同一处猜。

## 5. 过了之后：交付可烧录包

放到 `MDK-ARM/_pkg/<日期>_<实验名>/`：

- `.hex`
- `rebuild_log.txt`
- size（`fromelf --text -z` 或工程自带）
- `sha256`
- 当时的 `bringup_active.h` 与 profile 快照

## 6. 然后停下，等 CSV

**先交付烧录包 → 主人上台架跑 → CSV 回到 `VOFA+CSV/<日期>/` → 才写分析脚本。**

不要催结果、不要假设马上有数据（台架实验有等待期）。

## 7. 回复主人

写：`Keil Rebuild: 0 Error(s), 0 Warning(s)`

未通过不得声称任务完成。

## 只改非固件时可跳过

仅动 `tools/*.py`、`docs/`、`.clinerules/` 且没碰固件 → 可跳过编译。
