## 1. 认可的门禁（自此作为过线标准）

| # | 门禁 | 阈值（本签收采用） | 1930 | 1931 |

| G1 | 编码器活 | POST 内 0.5 s 窗 enc 冻结比例 \<5% | 0% | 0% |
| G2 | PRE 准踢 | `pre_ok=1`（假锁门禁过）后才进 MEAS | 是 | 是 |
| G3 | 无 −Iq 刹车回摆 | MEAS 时长 ≈0.30 s；踢段无持续负 Iq | 0.30 s | 0.30 s |

**两靴均 PASS ⇒ 本关签收。**

辅助观察（不单独否决，但应记录）：LOG 段 Iq≈0；`Ud_pi≈0`（ID_PI_OFF）；POST `|ε|` 不长期钉 ±90°。

## 2. 何以至此（证据链，极简）

| 包 | 角色 | 结果 |
|----|------|------|
| 1802 C4k | 有刹车；PRE 曾 q 锁 | 踢后失败形态混杂 |
| 1857 C4n | PRE 门禁过；**有 −Iq 刹车** | 踢末尚可对齐，刹车回摆 → POST **~174°** |
| 1924 C4o | 关刹车试枪 | POST ~5–10°（时间线较碎） |
| **1930 / 1931** | **签收包** | 门禁全过；1931 时间线干净 |

根因收口：**踢 + decide 可用；−Iq 对称刹车在冻 θ̂ 窗口回摆，毁掉踢末对齐。** 对策是 C4o：踢完 `Iq=0` 滑行进 LOG/RUN。

保留能力：C4n 的 PRE 假锁门禁（`QKICK_PRE_GATE`）仍开在 C4o 上。

## 3. 本签收明确不包含

- 反极且踢不动时的 **翻 π 再踢**（产品完备项，未测/未做）  
- 过线后 **Iq 权威 / 速度环 ~100 rpm**（旧 S3c0a/C5 区）  
- **HFI↔SMO** 软切  
- ISR 深度减负（遥测已 D=8；PI 每拍复位等仍可后做）

## 4. 下一步（建议顺序，一枪一变量）

### 4.1 立刻（文档/基线）

1. 冻结 **GATE=29 C4o** 为静置捕获基线；回退点写进 `bringup_active.h` 注释。  
2. 新实验只许 **GATE≥30** 新开分支，禁止改 29 行为冒充复测。

### 4.2 下一枪技术（捕获→可用）

| 优先级 | 内容 | 目的 | 建议 |
|--------|------|------|------|
| **P0** | 过线后极小出力 / 质量限 Iq（对齐旧 C4 / C3b 精神） | 验证「咬住后」能否轻轻出力而不掉 q | **GATE=30 C4p**：C4o + FEED_A=**0.5 A**（HI=0）；一变量 |
| **P1** | 无运动 / 拒判 → 翻 π 再踢（限次） | 补 π 完备性（1930/31 未覆盖反极踢不动） | 新 GATE，勿与出力同枪 |
| **P2** | ~100 rpm 巡航（先低 HI） | 接回「捕获后巡航」 | 捕获门禁保持；只加速度环 |
| **P3** | HFI↔SMO | 产品中高速 | 须 P2 有稳定包 |

### 4.3 明确先不做

- 恢复 −Iq 对称刹车当默认（除非另做「刹车段跟 θ̂」专用枪）  
- 固定角补偿 / FORCE_PI 当产品路径  
- 未过 P0 就顶满 Iq 或开满速度环
