## 1. 一句话结论

在本机 **20 kHz 电流环**、堵转锁 θ=30°、死区 ON / LUT OFF、Id 轴 OFF-hi 扫频条件下：

| 角色 | 设计 `M1_PI_FC_HZ` | 实测 f−3dB | Mp | 判定 |
|------|-------------------|------------|-----|------|
| **日常推荐** | **1000** | ~2.1 kHz | ≈1.00 | 稳、与 7/7 一致 |
| **可用上限（偏稳）** | **1500** | **~3875 Hz** | **1.19** | 推荐工作点 |
| **踩线天花板** | **1600** | **~4057 Hz** | **1.30** | ≈ \(f_s/5\)，不建议默认 |
| **过线** | ≥1700 | ≥4.2 kHz | ≥1.44 | 相位余量耗尽，不可用 |

**平台硬上限**：可用闭环带宽约 **\(f_s/5 \approx 4.0\,\mathrm{kHz}\)**（以 Mp≤1.3、增益回 1 时相位未贴 −180° 为工程门槛）。  
**不要用** fc=2000 的 f−3dB≈4.7 kHz 当作“带宽能力”——那是欠阻尼超调后的虚假宽度。

高频等效纯延迟（f≥4 kHz 相位折合）跨设计 fc **自洽**：

\[
T_d=\frac{-\varphi-90^\circ}{360^\circ\,f}\approx 78\text{–}87\,\mu\mathrm{s}\ \approx\ 1.6\text{–}1.7\,T_s
\]

**Iq 对照（7/6–7/7，fc=1000，57 点）**：OFF-hi f−3dB **2128 ± 4 Hz**（0042/0044/0045），与 Id ~2060 Hz **同量级**。

### 3.1 读表规则

1. **签收带宽** = OFF-hi 的 f−3dB，不是设计 fc，也不是 OFF-lo。  
2. **可用上限** 同时看 **Mp** 与 **\|G\|→1 时的相位**：1500 档约 −162° @ 3.1 kHz；1600 档约 −178° @ 3.4 kHz（余量耗尽）。  
3. **Td** 只用 f≥4 kHz；中频相位含植物极点，不能拿来估延迟。  
4. **动态电感** 优先用 fc=1000、f3≈2.1 kHz 比例法：\(L_\mathrm{dyn}\approx L_\mathrm{static}\times f_c/f_{3}\approx 28\text{–}29\,\mu\mathrm{H}\)（Ld）。勿对 fc=500 或 ≥1500 盲目平均反推（弱环非理想 / 延迟抬升 f3 会扭曲 L）。

## 4. 多轮扫频说明（按时间线）

### 4.1 早期：配方定型（2026-07-06～07）

1. **48 点 / 到 1515 Hz / 50 ms**：高频 SNR 不够，−3 dB 不可测。  
2. **57 点 / 到 2559 Hz / ≥500 Hz 用 100 ms**：Iq 三联可重复完整滚降 → **Iq ≈ 2128 Hz**。  
3. **Id 对称扫**：→ **Id ≈ 2060 Hz**；确立「实测≈2×设计 fc（@1000）」与动态 L≪静态 LCR。

该阶段回答的是：**电流环有没有按设计工作、d/q 是否同量级**，尚未探 \(f_s/5\) 天花板。

### 4.2 抬增益探上限（2026-09-09）

同一配方，仅改 `M1_PI_FC_HZ`，频表延至 **69 点 / ~5150 Hz**：

| 轮次意图 | fc | 结论 |
|----------|-----|------|
| 复现基线 | 1000（69 点） | f3≈2137 Hz，与 7/7 一致；Td≈79.6 µs |
| 推荐档 | **1500** | f3≈3875，Mp=1.19，Td≈83 µs → **工程可用上限** |
| 夹 Mp=1.3 | **1600** | f3≈4057，Mp=1.30 → **\(f_s/5\) 踩线** |
| 过冲确认 | 1700 / 2000 | Mp 1.44 / 2.0 → 明确不可用 |
| 弱环对照 | 500 / 800 | f3/fc≈0.9 / 1.3；说明「低增益≠同样 2×」 |

重复性：主档三联 σ(f−3dB) 一般 **&lt;20 Hz**（1500/1600/800/500），可作为论文误差条。

### 4.3 为何 f3/fc 随 fc 变化？

| 区间 | 现象 | 解释（论文口径） |
|------|------|------------------|
| fc=500 | f3≈0.9 fc | 弱 Kp，R 带 / 逆变器非理想相对大；**不是**“软件优化坏了” |
| fc=800 | f3≈1.3 fc | 过渡 |
| fc=1000 | f3≈2.1 fc | 中等增益，动态 L≪静态 L → 实际带宽上冲 |
| fc≥1500 | f3 仍升，但 Mp↑、相位贴边 | 离散延迟 \(T_d\sim 1.6T_s\) 开始主导可用极限 |

**死区**：OFF-hi（1.25 A ±0.1 A）相电流很少过零，**不是死区主导**。低 fc 时若 lo 的 f3 **高于** hi，更不能用“过零死区主导”解释——应写弱环 + 工况/饱和电感差异。死区只作为小信号非线性次要项。

## 5. 对控制器整定的直接含义

```text
产品 / 日常默认：   M1_PI_FC_HZ = 1000   （稳，Mp≈1）
需要更宽电流环：   M1_PI_FC_HZ = 1500   （推荐上限工作点）
论文写天花板：     ≈ fs/5 ≈ 4.0 kHz     （对应 fc≈1600、Mp≈1.3）
禁止当作可用：     fc ≥ 1700            （过冲与相位余量）
```

1. **电流环是外环的硬顶**：速度/位置环带宽必须远低于实测电流环可用带宽（建议再留裕量，日常按 1–2 kHz 电流环能力规划外环）。  
2. **Kp 仍按静态 L×ωc 写代码**；带宽“偏宽”来自动态 L 偏小，属植物特性，不是再盲目加 fc 去“吃满 4.7 kHz”。  
3. **延迟预算**：建模/离散化应计入 **~80–85 µs** 等效延迟（约 1.6–1.7 拍），与 fc 几乎无关——这是平台常数，不是某次扫频噪声。

## 8. 结论（可直接进论文）

本平台在 20 kHz 采样下，Id/Iq 电流环闭环 Bode 多轮扫频表明：

1. **fc=1000** 时实测 −3 dB 约 **2.0–2.1 kHz**（d/q 同量级），对应动态电感约 **Ld≈29 µH、Lq≈41 µH**，显著小于静态 LCR。  
2. 抬高设计带宽后，可用闭环带宽上限约 **\(f_s/5\approx 4\,\mathrm{kHz}\)**：以 **fc=1500（≈3.9 kHz，Mp≈1.19）** 为推荐工作点，**fc=1600（≈4.1 kHz，Mp≈1.30）** 为踩线天花板。  
3. 更高 fc（1700/2000）虽仍给出更大的 −3 dB 数字，但 **Mp 与相位余量** 已不可接受，不能作为控制器能力。  
4. 高频相位折合延迟 **\(T_d\approx 1.6\text{–}1.7\,T_s\)**，跨多档 fc 重复一致，是离散电流环的平台上限机制之一。  

本文档为后续电流环改增益、外环设计与论文实验章的**唯一总参考**；分档细节以各验收报告为准。
