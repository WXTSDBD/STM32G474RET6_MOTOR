# 报告：为何「到 300 行、一编进 400 就在 100 失锁」——根因收口（2026-09-29）

## 0. 一句话

> **不是数字 400 有仇，也不是 400 rpm 物理转不动。**  
> 旧失败（1942 / 1959）是因为把多档转速写进 **FOC 每拍都跑的 `get_speed_ref`**（浮点 if 链 / 查表+optnone），加第四档会 **重写这段热路径机器码**。  
> 现行「变量阶梯」下，MAX=300 与 MAX=400 的整图 **Code 同为 56284**；`hfi_sqwave.o` 只差 **3 个字节**：`run_total` 21→28、封顶比较量 300.5→400.5。  
> **取速函数与 PLL/`on_current` 机器码完全相同。** 在 100 rpm 时段，两条固件控制行为应无差别。

---

## 1. 证据链（台架）

| 包 | 写法 | 上限 | 100 rpm |
|----|------|------|---------|
| 1948 | s2d+ext if | 只到 300 | **PASS** |
| 1942 | 同函数堆 if 含 400 | 到 400 | **FAIL**（指令仍 100） |
| 1959 | 查表+optnone 含 400 | 到 400 | **FAIL**（更惨，每拍 VDIV） |
| 2007 | `s_run_rpm_cmd` 变量 | 只到 300 | **PASS**（三档丝滑） |

共同点：凡在 **热路径** 里「多露出一档 400」就挂；改成 **慢路径改变量** 后到 300 恢复。

---

## 2. 现行源码里 MAX 只用在哪

`GATE=51`：

1. `hfi_run_speed_ref_rpm()` → **只** `return s_run_rpm_cmd;`（与 MAX 无关）  
2. `hfi_run_rpm_cmd_step()` → 每满 7 s 才用 `MAX+0.5` 决定是否 `+=100`  
3. `hfi_run_total_s()` → 档数×7 s（300→21 s，400→28 s），只影响何时 DONE  

进 RUN 后前 7 s：`s_run_rpm_cmd=100`，step 未触发，**读不到 MAX**。

---

## 3. A/B 实编（只改 `M1_HFI_RUN_RPM_MAX` 300↔400）

| 项 | MAX=300 | MAX=400 |
|----|---------|---------|
| Program Code | 56284 | **56284（相同）** |
| `hfi_sqwave.o` 大小 | 47960 | **47960** |
| `.o` 相异字节 | — | **恰好 3** |
| `get_speed_ref` | — | **指令级相同** |
| `on_current`（PLL） | — | **指令级相同** |
| `on_angle` 差异 | `VMOV #21`；字面量 `300.5` | `VMOV #28`；字面量 `400.5` |

三字节含义：

1. `eeb30a05` → `eeb30a0c`：`21.0f` → `28.0f`（RUN 总时长）  
2–3. 字面量 `0x43964000`（300.5）→ `0x43c84000`（400.5）（加档封顶）

快照：`MDK-ARM/_abin_cmp/C_max300.*`、`C_max400.*`。

## 4. 根因表述（分级）

### 已钉死

1. **失败模式** = θ̂ 掉到 ~−90°、Iq 顶满、轴正反抽；**不是** MCU 死机、不是指令误成 400。  
2. **不是** Flash 体积（旧 +24 B；现 Code 零差）。  
3. **不是** RUN 总时长本身（100 rpm 在 t=0，碰不到 DONE）。  
4. **不是** 「400 rpm 工况」：旧挂枪根本没跑到 400。  
5. 现行架构下 **MAX=400 不会改 100 rpm 的取速/PLL 机器码**。

### 旧枪（1942/1959）的直接原因

把 100/200/300/**400** 编进 **每拍调用** 的转速指令函数：

- if 链：编译器内联成交错 `VCMPE`/`IT`，加档就重排整函数（含前两档路径的寄存器安排）。  
- 查表+`optnone`：独立函数但 **每拍 VDIV+大量栈**，热路径更重，仍 FAIL。

相关变量 = **热路径代码形态被加档改变**；不是常量数值 400。

### 仍不必再找的

「400.0f 与别处 400 宏撞车」：图中本就有 `POS_OMEGA_MAX`/`NOTCH` 等 400 常量；MAX=300 的 2007 也能跑，说明 **多一个 400 字面量本身无害**。

---

## 5. 结论与用法

| 问题 | 答案 |
|------|------|
| 300 可以 400 不行？ | **旧写法下的表象**；根因是热路径被重写。 |
| 400 有仇？ | **无。** |
| 现在怎么加到 400？ | 只改 `M1_HFI_RUN_RPM_MAX`；保持 `s_run_rpm_cmd`。 |
| 如何验收？ | 烧现行 MAX=400，看 100 rpm 是否仍如 2007；再看 400 档跟随。 |

---

## 6. 现行固件

- `M1_HFI_GATE=51`，`RUN_RPM_MAX=400`，每档 7 s（100→200→300→400）  
- Keil：`0 Error(s)`，Code=56284（与 MAX=300 同码量）
