## 0. 一句话

> HFI 的成败不在「公式」，而在 **注入、解调、电流环三者是否共用同一条被 PI 掐到零的 Id**。
> 正确做法是三条同时成立：**Vh 在电流环之后沿 θ̂ 叠到 αβ** → **解调吃注入轴 iαβ 的半周 Δi（不吃 Park 出来的 Id）** → **Id*=0 的 PI 从 HFI 第一拍就常开**。
> 再补两条才能接中高速：**u_hfi 电压单独记账**（SMO/磁链只用 u−u_hfi）、**切角用「两角近 + 速度滞回」而不是「转速到了」**。

`【事实】` 现行 GATE141 已把前三条打开（`M1_HFI_INJECT_POST_LOOP=1`、`M1_HFI_DEMOD_INJ_AXIS=1`、`M1_HFI_ID_ON_FROM_RUN_ENABLE=1`），第 4 条打开（`M1_HFI_SMO_SUB_VH_ENABLE=1`），第 5 条部分打开（`hfi_pub.c` 里有两角 + 速度滞回 + 融合）。**本文的价值是：把「已经长成什么样」和「还差什么、参数该怎么定」写清楚，避免下一轮又从「调 atan2 的 HP/LPF/顺序」开始拧。**

## 读法先讲：现行实现（GATE141）的逻辑

> 这一节只讲**它怎么跑、为什么这么跑**，不列代码位置。要找函数/宏的落点，看 §10。

### A. 它在这个系统里是什么角色

HFI 是**零速与低速的角/速源**。对外只给三样东西：

1. **Park 角 θ̂** —— 电流环把三相电流旋到哪个坐标系，由它决定；
2. **转子速度 ω** —— 就是锁相环的输出；低速段它同时是速度环的反馈；
3. **「这个角现在能不能信」** —— 由解调质量实时判断，不是靠转速门限。

它上下接两条线：

- **下面**：电流环 + SVPWM —— 它往电压里加载波、从电流里取信息；
- **旁边**：中高速观测（SMO 反电势 → EMF-PLL）—— 两者**并行**跑，由一个「发布器」决定当前发谁的角度、以及还要不要继续加载波。

编码器在这条链里**只是老师**：不喂 HFI 速度前馈、不参与 HFI 的角度推进、不参与 HFI 的积分。它只用于台架真值，以及踢段那一下的位移判决。这就是「产品钟不吃编码器」的落地方式。

### B. 一次上电之后，它按这个顺序跑

1. **IDLE（约 5 s）**：不注入、不输出角、电压给 0。目的是让母线、采样、编码器通信先稳；同时把电流 PI 的积分从「上电残留」里清出来 —— 否则进 RUN 第一拍会带出十几伏的假 Ud，把 HFI 打乱。θ̂ 归 0，PLL 积分归 0。
2. **进 RUN，立刻开始注入**：沿当前 θ̂ 叠 10 kHz、0.40 V 的方波。此时**不出力矩**（Iq 给定 0），θ̂ 也只是从 0 起步。
3. **头 2 s 是「允许收敛」的窗口**：每拍都解调 + 更新 θ̂，让它自己往凸极轴上靠。不出力，避免「角还没对就使力」。
4. **踢一下，解决 180° 模糊**：凸极只告诉你「轴在哪」，不告诉你「哪头是 N」。所以在估计出的轴上打一个 1.6 A、300 ms 的 q 轴电流脉冲，看转子往哪边动：
   - 估计的是真 d 轴 → 有力矩、转子转；
   - 估计的是 q 轴（差 180°）→ 几乎不动或反着动。
   判决出 +1 / −1 / 0（没动），据此决定要不要把 θ̂ 翻 180°，并把踢期间因「冻角」落下的位移补回去。
5. **踢后静置 0.4 s 再锁一次**：清 Iq、清电流 PI、清 PLL 积分，在**无外力矩、转子静止**的条件下重新收敛。这一步是「确认踢没有把角带跑」。
6. **回到 RUN，这次不再踢**：速度环接管，速度反馈用 HFI 的 ω，按「±1500 rpm、每档保持 0.5 s、正反共 5 轮」的序列跑（141 的验收工况）。
7. **转速起来后交给中高速观测**：EMF-PLL 稳定之后，发布器开始比对两者 —— 速度到了、两角接近、两速接近，才把 Park 角在 20 ms 内**线性融合**过去；再高一点就把载波幅值收到 0。转速掉下来，重新回到 HFI 并重开载波。

### C. 每一拍（50 µs）到底在算什么

核心一句话：**用「上一个半周打出去的电压」和「这一个半周读回来的电流」，反推我现在的角差多少**。下面按逻辑展开 9 步（与 §3.1 的动作主线是同一件事，这里侧重「为什么」，落点见 §3.2）：

1. **Park 用上一拍的 θ̂**。先用它把三相电流旋到 dq 给电流环；同一拍的解调也建立在这个坐标系上。θ̂ 的更新发生在本拍后半段，所以「电流是上一拍的角度造成的」这个因果顺序是自洽的。
2. **载波符号每拍翻转**。本拍 +Vh、下拍 −Vh，方向沿 θ̂。电机看到的是 10 kHz、沿估计 d 轴来回的方波电压。翻转的同时把**本拍**的符号锁存下来，供注入使用。
3. **电流为什么携带位置信息**。d 轴上的电压产生的电流变化率是 `Vh/L`，而 `L` 取决于「这个电压方向相对转子磁极是 d 还是 q」：d 方向电感小 → 电流涨得快；q 方向电感大 → 涨得慢。于是电流对半周方波的响应幅度和方向，就编码了「θ̂ 距真 d 轴差多少」。
4. **配对差分**。把本拍电流与上一拍电流**投到同一根轴**（打出那段电压时的 θ̂）上相减，得 `Δi_d`、`Δi_q`。投到同一根轴是关键：两个样本若投到不同轴，差分里会混进「轴自己在转」的假信号。
5. **符号还原**。Δi 是在一个符号已知的半周里产生的，乘回那个符号，交替的载波就被搬到直流；否则正负半周会互相抵消。结果记作 `x`、`y`。
6. **扣慢分量**。`x`、`y` 里除载波外还混着基波与负载引起的缓慢变化；用一个慢估计逐拍跟随并减掉，只留高频那部分。
7. **对向量低通，不对角度低通**。对 `x`、`y` 各自做低通。这一条很关键：如果反过来对「角度」低通，±π 处的支割会把左右抹平，使「锁在 q 轴」这种假锁看起来和真锁一样安静。
8. **取角（两种等价读法）**。手里的 `(x, y)` 就是「角差的二维表示」，画出来是以 `(A, 0)` 为圆心的椭圆：`x = A + B·cos2δ`、`y = C·sin2δ`（δ 为角差）。
   - **`ε = ½·atan2(y, x − A_est)`**：直接解出角差再折半。它需要知道圆心 A 在哪，对圆心漂移敏感 —— 主要用来**看「盆地」形状、做质量门、遥测**。
   - **`e = SIGN·(y/Ts) / (Vh·(1/Lq − 1/Ld))`**（141 里 `SIGN=−1`），再限幅 ±0.30：只用 `y`。因为 `y = C·sin2δ`，角差小的时候 `y` 正比于角差，归一化后天然就是一个「角差」量。它不需要知道 A，所以**闭环喂 PLL 用它**：圆心漂移不会把闭环带偏。
9. **锁相环更新**。`ω = Kp·e + ω_est`，`θ̂ += ω·Ts`，其中 `ω_est` 用一阶泄漏积分慢慢跟随 `ω`。逻辑上是「用角差修正速度估计，再把速度估计积成角」：慢的那路负责长期跟住转子转速，快的那路 `Kp·e` 负责把角拉回来。

另外两条配套逻辑：**误差必须限幅**（否则一次坏采样 —— 比如踢段刚结束、或辨识正在跑 —— 会把 ω 打飞）；**积分可选死区**（防止极小的漏解调被慢慢积出一个假转速 —— 台架上见过「ε≈0.01 积出十几 rpm」）。

### D. 「这个角能不能信」是怎么判断的

不用编码器、也不用转速门限，而是**用解调结果自己判断**：

- 锁准了：角差趋于 0 → `cos2δ→1` → `x` 稳定在圆心附近；
- 锁到 q 轴了：角差趋于 ±90° → `cos2δ→−1` → `x` 掉到 `A−B` 附近，**同时 ε 也很小**。

所以「`x` 高」是好的指纹；「`x` 低且 ε 小」是最危险的状态 —— **它看起来最安静，实际是假锁**。

据此生成一个 **Iq 天花板**：

- `x` 连续足够好 → 允许速度环出全部 Iq；
- `x` 掉下去且 ε 也小 → 判假锁，**把天花板拉到 0**，不给它力矩；
- 中间带保持；天花板升降有斜率限制，防止边缘抖动凑数。

这条逻辑的意义是：**在角度被证明可信之前，不允许用这个角度输出力矩**。否则就是「用错的角使力 → 转子被拽到错的位置 → 角看起来更对」的自锁（1305 那包 FAIL 的机理）。

### E. 什么时候注入、什么时候不注入

- HFI 阶段：一直注入（静止、踢段、静置都注入）。
- 融合到中高速观测之后：还多注入一小段，观察两边角是否一致。
- 转速到更高一档且融合已完成：把载波幅值收到 0。
- 转速掉回下一档：重开载波。

要点：**「关载波」和「换角度」是两件独立的事**，各有独立门槛与回滞。

- 换角度看的是「两个角实际有多接近」（角差 + 速度差，连续满足一小段时间才换）；
- 开关载波看的是「转速到没到」。

两者分开的好处是：关载波时**电流环坐标系不变**，只是把调制幅值设成 0，没有「某一刻突然改了环」的冲击。这就是 VESC 范式里「只调度载波与发布角、不改电流环坐标系」那一点。

### F. 与中高速观测的并行关系

- SMO 从 HFI 阶段起就**一直在跑**，不是等切过去才启动。
- 但它拿到的电压是「**扣掉载波之后剩下的基波**」。不这么做，SMO 会把 10 kHz 方波当成基波电压，低速/减速时乱锁。
- EMF-PLL 吃 SMO 的反电势，输出自己的角与速。
- 发布器拿 HFI 的 θ̂ 与中高速的角/速做比较，决定当前发布谁。
- 结果是一条链：**零/低速 HFI → 重叠区融合 → 中高速 EMF-PLL**，外环只看到「一个角、一个速」。

### G. 这套逻辑里「刻意没做」的事（也是设计的一部分）

- 不拿编码器速度做 HFI 前馈 —— 否则 HFI 是在抄答案，掩盖真正的锁相能力。
- 不在切换瞬间突然放开 Id 环 —— 那等于同时改调节器与对象，会失步。
- 不因为「转速到了」就换角 —— 必须两个角实际接近。
- 静置锁相期间不出大力矩 —— 先证明角对，再给力。
- 不用「把偏差写进 Park 角」补偿负载 —— 那是失锁的表现，不是负载凸极。

## 1. 为什么「方波强行注入 + 吃 Id 解调」效果差

这不是口味问题，是一条因果链。`【事实】`见 10/3 对照报告 §2.1。

```
SMO 是反电势观测，可观性 ∝ |ω|·λ
  → 减速到低速不进可观区，必须保留持续激励
  → 保留 Vh：把 ±Vh 当电压扰动一直叠在桥上
  → Vh 是电压扰动，必须与基波电流环共存
  → 共存的条件：基波 Id*=0 且 Id PI 常开（不能「进交接那一拍才合上」）
  → Id PI 常开会把「吃 Id 的解调」掐掉
  → 必须把解调从 Id 上搬走（环后注入 + 注入轴 iαβ 解调）
```

### 1.1 旧实现的三个结构性缺陷

| 编号 | 缺陷 | 后果 | 台架证据 `【事实】` |
|------|------|------|--------------------|
| D1 | 注入叠在 `ud`（环内、PI 之后但仍进 PI 的坐标系） | Vh 被 Id PI 当成误差去抵消；PI 与被观测的 Id 抢同一条电流 | 关环 `\|θ_err\|≈0.03 rad`（Id 旁路）；开环 FEED 0.8 A 且 Id PI 开 → `\|θ_err\|≈1.25 rad`（GATE84 / `1225`）**差一个数量级** |
| D2 | 解调吃 `id[k]−id[k−1]`（PI 正在调的那条 Id） | 观测与调节代数对立；FEED 上 Iq 后 `\|di_q\|` 被压、ε 塌 | GATE89（连 LOG/踢都不旁路）→ `\|θ_err\|≈2.14 rad`，比 84 更差 |
| D3 | 交接当「事件」：灭 Vh → 切角 → 突然放行 Id PI | 混合系统切换，积分与植物同时变，失步塌速 | IDUP（58/62/64）**塌速否决**；72/91/92 的 1500 rpm 加速**建立在 Id 旁路上**，不能当作「Id=0 HFI 已完成」 |

## 2. 原理与符号约定（写代码前必须钉死）

这一节是**唯一的口径**。代码里所有 `x/y/ε/A/B/C/δ/δ′` 都按这里定义，任何一处不一致都会静默出错。

### 2.1 电机模型（凸极）

dq 系（d 轴 = 转子磁极 N 方向），高频段（`ωh ≫ ωe`、`Rs` 可忽略）：`u_h ≈ L·di/dt`，
即 **d 轴电压只看见 `Ld`，q 轴电压只看见 `Lq`**。这就是凸极可观测的全部依据。
本电机内嵌式 `Ld<Lq`：**d 轴电感小 → 同样电压下 d 轴电流斜率大**。

### 2.2 注入（脉振方波）

- 频率 `fh = 10 kHz = fs/2`，**每拍翻极性**（`s_sign = -s_sign`，`hfi_sqwave.c:1269`）。
- 幅值 `Vh`（141：0.40 V）。
- 方向：沿**估计 d 轴** `θ̂`。
- 极性：`s_vh_sign` 每半周固定一次，**注入用它、解调也用同一路**（`hfi_sqwave.c:906`；`get_inj_ab` 用 `s_vh_sign`，`hfi_sqwave.c:1766-1768`）。

**目标实现是环后注入**（`M1_HFI_INJECT_POST_LOOP=1`）：

```
ud_pi, uq_pi  ← 电流 PI 输出（基波）
uα_fund = ud_pi·cos θ_park − uq_pi·sin θ_park
uβ_fund = ud_pi·sin θ_park + uq_pi·cos θ_park
u_hfi_α = s_vh_sign · Vh · cos θ̂
u_hfi_β = s_vh_sign · Vh · sin θ̂
uα = uα_fund + u_hfi_α
uβ = uβ_fund + u_hfi_β
SVPWM(uα, uβ)
```

落点：`motor/motor_current.c:1656-1699`（`s_m1_inj->get_inj_ab` 取 ±Vh，旋回本拍 Park 帧后加到 `ud_out/uq_out`），同时记下 `ua_hfi/ub_hfi`。

`【事实】` 141 下 `hfi_sqwave_get_inj()`（dq 注入口）**恒返回 0**（`hfi_sqwave.c:1745-1754`），注入只走 `get_inj_ab`。

### 2.3 解调（半周差分）

注入方波在同一根轴上正负交替，对「一个半周」的电流增量做**带符号**处理，即可把载波搬到直流：

```
prev_sign = 该 Δi 所在半周的注入符号（= −s_sign，见 §3 时序说明）
Δi_d      = i_d(k) − i_d(k−1)
Δi_q      = i_q(k) − i_q(k−1)
x_raw     = XY_X_SIGN · prev_sign · Δi_d
y_raw     = XY_Y_SIGN · prev_sign · Δi_q
```

- **目标实现里 `i_d/i_q` 不是 Park 的输出，而是「把 iαβ 投到注入轴 θ̂ 上」**（`M1_HFI_DEMOD_INJ_AXIS=1`，`hfi_sqwave.c:1097-1140`）。这样 Id PI 开多大都不影响解调。
- 两个电流样本（k 与 k−1）**必须投到同一根轴**：`hfi_sqwave.c:1102-1113` 就是干这件事——本拍入口先存下"上一拍的 θ̂ 与 iαβ"，本拍再算差分。
- 慢分量扣除：`s_id_inj_slow += M1_HFI_DEMOD_HP_A·(x − slow)` 再相减（`hfi_sqwave.c:1144-1155`）。**踢段（MEAS）不做这一步**，因为踢段要看真 Δi。
- LPF：`s_x_lp += a·(x_raw − s_x_lp)`，`a = 0.05`（`hfi_sqwave.c:1183-1184`）。**先滤向量、再取角**：对 `x/y` 各自滤波而不是对 `ε` 滤波，避免 `±π` 支割把 ±90° 抹平。

### 2.4 2δ 模型（这是「为什么能锁」的全部）

设 `δ = θ̂ − θ_d`（`θ_d` = 真 d 轴电角），理想点机下：

```
x ≈ A + B·cos 2δ
y ≈ C·sin 2δ
A  = Vh·Ts·(1/Ld + 1/Lq)/2       // 与位置无关的椭圆圆心
B  = Vh·Ts·(1/Ld − 1/Lq)/2 > 0   // 凸极项（Ld<Lq）
C  ≈ ±B                          // 实际因交叉耦合、采样相位，|C|≠|B|
```

- `【事实】` 实测 `A_fit≈0.238`、`|B|≈0.044`、极值比 `(A+|B|)/(A−|B|)≈1.47`，与 `Ld/Lq` 自洽。
- 真实 `A` 随电流、死区、母线漂；**闭环时圆心 ≠ 开环 A**（9/30 把 `A_cmd` 从开环 0.238 改到闭环圆心 **0.216**；141 profile 暂写 `0.10`，见 §5.3）。
- 相位 `φ`：若实测峰不在 0°，写 `x ≈ A + B1·cos2δ + B2·sin2δ`、`y ≈ C1·cos2δ + C2·sin2δ`，`φ = −½atan2(B2,B1)`；对齐到 `δ′ = δ + φ` 后再用决策表。残差门槛：`RMS(x−x̂) ≤ 0.10|B|`、`RMS(y−ŷ) ≤ 0.10|C|`；爆了说明不是 2δ。

### 2.5 两种角误差，别混

**（a）atan2 型**（遥测 / PRE 门禁 / AUTH 用）

```
ε = ½ · atan2(y_lp, x_lp − A_cmd)          // hfi_sqwave.c:1185
```

**（b）VESC V4 型**（真正喂 PLL 的那条，141 已开）

```
e = SIGN · (y_raw / Ts) / ( Vh · (1/Lq − 1/Ld) )     再 clamp(±MAX_ERR)
```

落点：`motor/motor_math.h:71`（纯函数 `motor_vesc_ang_err`）+ `hfi_sqwave.c:814-826`（`hfi_vesc_ang_err`，`Vh` 有 0.05 V 下限保护）。

- 归一化后 `e` **无量纲**：`(A/s) / (V·1/H) = 1`，所以 `Kp=1200` 乘上去直接得 `rad/s`。
- 好处：**不依赖 `A_cmd`**。`x` 的圆心漂移不再影响鉴相，只用 `y`（`sin2δ` 那一路）。
- 141 参数：`M1_HFI_PLL_VESC_ERR_ENABLE=1`、`MAX_ERR=0.30`、`ERR_SIGN=−1`（与 `XY_*_SIGN=−1` 配套）。
- 141 里 `ε`（atan2）仍算、仍上遥测、仍给 PRE/AUTH（`hfi_sqwave.c:1196-1197`）。

### 2.6 PLL（141 实际长什么样，别照抄教科书）

```
ω  = Kp · e + s_pll_int                  // 141: Kp = 1200
s_pll_int = s_speed_est                  // "积分"= 上一拍转速估计
s_speed_est += 0.01 · (ω − s_speed_est)  // VESC UTILS_LP_FAST(0.01)
θ̂ += ω · Ts
```

落点：`hfi_sqwave.c:1215-1222`、`1249-1250`。

- `【事实】` **主环不是标称 Type-II**：`M1_HFI_PLL_KI=389` 只给影子 PLL 用（`hfi_sqwave.c:1242`）；主环的"积分"是 α=0.01 的一阶泄漏积分，等效时间常数 `100·Ts = 5 ms`。**写成 Type-II 反而要重新标一次增益，不划算。**
- `s_pll_int` 是**对外发布的速度**（`hfi_sqwave_get_pll_int_el`，`observer_composite.c:75`），也是低速段速度环反馈（`motor_current.c:912`）。
- 限幅：`M1_HFI_PLL_W_MAX=200 rad/s`、`M1_HFI_PLL_INT_MAX=200`。
- `ω_ff` 恒 0：`w_ff = 0.0f`（`hfi_sqwave.c:1219`）、`M1_HFI_OMEGA_FF_SRC=0`（profile:129）、`motor_current.c:1515` 每拍写 0。**这是反作弊红线。**

### 2.7 极性（π 模糊）与稳定点判据

- 2θ 只能定到 **180°**：`x = A+Bcos2δ`、`y = Csin2δ` 对 `δ→δ+π` 不变。**π 极性必须另有机制**：q 踢（141：1.6 A × 300 ms，`profile:208-213`）+ 编码器位移判决 `s_qk_verdict`（`hfi_sqwave.c:1436-1499`）。
- 稳定点判据（`B>0, C<0`，9/15 §4 包 2）：
  - **充要（单边）**：`A_cmd < A + B` → 唯一稳定点 = 峰值轴（真 d）；`A_cmd ≥ A+B` → 无平衡点，ε 不过零、积分绕圈。
  - `|A_cmd − A| < |B|` 只是**充分条件**，不要当充要，也不要把「A_cmd 偏小」写成"90° 假锁"。
  - `±90°` 结构上永远不是吸引子（要成吸引子需 `A_e<B`，要成平衡点需 `A_e>B`，互斥）。
- 所以 **`A_cmd` 只剩两处用途**：`ε` 的零点（atan2 型）与 AUTH 的 x 门限；VESC 型误差不吃它。

### 2.8 符号决策表（翻哪一路，必须离线定）

`dε/dδ′ = B·C / (B²cos²2δ′ + C²sin²2δ′)`，符号恒等于 `sign(B·C)`。

| B | C | \|x\|峰值 | 含义 | 动作 |
|---|---|-----------|------|------|
| + | − | 0° | 理想 | 不动 |
| + | + | 0° | q 通道反号 | **翻 y**（`XY_Y_SIGN` 取反） |
| − | − | 0° | d 通道反号 | **翻 x** |
| − | + | 0° | 整体反号 | **翻 x 和 y**（141 就是这一行，两个都是 −1） |
| − | + | ±90° | 编码器/标签差 90° | **停**，重定标签（仍禁动 encoder offset，先查污染） |

- 改符号**必须改落盘通道（`XY_X_SIGN/XY_Y_SIGN`）**，不许只改 `ε` 的号（`M1_HFI_EPS_SIGN`）。
- `sign(C) = −sign(B)` **不是** pass/fail 门禁，只是可信度 + 决策表输入。

## 3. HFI 实现逻辑（现状：每一拍在算什么、为什么这么算）

HFI 有一半 bug 来自**逻辑/顺序**，不是公式。3.1 先把一拍内的逻辑讲通（不看代码也能懂）；3.2 给出与代码一一对应的动作清单；3.3 是三条最容易踩的时序规则。起动时序、锁相判别、何时注入、交接、与中高速的并行关系，在〈读法先讲〉的 §B/§D/§E/§F 已讲，这里不重复。

### 3.1 一拍内到底发生了什么（逻辑主线）

HFI 在 20 kHz 上只做四件事：**打电压 → 看电流 → 算误差 → 推角度**。逻辑顺序如下：

1. **先由阶段机决定「这一拍该不该打、怎么打」。**
   每拍开头推进 HFI 的阶段与计时，据此确定：注入开/关、本拍的电流指令（`Id*`/`Iq*`）、以及本拍 Park 用哪个角。**阶段机的判据只吃 HFI 自己的时间和上一次判决，不吃编码器**（唯一例外是 q 踢后拿编码器位移判极性，见 3.4）。
2. **锁死本半周的注入极性。**
   本拍的注入符号在此刻"拍照"存下来（`s_vh_sign`）。此后整拍里，**注入电压和解调用的都是这一个符号**。锁下之后本拍不许再变——否则第 6 步量到的 Δi 会和真正打出去的电压差半个半周。
3. **取 Park 角。**
   还没发布给 SMO 时用 HFI 的 `θ̂`；已切到 SMO 后用 SMO 角。**同一个角既做 Park、也进 SVPWM**，一拍内不允许出现两个角。
4. **外环给电流指令。**
   速度环（或位置/MIT 外环）给 `ω*` 与 `Iq*`；**`Id*` 一律 0**（软开权重=1）。这是"载波能与电流环共存"的前提：d 轴基波电流必须被调到零，才不会把电压裕度占满、也不会让 Vh 进 q 轴出力。
5. **电流 PI 算基波电压。**
   用 Park 出来的 `id/iq` 算 `ud_pi/uq_pi`。这是"基波那一层"，与载波完全无关。
6. **把 iαβ 投到"打电流的那根注入轴"上，量半个半周的电流变化。**
   把**本拍**和**上一拍**的 `iαβ`，都投影到**上一拍存下来的那把注入轴**（也就是真正打出这段电流的那根轴，不是本拍最新的 `θ̂`），相减得到 `Δi_d/Δi_q`。
   - 平时先扣掉一个慢分量（基波/负载慢变），只留载波引起的跳变；**踢段不扣**，因为踢段要看真 Δi。
   - Δi 乘上"产生这段 Δi 的那个半周的注入符号"，得到 **x（沿注入轴）与 y（垂直注入轴）**。
   - `x/y` 各自做一阶**向量低通**。**先滤向量、再取角**，不要先取角再滤（在 `±π` 支割上会把 ±90° 抹平）。
7. **从 x/y 得到两个角误差（用途不同，别混）。**
   - `ε = ½·atan2(y_lp, x_lp − A_cmd)`：给遥测、准踢（PRE）门禁、Iq 权威用。
   - `e = −(y_raw/Ts) / (Vh·(1/Lq − 1/Ld))`，再限幅 ±0.30：**真正进 PLL 的那条**。它只用 y（`sin2δ` 那一路），所以 x 的圆心漂移不影响鉴相。
8. **PLL 推角度和速度。**
   `ω = Kp·e + 上一拍速度估计` → `θ̂ += ω·Ts`；速度估计是 ω 的一阶低通（α=0.01，约 5 ms）。**每拍更新一次**，不是每半周。踢段冻结（不吃 e），只记 raw。
9. **把 ±Vh 叠到 αβ 上（环后）。**
   在基波电压算完之后、进 SVPWM 之前，沿 `θ̂` 加上 ±Vh。**这一步在电流环之外**：Id PI 既拧不动它，也看不见它。同时把这份载波电压单独留一份（`u_hfi_αβ`）给第 10 步用。
10. **高速观测与发布决策。**
    SMO/EMF-PLL 的输入是「总电压 − u_hfi」，所以载波不进反电势模型，**HFI 段也能一直跑 SMO**。发布逻辑把 SMO 的角/速与 HFI 的角/速做比较，决定这一拍：Park 角发谁的、注入要不要关、要不要把 `θ̂` 重播成 SMO 的值。这个决策**只改"用谁的角度"和"载波开关"，不改电流环坐标系**——这正是 VESC 范式与旧实现的分界线。
11. **同拍出 SVPWM，拍末发遥测。**
    用本拍定了的 Park 角 + 本拍算出的 ud/uq 出 PWM；然后把一份 HFI 快照发布给任务/VOFA（ISR 内不再二次读 getter），避免任务读到半拍状态。

### 3.3 三条容易踩的时序规则

1. **注入符号与解调符号必须同源。**
   `hfi_set_inj_on_hat()`（步骤 3）把 `s_vh_sign ← s_sign`；`hfi_demod_step()` 末尾（步骤 8）才 `s_sign = −s_sign`。
   所以步骤 8 里 `prev_sign = −s_sign` 正好等于**上一个半周实际打出去的**注入符号。`get_inj_ab()` 必须用 `s_vh_sign`（已锁存），**用 `s_sign` 会与解调差半周 → x 反号**（1545 就是这么废掉的）。

2. **本拍 Park 用的是上一拍 θ̂。**
   解调在 Park 之后才更新 `θ̂`（`hfi_sqwave.c:1249`），所以 `x/y` 反映的是"上一拍注入轴 + 本拍电流"。这不是 bug，是必须承认的一拍延迟；**对 PLL 增益的影响已被 `Kp=1200` 的实测定标吸收**，不要为了"消延迟"去提前解调（会破坏 iαβ 与注入轴的对齐）。

3. **`MEAS`（踢段）是特例。**
   · 注入仍开、`update_angle=0`（冻 θ̂，`hfi_sqwave.c:1685`）；
   · 不做 HP 慢分量扣除与 LPF（只看 raw，`hfi_sqwave.c:1179-1181`）；
   · `s_eps` 被踢段自己写成 `s_qk_dth`（`hfi_sqwave.c:1483`）给遥测看。
   改这一段之前先读 `hfi_sqwave.c:1436-1499`。

### 4.2 `hfi_sqwave` 对外 API（`hfi_sqwave.h`）

### 4.4 发布与交接（`hfi_pub.c`）

`hfi_pub_step(θ_smo, ω_smo, dth)` 每拍一次（`motor_current.c:1886`），行为 `【事实】`：

| 量 | 141 值 | 含义 |
|----|--------|------|
| `M1_HFI_PUB_UP_RPM` | 1300 | 未发布时：`\|ω_hfi\|` 到 1300 才好切出去 |
| `M1_HFI_PUB_DOWN_RPM` | 1000 | 已发布时：`\|ω_smo\|` 低于 1000 连续 100 ms 退回 HFI |
| `M1_HFI_PUB_INJ_OFF_RPM` | 1500 | 已发布且已融合完，`\|ω_smo\|` ≥1500 才关载波 |
| `M1_HFI_PUB_INJ_ON_RPM` | 1400 | 回滞：≤1400 重开载波 |
| 角差门 | `0.436 rad(25°)` 好、`0.175 rad(10°)` 快照 | 速度差门 50 rpm，连续 100 ms |
| 融合 | `a += 1/400`（20 ms）线性 | `a=1` 时 `seed_hat(θ_smo, ω_smo)` |

- **切出去**看 `θ_smo − θ̂_hfi` 的角差 + 两速差 → 验收了「两角近」；
- **退回来**只看 SMO 速度（不用 HFI 积分，避免积分钉死）；

## 5. 参数怎么定（按顺序，一步一个）

### 5.1 `Vh`（注入幅值）与 `fh`

- `fh = fs/2 = 10 kHz`（每拍翻极性）**不要动**：这是本方案的骨架，改了要重标 `Kp` 与 LPF。
- `Vh = 0.40 V`（`profile:90-91`）。选定原则：`Δi` 要显著大于 ADC/死区噪声，又不能把 d 轴电流推爆。
  - 下界：`|B| = Vh·Ts·Δ(1/L)/2` 要能分辨。`Ts=50 µs`、`Ld=59 µH`、`Lq=87 µH` → `Δ(1/L)≈5450 S/H`，`|B|≈0.0545·Vh`；`Vh=0.40` 时 `|B|≈0.022`（实测 ≈0.044，含电流环放大）。
  - 上界：`Vh` 占用的电压裕度 = `Vh/(Vbus/√3)`；母线 24 V 时 0.4 V 约 3%，安全。
  - `Vh` 有下标称的运行时系数 `s_vh_scale`（`set_inj_scale`），**交接关载波只动 scale，不动标称值**。
- `hfi_vesc_ang_err` 里对 `Vh` 有 **0.05 V 下限保护**（`hfi_sqwave.c:820-822`）：关到 0 时不会除 0。改这段要保留。

### 5.2 采样与差分的对齐（最容易被忽略）

- 差分必须覆盖**同一个注入半周**，且两个样本都在该半周电流稳定之后（避开 SVPWM 切换瞬态）。G4 是 JEOC 单点采样，**不是 VESC 的双沿**——所以**先对齐现有采样，再谈 FFT**，不要一上来上双采样。
- 判断对齐是否对：离线用 `id/iq/vh_sign` 粗复算 `x/y`，与 MCU `x_raw/y_raw` 逐半周咬死。不咬 → 先查这对齐，**不要调 Kp**。
- `M1_HFI_DEMOD_AB_ENABLE` / `M1_HFI_DEMOD_AB_MID_ENABLE`（αβ 半周差分 / 三端点中点差分）默认 **0**：GATE87 已证「αβ 差分再 Park」使 FEED 更差（1.25→2.02 rad）。要做中点相，**另开 GATE 单独验**。

### 5.3 `A_cmd`（只看两处用途）

- 开环标定（MEAS、δ 网格、纯电压方波）用 `A_fit`（≈0.238）。
- **闭环**用**闭环圆心**（≈0.216），不是开环值；141 profile 暂写 `0.10`（`profile:138-139`）。
  - `0.10 < A + B` ⇒ 结构安全（0° 吸引、90° 排斥），所以「偏小」不会假锁，**但增益斜率会变**，这正是 §5.5 的铁律。
- 只许在**离线拟合过之后**改。禁把 `A_cmd=0.238` 直接当闭环值（1411 / 9/16 的 ε 钉 ±90° 就是这么来的）。

### 5.4 `XY_X_SIGN / XY_Y_SIGN`

- 141 是 `(-1, -1)`（决策表「整体反号」行）。
- **改符号只改这两个宏**，不许加 `EPS_SIGN` / 「只翻 x」/「只改 ε 不改落盘」。改完必须重跑一次 δ 网格，核 `A>0, B>0, C<0`。

### 5.5 `Kp` / `Ki`（141 的定标逻辑）

1. 从 δ 网格离线得 `B、C`（对齐 `φ` 之后），算**闭环斜率 `C/B`**。
   - **禁用**包 2 在 `A_cmd=0` 时的 `C/(A+B)` 去标闭环（差约 6 倍，`A≈5|B|`）。
2. 目标带宽：`ωn ≈ 2π·3 rad/s`、`ζ≈0.95` → `Kp = 2ζωn/|C/B|`、`Ki = ωn²/|C/B|`。
3. **但 VESC 型误差的 `Kp` 与 atan2 型的量纲不同**：`e` 无量纲，`Kp` 直接是 `rad/s`；141 实测取 `Kp=1200`（`profile:224-225`）。
4. 「积分」用 α=0.01 泄漏积分（§2.6）。**不要**同时开 `M1_HFI_PLL_KI` 到主环——那是影子 PLL 的口。
5. 调参顺序：先 `Kp`（看收敛/振荡），再 `s_speed_est` 的 α（看速度噪声）。**一次只改一个。**

### 5.6 死区与限幅

| 宏 | 141 | 用途 |
|----|-----|------|
| `M1_HFI_PLL_EPS_DEAD` | 0.0 | 角误差死区；>0 时误差小于它不积分（防漏解调积出假速） |
| `M1_HFI_PLL_W_MAX` / `PLL_INT_MAX` | 200 / 200 | 转速与积分上限（`rad/s` 电） |
| `M1_HFI_PLL_VESC_MAX_ERR` | 0.30 | VESC 型误差限幅 |
| `M1_HFI_DEMOD_HP_A` | 0.05 | 慢分量扣除的一阶系数 |
| `M1_HFI_IQ_AUTH_*` | 见 §5.7 | Iq 权威 |

`141` 的 `Kp=1200 × MAX_ERR=0.30 = 360 rad/s` 上限；`W_MAX=200` 在下游再夹一层。

### 5.7 Iq 权威（AUTH）——用「盆地质量」限 Iq，不用编码器

`hfi_iq_auth_step()`（`hfi_sqwave.c:1022-1077`）：给速度环的 Iq 加一个**天花板**：

```
|x_lp| ≥ X_GOOD(0.218) 连续 HOLD_N(2000拍=100ms) → ok，天花板升到 IQ_HI(2.0 A)
|x_lp| ≤ X_BAD(0.205) 且 |ε| ≤ EPS_FALSE_MAX(0.20) 连续 CLEAR_N → 判假锁，天花板降到 IQ_LO(0 A)
中间带保持；升降斜率 SLEW_A_S(4 A/s)
```

- 判据是「`x` 在 A 附近」而不是「钉在 A−B」——**这是真 d 与 q 轴假锁的指纹**。
- 交接关注入时 `s_iq_auth_hold=1`（`hfi_pub.c:129`），避免 x 掉下去把天花板收了。
- `motor_current.c:1533-1557` 把天花板同时写进 `iq_ref` 与速度 PI 的 `out/int` 限幅。

### 5.8 负载/Park 偏差

不要用「把偏差写进 Park 角」去补负载凸极 Δ。9/18 已证 9/14 的角滑是**失锁/第二不动点**，不是确定负载 Δ；`BIAS_CAL` 已否决，**不要恢复**。

## 11. 风险与回退

| 风险 | 对策 |
|------|------|
| 10 kHz 半周仅 1 拍，`Δi` 小、死区敏感 | 提 `Vh`；对照死区 OFF；临时 `D=1` 逐半周咬齐 |
| `id` 环与载波互相污染 | 坚持环后注入 + 注入轴解调（141 已如此）；不许回到 `ud += Vh` |
| π 极性未过就出力 | V3 未签收禁止 V4；踢段必须走 `QKICK_*` 且记 `Δθ_enc` |
| 交接瞬间塌速 | 两角门 + 速度滞回 + 融合；SMO 全程 `u−u_hfi`；**禁 IDUP** |
| 减速回 HFI 时 SMO 不可观 | 载波回滞（1500/1400）独立于角度切换；退回门用 SMO 速度不用 HFI 积分 |
| 冻死的编码器包被当成"最干净" | 每包先判 LIVE（手转 ch0 变、静止 LSB 抖）；std 小要当**嫌疑** |
| 回退 | 只改 `M1_HFI_GATE`；一次一包；保留 hex + `rebuild_log.txt` + size + sha256（`MDK-ARM/_pkg/<日期>_<实验名>/`） |
