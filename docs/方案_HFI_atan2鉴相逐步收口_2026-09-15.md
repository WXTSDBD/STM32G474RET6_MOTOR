# 方案：atan2 鉴相收口 HFI PLL（2026-09-15）

**对象**：STM32G474RET6_MOTOR · N5065 · `m1_hfi_standstill`  
**本文角色**：一步一枪、不过线不准进入下一步。不替代 [9/13 总方案](./方案_HFI方波位置辨识与SMO对接_2026-09-13.md) 与 [9/14 日报](./联调日报_HFI_CAPTURE_2026-09-14.md)。  
**要收的问题**：ε 未标定 → ±90° 假锁 / 2140 继电器抖 / 静置假速漂。  
**不在本文**：H2 低速速度环、H3↔SMO、带载 Δ(|Iq|) 补偿。

**台架最短路径：5 包。** 合并判据：**这个量能不能离线复算**。  
符号不靠「只翻 x」，靠 **§4.1 决策表**。A>|B| 是电感定理，2247 那种 |B|>>|A| 是坏测量，不是过线。

## 0. 一句话

> **原始 x/y/di_d/di_q 落盘；B、C、φ、翻哪一路都离线定。增益、初值、拆补丁各烧各的。**  
> 第一枪不闭环、不删补丁、不用公式 A=0.284。  
> **门禁（\|A\|&gt;\|B\|、x 不变号、极值比）不过线不上 atan2。唯一停线重定标签的组合是 (B<0, C>0, |x| 峰值在 ±90°)。**

## 1. 铁律

1. **能离线复算 → 合；只能固件生效 → 不合。**  
2. **不过线不往下。** FAIL 只回本包，不准加 AXIS_SEL / 死区 / 限流。  
3. **A 只用开环拟合。** 禁止模型 `0.284`。B&gt;0、C&lt;0 时充要条件是单边 **`A_cmd < A+B`**（唯一稳定点=峰值轴）。`|A_cmd−A|<|B|` 只是充分条件；A_cmd 偏小没有第二稳定点。  
4. **符号修正只落在落盘通道 `x_raw`/`y_raw`（决策表指定的那一路）。** `atan2(y,−x)=π/2−δ′`，翻 x ≡ 搬零点；`−ε=½atan2(−y,x)` ≡ 翻 y（决策表第 2 行，合法）。禁止再加 `EPS_SIGN` / `park_uses_hat` 翻号；**禁止只改 ε 不改落盘。**  
5. **窗卫生**：`ω_enc` 中位 `< 20 rpm`；另收 ch0 `θ_enc` 的 std（锁转子被注入顶会爬）与窗内 `|x|` 的 std（有趋势=漂移）。超阈该点作废。  
6. **开环标定帧 = 闭环 RUN 帧。** `PARK_ENABLE=1`，白名单在该 `#if` 内。  
7. **`sign(C)=−sign(B)` 不是 pass/fail。** 它是可信度 + 决策表输入。只有 **(B<0, C>0, |x| 峰值在 ±90°)** 才停、重定标签。  
8. **2247 三点不定符号、不定 φ、不定 A/B。** 13 点 + 门禁签名 + 翻号后的 A&gt;0/B&gt;0/C&lt;0 才是证据。  
9. **Kp/Ki 用闭环斜率 `C/B`，不用包 2 在 A_cmd=0 时的 `C/(A+B)`。**

**2247 推不出 φ≈0，也推不出 A/B 符号**

极值每隔 90° 一个，三点都在极值上不含 φ。干净模型 `A=KΣ`、`B=KΔ`、`Σ>Δ` ⇒ **A>|B| 恒成立**。A&gt;0、B&gt;0 时 x 恒正；门禁只要求 **全网格不变号**（允许整体反号，由决策表翻回来）。实测若 |B|>>|A| 或窗内变号，是 di_d 污染 / 电流环在 10 kHz 带反号，**禁止当过线值**。

**判据 0 — `|x|` 峰值**

`|x|` 峰在 ±90° **等价于 A·B&lt;0**（φ=0 的 2δ 模型）：包括 B&lt;0，也包括 **A&lt;0 且 B&gt;0**。后者既不是 φ≈90°，也不是「B&lt;0 标签差 90°」。

| 峰值 | 含义 | 动作 |
|------|------|------|
| **0°**（±15°） | 低感轴 ≈ 编码器 0° | 进决策表 |
| **±90°** | **A·B&lt;0**：B&lt;0，或 A&lt;0 且 B&gt;0；不要直接读成 φ≈90° | **先查 Ld/Lq 辨识来源和 di_d 污染**；禁动 `M1_ENCODER_OFFSET_RAD`。再进决策表（仅第 5 行停） |
| **既不在 0 也不在 90** | 不是标签差 90°。先看相位拟合的 φ；同样可能是 A·B&lt;0 的污染 | 停，不上 atan2 |

φ≈0 仍是假设，13 点网格的 ψ 尚未被数据验证。可选：用 2247 的 ch1/ch2 离线看驻留窗内 θ̂ 是否真没动。

**判据 A′ — 拆开：门禁 vs 翻号后目标**

物理：`A=KΣ`，`B=KΔ`，`Σ>Δ` ⇒ **|A|>|B| 是定理**（翻号不改变）。旧文「|B|、|C| 明显大于 |A|」与物理相反，已删。

**门禁（翻号不变，任一条不满足 → 不许上 atan2）**

| 项 | 要 |
|----|----|
| \|A\| vs \|B\| | **\|A\|>\|B\|** |
| x 变号 | **全网格不变号**（不是「全程为正」：整体反号由决策表翻回来） |
| 极值比 | `\|x\|_max / \|x\|_min ≈ Lq/Ld`。静态 87/59≈**1.47**；[Foundation 总结](./Foundation平台历史性总结与问题分析.md) :320 动态电感约一半 → **按 1.47±30% 粗判**（约 1.0–1.9） |

**翻号之后必须成立（决策表第 2/3/4 行就是为了走到这里；不可当门禁，否则那三行永远走不到）**

| 项 | 要 |
|----|----|
| A | &gt; 0 |
| B | &gt; 0（对齐 φ 之后） |
| C | &lt; 0 |

**判据 B — ±45° 用 x_raw / y_raw（不用 ch4/ch9）**

- `y(+45)` 与 `y(−45)` 反号（sin2δ 奇函数）。符号直接喂决策表。  
- 2247 **没有** ±45 点；本条是预期。45° 的 \|y\| 仍≈0 → 停。

**判据 C — 相位感知拟合（删掉 `x(±45)≈A`）**

`x(±45)≈A` 只在 φ≈0 时成立，φ=10° 就会误判成模型证伪。

```text
x ≈ A + B1·cos2δ + B2·sin2δ
y ≈ C1·cos2δ + C2·sin2δ
φ  = −½ atan2(B2, B1)

# 对齐到 δ′=δ+φ 后再取决策表用的 B、C：
#   x ≈ A + B·cos2δ′
#   y ≈ C·sin2δ′
```

残差：13 点，`RMS(x−x̂) ≤ 0.10 |B|`，`RMS(y−ŷ) ≤ 0.10 |C|`。爆 → 不是 2δ。

**决策表（B、C 一律用对齐后的 x_raw / y_raw）**

`dε/dδ′ = B·C / (B²cos²2δ′ + C²sin²2δ′)`，符号恒等于 `sign(B·C)`。平衡点只在 `B cos2δ′>0` 的轴上。B&gt;0 且 C&lt;0 时 ±90° 是排斥子，**结构上不可能假锁**。

| B | C | \|x\|峰值 | 含义 | 动作 |
|---|---|-----------|------|------|
| + | − | 0° | 理想 | 不动 |
| + | + | 0° | q 通道反号 | **翻 y** |
| − | − | 0° | d 通道反号 | **翻 x** |
| − | + | 0° | 整体反号 | **翻 x 和 y** |
| − | + | ±90° | 编码器/标签差 90° | **停，重定标签**（仍禁动 offset 先查污染） |

翻 x 只对应第 3 行。第 5 行若去翻 x，会盖掉真问题。

### 包 2 — atan2（A=0 结构安全；写 A_fit 只为增益）

`dε/dδ′ = C(A_e cos2δ′ + B)/(X²+Y²)`，`A_e=A−A_cmd`。B&gt;0、C&lt;0 时：

- 0° 斜率 `C/(A_e+B)`，90° 斜率 `C/(B−A_e)`。  
- 90° 要成为平衡点需 `A_e>B`，成为吸引子需 `A_e<B` —— **互斥 ⇒ 90° 永远不是稳定锁点。**

因此签名过线（|A|&gt;|B|）时 **A_cmd=0 &lt; A+B，结构安全**：0° 吸引，90° 是排斥子，不会假锁。双过零假锁这条理由作废。

写 `A_fit` 的**唯一**理由是增益：斜率从 `C/(A+B)` 变成 `C/B`（理想量级 A≈5|B| 差约 6 倍），即铁律 9。推荐包 2 就写入 A_fit，让开环斜率已经是 `C/B`，避免拿错数去标包 3。

按包 1 决策表翻对应那一路（可能是 y ≡ −ε，或 x，或两路）。翻完后核 A&gt;0、B&gt;0、C&lt;0。

**A 的窗口（B&gt;0、C&lt;0 时充要，单边）**

| 条件 | 闭环 |
|------|------|
| **`A_cmd < A+B`** | 唯一稳定点 = 峰值轴（真 d）；不存在第二稳定点。A_cmd 偏小（含 0）无风险，90° 顶多是排斥子 |
| **`A_cmd ≥ A+B`** | 无平衡点 → ε 不过零 → 积分绕圈/漂 |

`|A_cmd−A|<|B|` 只是充分条件，不要当充要，也不要把「偏小」写成假锁。

**斜率**：0° 处 `C/(A_e+B)`。包 3 的 Kp/Ki **必须用 `C/B`**（A_cmd=A_fit）。若包 2 固件仍 A=0，开环曲线斜率是 `C/(A+B)`，**不准**拿去标闭环。

过线：ε 零点在峰值轴；核 `ch4 ≈ ½atan2(y_adj, x_adj − A_cmd)`。

### 包 3 — 静置闭环

`DELTA_SWEEP=0`，Iq=0，`INIT_FROM_ENC=1`，`INIT_OFF=0`。  
`Kp = 2ζ wn / |C/B|`，`Ki = wn² / |C/B|`（ζ≈0.95，wn≈2π·3）。

## 6. 明确不做

- 「只翻 x」当万能修符号。  
- `sign(C)=−sign(B)` 当门禁。  
- `x(±45)≈A` 当模型自检。  
- `|B|>|A|` 当过线（与定理相反）。  
- 用 ch4/ch9 做跨包符号判据。  
- 用 `|A_cmd−A|<|B|` 当充要，或把 A_cmd 偏小说成 90° 假锁。  
- 禁止翻 y / 禁止 −ε（决策表第 2 行就是它，但必须改落盘 y 而不是只改 ε）。  
- 把 A&gt;0/B&gt;0/C&lt;0 当翻号前的门禁（会卡死决策表第 2/3/4 行）。  
- 用包 2 在 A_cmd=0 时的 `C/(A+B)` 去标包 3 的 Kp。  
- 动 `M1_ENCODER_OFFSET_RAD` 修 HFI 标签。  
- 包 1 额外关 PLL。  
- 未过包 5 就改 H3。
