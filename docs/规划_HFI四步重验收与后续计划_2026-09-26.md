# 规划：HFI 四步重验收与后续实验计划（2026-09-26）

**对象**：STM32G474RET6_MOTOR · N5065（7 极对，`Ld≈59µH` / `Lq≈87µH`）· profile `m1_hfi_standstill`  
**本文角色**：把 9/13–9/16 的实验史收成「当初四步计划 vs 实际过了什么」，并给出 **重做第 1、2 步 → 再无感起动 → 再 HFI↔SMO** 的可执行计划与验收口径。  
**不替代**： [9/13 总方案](./方案_HFI方波位置辨识与SMO对接_2026-09-13.md)、[9/15 atan2 收口](./方案_HFI_atan2鉴相逐步收口_2026-09-15.md)、[9/16 卡点复盘](./分析报告_HFI卡点复盘与HFI+SMO实施计划_2026-09-16.md)、[9/18 根因再分析](./分析报告_HFI根因再分析_2026-09-18.md)。细节证据以那四篇为准；本文只定 **工序与门禁**。  
**中高速 SMO V1** 仍以 [结档](./结档_SMO中高速无感V1与HFI开干_2026-09-12.md) 为准，本规划不回退、不重开满 PI。

## 0. 一句话

> **凸极 2θ 已经看见了；当初第 1、2 步的 PASS 掺了编码器时钟，所以第 3 步一自持就垮。**  
> 下面按原计划重跑 1→2→3→4。编码器只许当老师和有感托底，不许当 HFI 的积分时钟。1、2 不难；3 在 1/2 真过之后是工程收口，不是再推公式。

## 1. 原计划（不变）

| 步 | 意图 | 编码器该干什么 |
|----|------|----------------|
| **1** | Ud 开环摆到不同位置，HFI 开环辨识，对照编码器 | 真值 + MEAS 的 Park/注入参考 |
| **2** | 有感闭环约 100 rpm，HFI 辨识对照编码器 | 托速度环和 Park；HFI PLL **自己**出角 |

### 2.2 当初为什么会认为 1、2 过了

**第 1 步** 方案里 MEAS 用 Park=编码器本来就是对的（旁路看 2θ）。过线却过松：stage 会走、ε 非零、隐约双周期，就算「已落地」。没有「编码器 LIVE + 拟合过门 + 扫完停、不开 PLL」的签收包。后来网格把 2θ 测准了，但和「第 1 步已验收」不是同一回事。

**第 2 步** 意图应是：有感托转，HFI 旁路出角。实现上 `MOTION_BYPASS` 把 **编码器 PLL 转速喂进 HFI 的 \(\omega_{ff}\)**。θ̂ 贴编码器、相关 0.999，是构造出来的。H0.5 还用编码器消 π、初值 `θ̂=enc+偏置`。这和 SMO 9/10「观测器不进 Park、也不拿编码器推观测器」相反。

**第 3 步** 是环路第一次要自己活。9/14 一起自持就露出 q 轴锁 / 假速。不是 3 突然变难，是 1/2 没证明过「没有 \(\omega_{ff}\) 也能跟」。

### 2.3 已经证明 / 没有证明

**已证明（可当基线）**

- 10 kHz 方波、Vh=0.40 下凸极可观测；解调 \(x=\mathrm{sign}\cdot\Delta i_d\)、\(y=\mathrm{sign}\cdot\Delta i_q\)，\(\varepsilon=\tfrac12\mathrm{atan2}(y,x-A)\) 在 **d 轴邻域**自洽。
- \(A_\mathrm{fit}\approx0.238\) 与 profile `A_cmd` 一致；\(\|B\|/A\approx0.19\) 对 \(\Delta/\Sigma\)；Kp/Ki 按 \(C/B\) 量级自洽。
- BIAS_CAL 把偏置拧进 Park 会崩，不要恢复。
- 编码器 DMA 会静默冻死；「θ_enc std 小」会把死包判成最干净。

**没有证明**

- HFI PLL 在 **无编码器转速前馈** 时能跟转动凸极轴（第 2 步）。
- 静置闭环锁在 **真 d**（\(x_{lp}\to A+\|B\|\)），而不是 q 轴（\(A-B\)）。
- 编码器无关的 π 极性。
- 纯 HFI 低速速度环、HFI↔SMO 软切。

**公式结论：** 2δ 模型没有错。闭环失败主因是 **错盆地 + 编码器中继被当成锁定 + 尺子冻结**。SNR 够；开死区补偿不是下一枪。

## 3. 之后怎么做（关卡）

原则（从 SMO 9/6–9/12 搬过来）：

1. **一包只改一个量。** FAIL 只回本步，不准加 AXIS_SEL / 死区 / BIAS_CAL / DQ+QKICK 同包。
2. **能离线复算才当证据。** 每包冻：profile、关键 `.c` 哈希、git HEAD、Keil size、12ch 表。
3. **编码器 LIVE 是包有效前置。** 手转 ch0 必须变；静止 uniq 要有 LSB 抖。冻死的包直接作废，不分析 φ。
4. **第 1、2 步未签收，不准做第 3 步；第 3 步未签收，不准改 `obs_soft_switch`。**
5. **禁动 `M1_ENCODER_OFFSET_RAD` 修 HFI 标签。**

Vh=0.40、fh=10 kHz、死区 OFF 先不动。VOFA JustFloat×12，D=2→10 kHz。

### S0 — 包有效（每次上电，5 min）

手转转子，看 ch0。静止时 θ_enc 仍应有 LSB 级跳动（对照：活包约 7–8 kHz 更新；死包 60 s 一个字）。Keil Watch：`enc_cplt_cnt` 在涨、`enc_kick_skip_busy` 不狂增。不过 → 当天 HFI 数据不作数。

### S1 — 重做原计划第 1 步（开环尺子）

**做什么：** Ud MOVE 到至少 2～3 个姿态（或 13 点 δ 网格 −90°…+90° / 15° / HOLD 3 s）。MEAS：Park=enc 或 enc+δ，纯电压方波。**PLL 不更新 θ̂。扫完 DONE，不进 RUN。** DQ/QKICK/IPD/AXIS_SEL 全关。

**12ch（必须冻死，与分析脚本一致）：**

| ch | 量 |
|----|----|
| 0 | θ_enc |
| 1 | δ 或 θ_cmd |
| 2 | θ̂（应 = enc+δ） |
| 3 | vh_sign |
| 4 | ε（判据不用旧 ε 跨包） |
| 5 | ω_enc |
| 6–9 | x_raw, y_raw, di_d, di_q |
| 10–11 | stage, lock |

已烧过的 S1 口径（2026-09-26，已签收）：IDLE **8 s** → 13×3 s MEAS → LOG 5 s → DONE。不进 RUN。台架卡：`VOFA+CSV/20260926/_freeze_S1_20260926.txt`。

**过线：**

| 项 | 标准 |
|----|------|
| 尺子 | S0 过；MEAS 段 θ_enc LIVE |
| 2θ | \(\|A\|>\|B\|\)；\(\|B\|/A=0.19\pm30\%\)；\(\|x\|_\max/\|x\|_\min=1.47\pm30\%\)；\(\mathrm{RMS}/A<2\%\) |
| 正交 | x/y 为同一 2δ 的 cos/sin（相位差约 90°/2） |
| 复核 | 离线 \(x\approx(-\mathrm{vh\_sign})\cdot di_d\) 与落盘重合 |
| 多姿态 | Ud 真摆开则 ch0 必须变；峰值轴 φ 跨姿态差 <15° 电角 |
| 重复 | 同夹具两靴，φ 差 <10–15° |

**通过代表：** 开环能看见这台电机的凸极，并能量出 φ。**不代表会锁、会转。**

**FAIL 只许：** 查通道/Park/编码器活性。不许翻 XY、改 A_cmd、开死区、进 PLL。

### S2 — 重做原计划第 2 步（有感 100 rpm 旁路）

**做什么：** Park=编码器，速度环吃编码器，目标约 100 rpm。HFI 只估角对照。  
**必须：** \(\omega_{ff}=0\)（禁止 `s_pll_omega_mech_rpm` 喂 HFI）。不要 `POLARITY_ENC` 硬掰 π。一次只开这套旁路。

已烧过的 S2 口径（1136 签收）：`M1_HFI_GATE=2`。两靴 PASS（0° / 180°），d² 不中继，ε 离开切口。Park=enc，XY=−1，A_cmd=+0.10。台架卡：`VOFA+CSV/20260926/_freeze_S2_20260926.txt`。

| ch | 量 |
|----|----|
| 0 | θ_enc |
| 1 | ω_ref |
| 2 | θ̂ |
| 3 | θ_err = wrap(θ̂−enc) |
| 4 | ε |
| 5 | ω_enc |
| 6 | x_lp（盆地） |
| 7 | y_lp |
| 8 | ω_hfi |

| 10 | stage（RUN=7，DONE=5） |

**过线：**

| 项 | 标准 |
|----|------|
| 反作弊 | \(d^2(\omega_{hfi})\) 与 \(d^2(\omega_{enc})\) 相关 **< 0.3**（9/13 作弊包是 ~0.99；自持包约 0.02） |
| 角 | 稳态 \(\mathrm{median}(\thetâ-\theta_{enc})\) 落在 S1 的 φ 或 φ+180°（2θ 只能到 180°） |
| 抖 | \(\|\thetâ-\theta_{enc}\|\) p95 先 <30° 电角能跟住，再收 |

| 运动 | ω_enc≈100 rpm 真转；不要静置假速那种 ω_hfi~80 rpm、轴不动 |

**通过代表：** 转动中、力矩仍有感时，HFI PLL 能自己出可用角。这是第 3 步的必要前提。

**FAIL：** 仍相关 0.99 → 前馈没关掉，修配置再录，不要调 Kp。坐 q 轴 → 回到 S1 的 φ/标签，按 9/15 决策表只翻落盘指定那一路，当场重做 S2，不加新状态机。

### S4 — 原计划第 4 步（HFI↔SMO）

**S3c2（及建议 S3d）过了**再动 `obs_soft_switch`。底源改 HFI，高速仍 SMO。门限按 `|ω|` + emag + HFI 置信；重叠带须实测（SMO 闭环地板约 800–900 rpm，HFI 要先在旁路/低速环顶进重叠）。外环不新写「只认正转」的 PI。

**过线（摘要）：** 加速经 BLEND 进 SMO、减速回 HFI、Iq/ω 不崩；无编码器进环完成正反低速 HFI + 中高速 SMO（enc 只录波）；不回归 V1 限权巡航。

## 5. 明确不做

- 用开死区、加大 Vh 来「赌第 1 步过线」。
- 同一包开 DELTA_SWEEP + RUN(+90°) + DQ_IDENT + QKICK。
- 把 π 锁（δ≈168°、ε≈0）写成静置 PASS。
- 用 `|θ_err|<12°` 卡起动；用 ω̂≈ω_cmd 判锁。
- 恢复 BIAS_CAL；动 encoder offset 修 HFI 标签。
- **用 I/F 充当 HFI 起转**（产品是 HFI+SMO）。
- 未过 S3c2 就改软切或冲 1000 rpm HFI 速度环。
