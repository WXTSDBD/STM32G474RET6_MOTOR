# 对照：本仓库 HFI vs `别人的代码` vs VESC（怎么借鉴）

**日期**：2026-10-03  
**对象**：`STM32G474RET6_MOTOR` 脉振方波 HFI（`motor/observer/hfi_sqwave.c`、C4x FEED、HFI↔SMO 交接）  
**对照源**：

| 名称 | 本仓库位置 | 实际是什么 |
|------|------------|------------|
| 本实现 | `motor/observer/hfi_sqwave.c`、`motor/motor_current.c` | 半周 Δi + ½atan2，Vh 叠在估计 d 轴 |
| `别人的代码` | `别人的代码/sensorless_estimator.c` 等 | 别人驱动里的无感调度：**VESC 连续 HFI 封装 + 并行磁链 + IF 交接** |
| 上游 VESC | **不在本仓库**（`vesc_hfi.h` 被引用，无 `vesc_hfi.c`） | FFT / 多点采样载波观测；电流环后 αβ 注入 |

本文只谈架构与台架已证事实，不替代 GATE 签收表。不主张从零重写一份 VESC 固件。

---

## 1. 一句话

本实现已经能 **静置锁轴、踢极性、Id 关带转、IF→SMO 中高速**。  
Id 开着 FEED、以及 **HFI 旁路 Id 后在 SMO 高速再开 Id**，裕度明显不够。

VESC / `别人的代码` 并不是「同一套半周 atan2 调得更好」，而是：

1. **载波观测和基波电流环拆开**  
2. **磁链观测在 HFI 阶段就并行跑，并从电压里减掉载波**  
3. **切 Park 时旋 PI，没有「突然开 Id」这一事件**

借鉴这三件。不要克隆 VESC 工程，也不要再走「高速再放行 Id PI」。

---

## 2. 本实现实际做到了什么（避免自我贬低）

已经值钱、应保留的：

- 电机/电流环辨识、死区、SVPWM、VOFA 边沿日志  
- 静置 2θ 网格、q 踢消 π、C4x FEED 能带转（Id 关或 Id 开都能转）  
- IF→SMO 加减/正反曾签收（与 HFI 交接是另一条路径）  
- 编码器只作台架真值，产品钟不吃 enc ω_ff（约束仍有效）

缺的不是「电机还没转起来」，而是：

| 目标 | 现状 |
|------|------|
| Id*=0 且 PI 开着，FEED 0.8 锁相 | 能转，`\|θ_err\|` p50 ≈ **1.2 rad**（1225 / GATE84） |
| HFI→SMO 高速再开 Id | **IDUP 塌速**（62/64），已证伪 |
| 残 Vh 下 SMO 减速 | 2147 等 stall；未做成「减载波的并行磁链」 |

## 3. 三套方案怎么拆电流、注入、观测

### 3.1 本实现（脉振方波 + 半周 atan2）

```
ADC → Clarke → Park(θ̂) → Id,Iq
        ├─ Id PI（常被旁路，或与解调抢同一条 Id）
        ├─ 半周 di_d, di_q → x,y LPF → ε = ½ atan2(y, x−A)
        └─ Ud_pi + (±Vh 在 d 轴) → 反 Park → SVPWM
```

要点：

- 注入：`hfi_set_inj_on_hat()`，Park=θ̂ 时就是 **Ud += ±Vh**。GATE88 想改成 αβ 再 Park 进 SVPWM；Park=θ̂ 时与 Ud+=Vh **代数等价**。1545 因 `get_inj_ab` 用了解调后已翻转的 `s_sign`，x 反号，对照作废。  
- 解调：默认 `di = id[k]−id[k−1]`（GATE87 的 αβ 差分再 Park 使 FEED 更差）。  
- SMO：交接态机里常 **hold**，再灭 Vh、再 `id_pi_release`。不是并行减载波。

### 3.2 上游 VESC（本仓库无源码，按公开结构 + `别人的代码` 调用面）

```
ADC（常含载波相位上的一对样本）
  → 基波 Id/Iq PI（Id* 多为 0，环一直开）
  → 反 Park 得到 uαβ_fund
  → uαβ += Vh·(cos φ_inj, sin φ_inj)     // 环后注入
SVPWM

并行：
  FFT / 注入轴电流 → θ̂_HFI
  磁链观测用 (uαβ − u_hfi)                // 载波不进模型
```

`别人的代码` 里对应接口：`foc->hfi_volt_ampl`、`foc->hfi_inject_phase`、`foc->sample_hfi_voltage_alpha/beta`、`vesc_hfi_update()`。

### 3.3 `别人的代码`（调度层，不是 FFT 本体）

文件：`sensorless_estimator.c`、`flux_observer.c`、`sensorless_if.c`。

它做的是 **状态机 + 并行观测 + 交接门**，HFI 数学在缺失的 `vesc_hfi.c`：

| 机制 | 代码位置（概念） | 作用 |
|------|------------------|------|
| 连续 HFI 调度 | `sensorless_vesc_hfi_schedule` | 只开关载波、把 flux 角 sync 给 HFI；**不改电流环坐标系** |
| 磁链减载波 | `flux_observer_update`：`sample_voltage − sample_hfi_voltage` | HFI 阶段 flux 就能热 |
| 交接门 | `hfi_handover_ready && flux_handover_qualified` | 锁 + 极性 + 两角近 + ψ 幅值 + 反电势证明在转 |
| 切帧 | `sensorless_native_seed_rotor_current` | 把 Ud/Uq/积分/IdIq **旋到新相** |
| Id 指令 | `get_startup_current`：tracking 前 Id*=Iq*=0 | **没有**「高速再开 Id PI」 |

注释写明：VESC 连续模式是 **阈值切换**，不是长时间 dual-DQ；但仍要求 **切之前两边已经对齐**，电流环保持同一电压矢量。

## 5. 台架已经否决的路（不要写进「下一步」）

这些是数据，不是口味：

1. **Id PI 吃低通 Id**（GATE85 / 1236）：相对 1225 **NO_GAIN**。  
2. **解调前高通 Id/Iq**（GATE86 / 1516）：FEED `\|di_q\|` 仍 ≈0.021，**NO_GAIN**。不要拧 `DEMOD_HP_A`。  
3. **αβ 半周差分再 Park**（GATE87 / 1524）：FEED `\|θ_err\|` 1.25→**2.02**，REGRESS。  
4. **GATE88 αβ 注入**：1534 没进 SVPWM；1545 进桥但 **x 反号**（`s_sign` vs `s_vh_sign`）。不能写成「αβ 注入更差」。Park=θ̂ 时预期 ≈1225。  
5. **HFI 关 Id，SMO 高速再开 Id（IDUP）**：塌速失角。`别人的代码` 也没有这一刀。  
6. **离线扣 Id 再解调**（1225）：比 `½sin2θ_err` 更差，否决上 MCU。

还成立的：踢前 Id 开着也能锁；问题在 **带 Iq 的 atan2** 和 **不连续的交接**。

## 6. 应该借鉴什么 / 不要抄什么

### 6.1 要学的（按优先级）

**A. 电流环语义（交接能活的前提）**  
HFI 段 Id PI **不要旁路**。Id*=0，环一直算。产品路径禁止再出现 `id_pi_release` 当高速事件。

**B. HFI 电压单独记账**  
SVPWM 用的电压里，载波分量要能拿出 `u_hfi_αβ`。磁链/SMO 只用 `u − u_hfi`。本实现 SMO 现在吃的是「可能含 Vh 的 ud/uq」，且交接前还 hold。

**C. 解调离开「PI 正在掐的那条 Id」**  
注入轴上的 iα/iβ（半周中点差分即可起步；FFT 后上）。采样相位要对齐注入边沿。G474 的 JEOC 不是 VESC 双采样，**先对齐现有采样再谈 FFT**。

**D. 切角条件 + 旋 PI**  
学 `hfi_handover_ready && flux_handover_qualified` 和 `sensorless_native_seed_rotor_current`：两角近、ψ 可信、转子在转，再把积分旋过去。不要用「转速到了 1050」当唯一门。

### 6.2 不要抄的

- 整份 VESC 工程、`mcpwm`、其电流环与采样 ISR  
- 把 `别人的代码` 五个文件丢进 MDK（缺 `vesc_hfi.c` / `foc.h` / BSP）  
- 再叠 GATE 去拧半周 atan2 的 HP/LPF/Park 顺序  
- 「到了 SMO 再开 Id」——两边都不是这样设计的  
- 弱化已辨识的 Id PI 增益（无证据）

### 6.3 不要从零重做 VESC 的原因

- 辨识、死区、IF–SMO、台架地图、板级与 HFI 公式无关，重写没有复利。  
- VESC 的复利在 **观测拆分**，不在文件名。  
- G4 采样与 VESC 不同，从零克隆会先卡采样，锁相问题被挡住。

## 7. 建议落在本仓库的工序（仍一包一变量）

在 **现有** `hfi_sqwave` + `emf_smo` 上长，GATE 回退机制保留。

| 步 | 做什么 | 验收（相对 1225 或 2147） | 不是什么 |
|----|--------|---------------------------|----------|
| 0 | 88 极性改 `s_vh_sign`，做完有效包 | 踢前 x>0 且能踢；FEED 预期 ≈1225 | 新观测器 |
| 1 | HFI 全程 Id PI 开、Id*=0，禁止旁路 | 踢前仍锁；记录 Ud_pi | 改解调公式 |
| 2 | `u_hfi_αβ` 记账；SMO `u−u_hfi`，HFI 段不停 SMO | 静置 SMO 不炸；加速交接不再 IDUP | 突然开 Id |
| 3 | 解调改为注入轴 αβ Δi（中点相），电流环仍裸 Id | FEED `\|θ_err\|` 相对 1225 下降 | FFT 第一步 |
| 4 | 切角：两角门 + Park 旋 PI | 加速过交接不塌；减速再采 2147 类包 | 指令转速硬切 |
| 5 | 需要时再上 FFT bin / 双边沿采样 | 仅当第 3 步触顶 | 从零 VESC |

第 0 步只是把 1–3 步旧计划收口。第 3 步才是「学 VESC 解调」。第 2、4 步才是「学 VESC 高低速裕度」。

## 8. 读代码时怎么对照（避免读散）

**本实现（先读这些）：**

- 注入：`hfi_sqwave.c` 中 `hfi_set_inj_on_hat`  
- 解调：`hfi_demod_step`  
- 叠压与 SVPWM：`motor_current.c` 中 `get_inj` / `INJECT_AB` / `foc_svpwm_apply_abc`  
- 交接：`motor_current.c` 中 `HFI_HAND_*`、`HAND_OPEN_ID`、`id_pi_release`

**别人的代码（当设计说明读，不当可链接库）：**

- 载波与 flux 减 Vh：`flux_observer.c` `flux_observer_update` 开头  
- 连续 HFI 只调度载波：`sensorless_vesc_hfi_schedule`  
- 交接门与旋 PI：`hfi_handover_ready` 一段、`sensorless_native_seed_rotor_current`  
- Id*=0：`sensorless_estimator_get_startup_current`

缺的文件：`vesc_hfi.c`（FFT 本体）。要学 FFT 需另取上游 VESC，不要假装本仓库已经有。

## 9. 结论

| 问题 | 答案 |
|------|------|
| 要不要从零实现 VESC？ | **不要。** |
| 他们 HFI 和我的本质差别？ | **观测是否独立于 Id PI；磁链是否并行且减载波；切帧是否连续。** |
| 我是不是「只是转起来了」？ | 转和辨识是真的；**Id 开着锁相、以及 SMO 交接**才是缺口。 |
| 以后最有复利的学法？ | 在本 FOC 上按 §7 拆环，而不是新仓库克隆 VESC。 |
