## 一、领域划分

整个固件分为两个互不调用的域，只通过共享数据区交换信息。

```Plaintext
┌──────────────────────────────────────────────────────────────────┐
│                         Application 层                            │
│                 系统初始化编排、生命周期管理、模式调度               │
├────────────────────────────┬─────────────────────────────────────┤
│    通信域 (Comms Domain)    │       控制域 (Motor Domain)          │
│                            │                                      │
│  FDCAN / CANopen           │  20kHz FOC 热路径                    │
│    ├─ SDO (参数读写)        │    电流采样 → Clarke/Park            │
│    ├─ PDO (控制指令/反馈)   │    → 电流环PI → 死区补偿             │
│    ├─ NMT/Heartbeat/EMCY   │    → 前馈 → Park逆 → SVPWM           │
│    └─ OTA (固件升级)        │                                      │
│  LPUART (调试遥测 5Mbps)   │  2kHz 速度环 / 位置环                 │
│  UART1 (OTA 备用)          │  观测器 (有感 / SMO / ESO / HFI)      │
│  串口命令行 (CLI)           │  参数辨识 / 标定                      │
│  OLED / LED 灯语           │                                      │
│                            │  三角函数 (硬件CORDIC / 查表+插值)     │
│  运行方式: RTOS 线程        │  运行方式: 裸机中断驱动                │
├────────────────────────────┴─────────────────────────────────────┤
│                        共享数据区                                  │
│  ControlCommand (通信域→控制域) / MotorTelemetry (控制域→通信域)    │
└──────────────────────────────────────────────────────────────────┘
```

**关键约束**：

- 控制域绝不调用通信域的任何函数

- 通信域绝不调用控制域的任何函数

- 域间只通过共享数据结构交换信息

## 二、五层架构

```Plaintext
┌──────────────────────────────────────────────┐
│  App 层                                      │
│  系统初始化编排、生命周期管理、模式切换调度     │
│  唯一知道所有具体类型的地方                    │
├──────────────────────────────────────────────┤
│  Service 层                                   │
│  纯逻辑层，不碰任何寄存器                      │
│  motor/ | comms/ | ota/ | calibration/       │
│  fault/ | test/  | debug/                    │
├──────────────────────────────────────────────┤
│  Platform 层                                  │
│  板级定义、引脚映射、资源分配、产品配置         │
├──────────────────────────────────────────────┤
│  Driver 层                                    │
│  按功能域分组，封装 HAL，提供类型安全接口       │
│  encoder/ | current_sense/ | gate_driver/    │

│  adc/     | math/ (三角函数)                  │
```

**依赖规则**：单向依赖，上层只依赖下层接口。下层完全不感知上层。跨层访问绝不允许。

### 4\.2 核心接口定义

```C++
// 观测器接口
class IObserver {
public:
    virtual ~IObserver() = default;
    virtual bool init() = 0;
    virtual void update(float ia, float ib, float ua, float ub) = 0;
    virtual float getTheta() const = 0;
    virtual float getOmega() const = 0;
    virtual bool  isConverged() const = 0;
    virtual void  reset() {}                           // 默认空实现
};

// 前馈接口
class IFeedforward {
public:
    virtual ~IFeedforward() = default;
    virtual float computeUd(float id_ref, float iq_ref, float omega) = 0;
    virtual float computeUq(float id_ref, float iq_ref, float omega) = 0;
};

// 死区补偿接口
class IDeadbandCompensation {
public:
    virtual ~IDeadbandCompensation() = default;
    virtual bool learn() = 0;
    virtual void compensate(float ia, float ib, float& ua, float& ub) = 0;
};

// 指令处理接口
class ICurrentCommandProcessor {
public:
    virtual ~ICurrentCommandProcessor() = default;
    virtual void process(float& id_ref, float& iq_ref, 
                         float omega, float load_est) = 0;
};

// 电流采样接口
class ICurrentSensor {
public:
    virtual ~ICurrentSensor() = default;
    virtual bool init() = 0;
    virtual void sample(float& ia, float& ib) = 0;
    virtual float getDCLinkVoltage() const = 0;
    virtual float getTemperature() const { return 0.0f; }  // 默认
    virtual void  calibrateOffset() {}                       // 默认
};

// 定时器接口
class IPWMTimer {
public:
    virtual ~IPWMTimer() = default;
    virtual bool init(const PWMConfig& cfg) = 0;
    virtual void setDuty(uint8_t motor_index, const PWMOutput& duty) = 0;
    virtual void enable(uint8_t motor_index) = 0;
    virtual void disable(uint8_t motor_index) = 0;
    virtual void emergencyOff(uint8_t motor_index) = 0;   // 硬件急停
    virtual uint8_t motorCount() const = 0;
};

// 三角函数接口 (Driver/math)
class ITrig {
public:
    virtual ~ITrig() = default;
    virtual void sincos(float theta, float& sin_out, float& cos_out) = 0;
    virtual float atan2(float y, float x) = 0;
    virtual float sin(float theta) = 0;
};
```

### 4\.3 三角函数实现选择

|实现|Park变换|PLL atan2|扫频sin|移植性|
|---|---|---|---|---|
|硬件CORDIC \(G474\)|12 cycle|12 cycle|12 cycle|仅G4|
|查表256\+插值|20 cycle|arm\_atan2 ≈200 cycle|20 cycle|全平台|
|CMSIS\-DSP|arm\_sin\_cos ≈200 cycle|arm\_atan2|arm\_sin|全平台|

**策略**：FOC ISR 用硬件 CORDIC（独占，prio 0不被打断），扫频测试用查表\+插值。两者通过 ITrig 接口各自持有独立实例。

### 4\.4 MotorCore 热路径

```C++
class MotorCore {
    // 硬件依赖
    ICurrentSensor& current_sensor_;
    IPWMTimer&      pwm_timer_;
    ITrig&          trig_;              // CORDIC 或查表
    uint8_t         motor_index_;
    
    // 策略依赖 (初始化注入，运行时不改)
    IObserver*              observer_ = nullptr;
    IDeadbandCompensation*  deadband_ = nullptr;
    IFeedforward*           feedforward_ = nullptr;
    ICurrentCommandProcessor* cmd_proc_ = nullptr;
    
    // 调试遥测 (可选)
    TelemetryStream*        telemetry_ = nullptr;
    
public:
    // 20kHz TIM 中断直接调用，约 750 cycle (160MHz)
    void tick() {
        current_sensor_.sample(ia_, ib_);
        observer_->update(ia_, ib_, ud_ref_, uq_ref_);
        theta_ = observer_->getTheta();
        omega_ = observer_->getOmega();
        
        clarke_park(ia_, ib_, theta_, &id_, &iq_);  // 内部用 trig_
        
        ud_ref_ = id_pi_.tick(id_ref_, id_);
        uq_ref_ = iq_pi_.tick(iq_ref_, iq_);
        
        if (deadband_) deadband_->compensate(ia_, ib_, ud_ref_, uq_ref_);
        if (feedforward_) {
            ud_ref_ += feedforward_->computeUd(id_ref_, iq_ref_, omega_);
            uq_ref_ += feedforward_->computeUq(id_ref_, iq_ref_, omega_);
        }
        
        float ta, tb, tc;
        inv_park_svpwm(ud_ref_, uq_ref_, theta_, v_bus_, &ta, &tb, &tc);
        pwm_timer_.setDuty(motor_index_, {ta, tb, tc});
        
        #if TELEMETRY_ENABLE
        if (telemetry_) {
            BatchEntry batch[] = {{0x01,id_}, {0x02,iq_}, {0x03,omega_}, {0x04,theta_}};
            telemetry_->writeBatch(batch, 4);
        }
        #endif
    }
    
    // 2kHz 速度环
    void speedTick() {
        if (!enabled_) return;
        float omega_err = omega_ref_ - omega_;
        iq_ref_ = speed_pi_.tick(omega_err);
        if (cmd_proc_) cmd_proc_->process(id_ref_, iq_ref_, omega_, load_est_);
    }
};
```

**tick\(\) 开销分析 @ 160MHz**：

|操作|周期数|
|---|---|
|电流采样|\~50|
|观测器 \(有感编码器\)|\~100|
|Park变换 \(CORDIC\)|\~40|
|电流环PI ×2|\~160|
|死区补偿|\~30|
|前馈|\~20|
|Park逆\+SVPWM|\~250|
|遥测写入 \(4变量\)|\~30|
|**总计**|**\~680**|
|20kHz 周期容量|8000|
|占比|8\.5%|

## 五、通信域完整设计

### 5\.1 CANopen 精简策略

**保留的（CiA 301 完全兼容）**：

- SDO server \(OD 读写\) — 参数配置、OTA 触发、诊断

- NMT slave — 节点状态管理

- Heartbeat — 连接监控

- EMCY — 紧急故障报文

- SDO segmented transfer — OTA 固件传输

**裁减的（不再声称完整 CiA 402 兼容）**：

- CiA 402 状态机 → 精简为三态：IDLE → ENABLED → FAULT

- PDO 映射 → 自定义，只保留实际需要的对象

- 大量 Optional 对象 → 不实现，SDO 读返回 Abort \(0x06020000\)

**自定义 PDO 映射**：

```C++
// RPDO1: 主控 → 驱动板 (20字节)
struct MotorRPDO {
    uint16_t controlword;       // bit0:使能, bit1:失能, bit7:故障复位
    uint8_t  mode_of_operation; // 1=PP, 3=PV, 10=CT
    uint8_t  padding;
    int32_t  target_position;
    int32_t  target_velocity;
    int16_t  target_torque;
    int16_t  pos_kp;            // MIT: 位置刚度
    int16_t  vel_kd;            // MIT: 速度阻尼
};

// TPDO1: 驱动板 → 主控 (16字节)
struct MotorTPDO {
    uint16_t statusword;
    uint8_t  mode_display;
    uint8_t  fault_code;
    int32_t  actual_position;
    int32_t  actual_velocity;
    int16_t  actual_torque;
    int16_t  dc_link_voltage;
};
```

**MIT 控制 1kHz 回路**：RPDO \+ TPDO = 36B。CAN FD 64B/帧，一收一发 \~218μs，占 1kHz 周期的 21\.8%。

**OTA 改进**：一帧一 ACK，56B 数据段 \+ 4B seq \+ 4B CRC = 64B 刚好一帧。防止 5Mbps FDCAN FIFO 溢出。

### 5\.2 CANopen 中断两级分流

```Plaintext
FDCAN 接收中断
  ├── 快速路径 (ISR 内, <2μs):
  │     · PDO → 直接写 ControlCommand
  │     · NMT → 直接改状态
  │     · Heartbeat/SYNC → 消费
  │     · EMCY → 设置故障标志
  └── 慢速路径 (入 SPSC 环形队列):
        · SDO (读写OD, 分片重组)
        · OTA 固件块 (写Flash)
```

## 六、调试遥测系统

### 6\.1 设计方案

```Plaintext
FOC ISR (20kHz, prio 0):
  批量写入变量 → 三缓冲 (3×4KB) → 填满一个buffer → 置READY标志
  开销: ~30 cycle (memcpy 18-24字节)

2kHz tick 轮询:
  checkAndSend() → 发现 READY → 启动 LPUART DMA 发送
  开销: ~60 cycle (偶尔)

LPUART DMA 后台发送:
  5Mbps → 4KB 发送需 6.5ms
  DMA TC 回调 → 标记 SENDING → IDLE

上位机 Python:
  pyserial 读完整帧 (MAGIC + Header + Entries + CRC)
  → CSV 导出 → matplotlib 画波德图/阶跃响应
```

### 6\.2 帧格式

```Plaintext
┌──────────────────────────────────┐
│ Header (12 bytes)                 │
│  magic:  0xDA7A (2B)             │
│  version: 0x01 (1B)              │
│  buf_idx: 0/1/2 (1B)             │
│  sequence: uint32 (4B)            │
│  timestamp: uint32 (4B)           │
├──────────────────────────────────┤
│ Entry 0: var_id(2B) + float(4B)  │
│ ...                               │
│ Entry N: var_id(2B) + float(4B)  │
├──────────────────────────────────┤
│ Footer: CRC16 (2B)               │
└──────────────────────────────────┘
```

### 6\.3 带宽验证

|场景|变量数|填满耗时|发送耗时|持续？|
|---|---|---|---|---|
|扫频 @ 20kHz|3\-4|11\.4\-8\.5ms|6\.5ms|✅|
|扫频 @ 2kHz|4|114ms|6\.5ms|✅|
|全量 @ 20kHz|8|4\.3ms|6\.5ms|⚠️ 偶丢\(三缓冲兜\)|
|全量 @ 2kHz|8|42\.5ms|6\.5ms|✅|

### 6\.4 为什么不用 RTT

- RTT 必须 J\-Link，产品部署后不可用

- 调试器暂停 CPU 可能导致 MOSFET 桥直通烧毁

- RTT 闭源，无法二次定制

- 串口方案：RS485 两根线，任何笔记本可接，Python 原生集成

## 七、RTOS 角色

**原则**：RTOS 只做辅助。所有硬实时任务在裸机中断完成。

```Plaintext
中断优先级 (数字越小越高):
  TIM_FOC    (20kHz):  prio 0  ← FOC热路径，硬件CORDIC独占
  ADC 注入完成:        prio 1
  TIM_SPEED  (2kHz):   prio 2
  FDCAN RX:            prio 3
  UART / DMA TC:       prio 4
  TIM_BASE  (RTOS tick): prio 5

RTOS 任务:
  Task_CANopenProcess   prio 6,  1kHz,  1.5KB 栈
  Task_CLI              prio 5,  事件驱动, 2KB 栈
  Task_OTA              prio 5,  事件驱动, 2KB 栈
  Task_OLED             prio 4,  20Hz,  1KB 栈
  Task_LED              prio 3,  50Hz,  512B 栈
  Task_Logger           prio 3,  事件驱动, 2KB 栈
```

**RTOS 禁止碰的事**：FOC ISR、TIM CCR 寄存器、热路径数据锁。

## 八、状态机设计

### 8\.1 两层状态机

```Plaintext
大状态机 (SystemModeManager): 管理权限和安全
  IDLE ⇄ SETUP ⇄ CALIBRATION ⇄ TEST ⇄ ENABLED
    ↓                    ↓         ↓
  FAULT ←────────────────┴─────────┘
    ↓
  EMERGENCY

转移矩阵: isTransitionAllowed[from][to]
  权限判断: IDLE可OTA/改参数；ENABLED锁定参数

小状态机 (MotorModeManager): 仅在ENABLED下有效
  PP ⇄ PV ⇄ CSP ⇄ CSV ⇄ CT, HM
  用 switch + 条件 (条件比矩阵更合适)
```

### 8\.2 事件/时间分离

```Plaintext
事件响应层 (事件触发, 立即):  只写数据，不改状态
条件检查层 (2kHz tick):     读数据，判断转移，执行转移
行为执行层 (各自频率):       不关心状态转移，只管计算
```

状态转移只有条件检查层一个入口，消除并发冲突。

### 8\.3 SPI3 共享总线访问控制

```Plaintext
IDLE/SETUP/CALIBRATION:
  → SPI3 归任务 (OTA写Flash，日志写Flash)

ENABLED:
  → SPI3 归 FOC ISR (编码器B读取)
  → 任何任务不准碰 SPI3
```

归属切换通过系统模式决定，零运行时争抢。

## 九、故障诊断

### 9\.1 错误码体系

```C++
// 格式: 0xTTSSCCCC (Category + SubCategory + Code)
namespace ErrorCode {
    // MOTOR_A: 0x01xxxxxx
    constexpr uint32_t MOTOR_A_OVERCURRENT   = 0x01000001;
```

### 9\.2 故障记录器（防断电丢失）

```Plaintext
FOC ISR 检测故障:
  → FaultLogger::recordFromISR() [只写RAM, ~50ns]

FaultHandler 任务:
  → 读 RAM 故障记录
  → 通过 CANopen EMCY 上报
  → 尝试刷到 SPI Flash 持久化

如果中途断电:
  → RAM 丢了，但 EMCY 可能已发出
  → 下次上电 POST 读 Flash 里的上次故障记录
```

### 9\.3 故障分级

|等级|响应|停止策略|
|---|---|---|
|WARNING|只记录|无|
|RECOVERABLE|尝试重试，计次|阻尼停机|
|CRITICAL|立即停止，需人工|动态刹车|
|FATAL|硬件锁死|紧急刹车|

### 9\.4 停止策略

|策略|行为|
|---|---|
|COAST|关所有 MOSFET，惯性滑行|
|DYNAMIC\_BRAKE|下桥全导通，动能耗散|
|DAMPED\_STOP|速度环零速，可控减速|
|EMERGENCY\_BRAKE|硬件紧急关断|

## 十一、上电自检 \(POST\)

```Plaintext
POST (在初始化序列中，Driver 之前):
  1. 电源轨检测 (3.3V/5V/母线电压 ±10%)
  2. 外部存储检测 (W25Q128 JEDEC ID)
  3. 栅极驱动检测 (FD6288 是否存在)
  4. 编码器连通性 (AS5047 ID 寄存器)
  5. 电流偏置校准 (PWM关闭，采样100次取平均)
  6. CAN 总线检测 (发 Heartbeat)
  7. 上次故障记录读取 (SPI Flash)

任何一项 FAIL → FAULT 状态
全部 PASS → 继续初始化
```

## 十二、安全策略

- 故障发生时先记录（ISR安全），再刹车

- 停止策略根据故障类型选择（阻尼 vs 硬刹）

- 刹车和上报顺序：记录 → EMCY 上报 → 执行停止

- CORDIC 独占给 FOC ISR：最高优先级上下文不外借

## 十八、CANopen 精简

### 兼容性声明

- CiA 301 预定义连接集：完全遵循

- CiA 402 Mandatory 对象：完全实现 \(6040/6041/6060/6061\)

- CiA 402 Optional 对象：按需实现，其余返回 SDO Abort

- PDO 映射：自定义，非标准 402 映射

- 状态机：精简为三态，不声称完整 402 兼容

### 边界保证

- 任何标准 CANopen 主站可通过 SDO 读写你的 OD

- 任何标准主站可通过 NMT 控制你的节点状态

- Heartbeat/EMCY 标准格式

- 未实现对象返回 SDO Abort \(0x06020000\)，不挂死
