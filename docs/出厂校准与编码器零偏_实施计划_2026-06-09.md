# 出厂校准与编码器零偏 — 实施计划

> **日期：** 2026-06-09  
> **修订：** 2026-06-09 — 补充标定结束→FOC 首拍 raw 时序、`encoder_kick` 预热  
> **状态：** 已评审，可执行  
> **范围：** M1 单编码器（SPI1 / `enc_m1` / TIM8）、JEOC-only 控制、片内 Flash NVM  
> **前置：** ADC 零偏标定（Step C）已完成；开环 Uq=2 可转，但 Id≈Iq（`add` 未对齐）

---

## 1. 背景与目标

| 痛点 | 现状 | 目标 |
|------|------|------|
| 电角零偏 `add` | `angle_init()` 写死 ~2.1 rad | 方法 A 锁转子实测，`Id ≪ Iq` |
| 机械角方向 `mech_sign` | 无；台架曾靠宏 | **出厂必选**：低速限流速度阶跃判 `sign(ω)`，NVM 存 ±1（见 KTH 规划 §4.4） |
| 出厂标定 | 仅 ADC 零偏 | 可插拔步骤（probe、encoder zero、**mech_dir**、Rs/Ld…） |
| 持久化 | 无 | 片内 Flash 尾 4 KB，标一次长期有效 |
| OTA | scatter 占满 512 KB | 升级不覆盖 NVM 区 |
| 架构 | 标定逻辑易堆进 FOC | **COMMISSIONING 与 RUN 平级**，JEOC 只做分发 |

## 2. 架构原则

### 2.1 模式分层（最终形态）

```text
Layer 1 — 系统模式（lifecycle）
  INIT → COMMISSIONING → RUN → FAULT

Layer 2 — 各模式子状态
  COMMISSIONING: cal_runner（step0 → step1 → commit）
  RUN:           m1_jeoc_control_tick（FOC）

JEOC 唯一出口: system_jeoc_tick() / hadc2_jeoc_dispatch()
  INIT:           adc.cal_active | encoder_cal（MVP 临时）
  COMMISSIONING:  cal_runner_jeoc_tick → 当前 step
  RUN:            m1_jeoc_control_tick
```

### 2.2 纪律

- Step **不直接**擦 Flash；只有 `motor_cal_nvm_commit()` 可写 NVM
- 锁转子 / 辨识 **不写入** `m1_jeoc_control_tick`
- 标定 JEOC：**只 SVPWM，不 `encoder_kick`，不 FOC**
- 读角：阻塞 `AS5047_read(SPI1)`，不走 DMA 链
- W25Q128 只做 OTA 固件；**出厂 cal 只放片内 Flash**

## 3. 片内 Flash 分区（P1，今天不改 scatter）

```text
0x0800_0000 ─ 0x0807_EFFF   Application（scatter ER_IROM1 止于此前）
0x0807_F000 ─ 0x0807_F7FF   FACTORY_NVM 主记录（2 KB）
0x0807_F800 ─ 0x0807_FFFF   FACTORY_NVM 备份（2 KB）
```

Keil scatter 示例（P1）：

```text
LR_IROM1 0x08000000 0x0007F000  { … }   /* 尾 4KB 不链入 RO */
```

OTA/Bootloader 共用 `config/memory_map.h` 白名单，只刷 App 区。

## 4. 编码器零偏 — 方法 A（锁转子）

### 4.1 公式

```c
theta_meas = encoder_get_theta_el(&enc_m1, raw_avg, M1_POLE_PAIRS, 0.0f);
add = wrap_2pi(-theta_meas);
as5047_spi1.add = add;
```

### 4.2 与当前 JEOC-only 工程对齐

| 项目 | 说明 |
|------|------|
| 控制节拍 | `hadc2` JEOC，非 TIM8 UP |
| TIM8 | `HAL_TIM_Base_Start` + PWM CH1~3/CH4，**无** `Base_Start_IT` |
| ADC 零偏后 | `adc_sample_calibrate_offset` 会 Stop Base+CH4 → **锁转子前须重开全 PWM** |
| 标定 JEOC | `encoder_cal_jeoc_tick`: `setPhaseVoltage(uq_lock, 0, 0)` |
| 采样 | 阻塞 `AS5047_read` × 8~16 次平均 |

### 4.3 参数

| 参数 | 建议值 |
|------|--------|
| `Uq_lock` | 0.5 ~ 1.0 |
| 稳定时间 | 300 ~ 500 ms @ 20 kHz JEOC |
| `θ_ref` | 0 |
| 验收 | 开环 Uq=2，VOFA Id ≪ Iq；Iq 反号 → `add ± π` |

### 4.4 标定结束 → 正常 FOC 首拍时序（必读）

标定期间 **不 `encoder_kick`**，`encoder_get_raw()` 读的 `ctx->raw` 只在 DMA FRAME2 完成时更新（见 `as5047_async.c`）。阻塞 `AS5047_read` **不会**写 `ctx->raw`。

```text
标定 300~500ms:  encoder_cal_active=1 → JEOC 仅 setPhaseVoltage(uq,0,0)；DMA 链停
标定结束:        active=0 → 阻塞读平均 raw → 算 add → 写 as5047_spi1.add
JEOC 下一拍:     进 m1_jeoc_control_tick → encoder_get_raw() 可能仍是标定前的旧缓存
```

| 因素 | 说明 |
|------|------|
| 实际影响 | 锁转子下 raw 变化极小，**不是 bug**；最多 **1 拍 (~50 µs)** 用旧 raw + 新 add |
| 第二拍起 | FOC 末尾 `encoder_kick` 后 DMA 完成，`ctx->raw` 恢复刷新 |

**`encoder_cal_run_lock` 结束顺序（固定）：**

```text
1. g_encoder_cal_active = 1，JEOC 锁转子 300~500 ms
2. g_encoder_cal_active = 0          /* 先停标定 JEOC，再读角 */
3. 阻塞 AS5047_read × 8~16 → raw_avg → add → as5047_spi1.add
4. encoder_kick(&enc_m1)             /* 重启 DMA，预热 ctx->raw */
5. （可选）短等 DMA 完成（phase==IDLE 或 ~100 µs）
6. return → telem / RTOS → 正常 FOC
```

> **注意：** 在 `active=1` 时 kick 不能代替步骤 4——下一拍 JEOC 仍走标定路径；须在 **`active=0` 之后** kick。

## 5. 可插拔步骤接口（今天定 shape）

路径：`cal/cal_step.h`

```c
typedef enum {
    CAL_STEP_ADC_ZERO     = 0x01u,
    CAL_STEP_ENCODER_ZERO = 0x02u,
    CAL_STEP_RS_IDENT     = 0x08u,
    /* 只追加，不改号 */
} cal_step_id_t;

typedef struct cal_step_ops {
    uint16_t id;
    uint16_t required_mask;
    int  (*begin)(void *ctx);
    int  (*tick)(void *ctx);   /* 0=完成, 1=进行中, <0=失败 */
    void (*abort)(void *ctx);
    int  (*finish)(void *ctx);
} cal_step_ops_t;
```

**编译开关：**

```c
#define M1_RUN_ENCODER_CAL  1   /* 测 add 时开，测完改 0 */
```

**Init 顺序：**

```text
InjectedStart_IT → bsp_init → ADC 零偏
→ 开 TIM8 CH1/2/3 + 互补N + CH4 + Base
#if M1_RUN_ENCODER_CAL
  encoder_cal_run_lock(...)   /* 见 §4.4：active=0 → 阻塞读 add → kick 预热 */
#endif
→ telem_init → RTOS → 正常 FOC（首拍 JEOC 已有 kick 预热的 raw）
```

> 若未跑 `M1_RUN_ENCODER_CAL`，仍保留一次 `encoder_kick` priming（与现 main 一致）。

**JEOC 分支：**

```text
adc.cal_active        → adc_sample_on_injected
encoder_cal_active    → encoder_cal_jeoc_tick
else                  → m1_jeoc_control_tick
```

**验收：**

- [ ] Watch `as5047_spi1.add` 稳定
- [ ] 开环 Uq=2：Id 明显小于 Iq
- [ ] `M1_RUN_ENCODER_CAL=0` + 写入的 fallback 重启仍正确
- [ ] `encoder_cal_run_lock` 内：`active=0` 后阻塞读 add，再 `encoder_kick`（§4.4）

**不做：** scatter、NVM、runner、`sys_mode_t`
