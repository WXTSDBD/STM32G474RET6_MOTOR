## 2. 对象与失败机理（为何「正常环」接不上）

### 2.1 机电对象

- 轻惯量、**粘滞 B 接近 0**、凸极性强。  
- I/F：电频率像硬时钟，转子被力矩拖着跟——提供的是**频率刚度**，不是速度伺服。  
- 速度环：`Iq → ω` 近似 `1/(Js)`；空载时 PI 很容易进入极限环。

### 2.2 浅刹车为何「能跑」

`M1_IF_OBS_IQ_MIN_A = −0.25 A` 把执行器变成**几乎只能电动、很难发电**。  
极限环的「重刹半周」被掐掉 → 表现为大多正 Iq、转速晃、但能活。  
这是**非对称限幅拐杖**，不是速度环调好了。

### 2.3 为何②一松就炸（以 `1357` 为代表）

巡航状态机当前逻辑（`motor_outer_loop.c`）：

1. **①** `246`：`ω_ref→CRUISE_RPM`，续浅刹车 + 弱 PI，定时 `STAGE1_S`  
2. **②** `247`：清浅刹车，`out_min/max = ±CRUISE_IQ_ABS_MAX`（8 A），仍弱 PI，定时 `STAGE2_S`  
3. **③** `248`：写入 `CRUISE_PI_KP/KI`

录波现象：① 大致能跟 ~990 rpm（仍晃）；进入②后约 1 s 量级出现 `iq_ref` 大幅负向 → 转速 200↔1400 → θ 失锁。  
机理一句话：**残差振荡尚未收掉时，突然恢复大负向权威，等于给极限环加油门。**

### 2.4 与工业做法的差距

工业驱动通常：

- 角切 / 速切用**置信门控**（连续 N 拍），时间只作超时；  
- 切速瞬间 `ω_ref≈ω̂`、积分 bumpless；  
- 空载常加**虚拟粘滞 / 主动阻尼**；  
- **权威（限幅）与刚度（Kp/Ki）分开调度**，分级放开。

本工程已具备角/速软切与交接拐杖；缺的是阻尼项、门控升档、iq_min 阶梯。

## 4. 目标架构（建议状态机）

```text
S0 I/F ──► S1 角融 ──► S2 速切 ──► S3 阻尼巡航 ──► S4 iq_min 阶梯 ──► S5 正常 PI
              │            │            │                │
              │            │            │                └─ 弱 PI 不变，只放权威
              │            │            └─ Bd + 浅限幅；门控「晃够小」才离开
              │            └─ ω_ref≈ω̂ bumpless；反馈切 ω̂
              └─ θ̂；ω_ref=ω_IF；弱 Iq
```

设计铁律：

1. **时间只作最短等待 / 超时**；升档靠门控。  
2. **先权威、后刚度**：未到对称限幅前不要上最终 Kp/Ki。  
3. **浅刹车是拐杖，Bd 是阻尼**；空载最终环可保留小 Bd。  
4. 一次烧录只验一类风险（见 §5）。

## 5. 分步实现计划（按烧录节奏）

改动以 `motor_outer_loop.c/.h`、`motor_params_m1.h`、`m1_if_100rpm.profile.h` 为主；`motor_current.c` 仅在 VOFA/武装时机需要时动。每步 Keil **0 Error(s)** 后再下板。

### Step 0 — 基线锁死（不改控制律）

**做什么**：临时禁止 ①→②（拉长 `STAGE1_S`，或 `cruise_tick` 在 phase==1 不升级）。  

**验收**：长期 `open_seq=246`，浅刹车下可晃着跑 ~1000；作为后续对比基准。

---

### Step 1 — 主动阻尼 `Bd`（仍停在①）

**做什么**

- 新增宏：`M1_IF_OBS_DAMP_ENABLE`、`M1_IF_OBS_DAMP_BD`（单位建议 A/rpm，从极小开始）、可选 ω 一阶滤波截止。  
- 在 `outer_speed_pi_step`：PI 输出后  
  `iq -= Bd * omega_fb_filt`，再经现有 clamp / slew。  
- **不**改变 iq_min，**不**进入②。

**验收**

- 同工况下转速峰峰值明显下降；平均转速不被过度拖低。  
- 失败则减半 `Bd`（过大时正 Iq 顶限、转速塌）。

---

### Step 2 — ① 门控升级（仍不松刹车）

**做什么**

- `motor_outer_if_obs_cruise_tick` phase1：由 `phase_s >= STAGE1_S` 改为：  
  - `phase_s >= T_min`  
  - **且** 连续 `HOLD_S`：`|ω_fb−ω_ref| < e_enter` 且长窗 `|dω|` < 门限  
  - `T_max` 超时：保持①或置失败标志，**禁止硬升②**  
- 复用速切侧 DOMEGA 长窗思路（或 cruise 内独立窗）。

**验收**

- 能稳定出现「gate OK」再允许离开①；门限过严则先放宽，仍不松刹车。

---

### Step 3 — ② 改为 `iq_min` 阶梯（核心）

**做什么**

- 取消「清浅刹车 + 一步 ±8 A」。  
- 巡航期由 cruise 调度当前 `iq_min`（示例）：  
  `−0.25 → −0.6 → −1.2 → −2.5 → −8`；正限可稍后对称。  
- `outer_iq_ref_min` / soft_brake：巡航激活时以 cruise 的 `iq_min` 为准，避免定时到期直接跳回 `M1_SPEED_PI_OUT_MIN`。  
- 每升一档：门控同 Step2 + bumpless；**增益仍为交接弱 PI**。  
- `open_seq`：可用 `247` + 子相位，或 VOFA 另看当前 `iq_min`。

**验收**

- 每一档至少稳跑数秒：无大幅负向抽振、无失锁。  
- 卡在某档则停在该档调 `Bd`/门限，禁止跳档。

---

### Step 4 — ③ 最后爬刚度

**做什么**

- 仅当权威已到目标（或 −2.5 A 且空载已够）且门控 OK：  
  `kp/ki` **斜坡**至 `M1_IF_OBS_CRUISE_PI_*`（建议 0.5–1 s），避免阶跃改闭环极点。  
- `open_seq=248`；空载建议保留较小 `Bd`。

**验收**

- 空载可跟 1000、轻扰动不炸；再单独验手捏 / 带载。

---

### Step 5（可选）— 失锁降档

**做什么**：emag / |eω| / 掉速超限 → 收回紧 `iq_min`、弱 PI，必要时回 I/F。  

**时机**：S4/S5 空载通后再做，避免与升档调试缠在一起。

## 6. 烧录验收（Pass/Fail）

### 6.1 通用窗口口径

在 `open_seq=246` 且 `spd_on=1`、`ω_ref` 已到约 1000 后，取连续 **≥3 s**（建议 ≥10 s soak）：

| 量 | 通道 / 算法 |
|----|-------------|
| 转速晃幅 | `ptp(ch5)`（speed_fb） |
| 均值 | `mean(ch5)` |
| 跟踪 | `p95(|ch5−ch1|)` |
| 负向权威 | `min(ch2)`（Iq_ref） |
| 相位 | `open_seq` 必须保持 **246**（本固件 LOCK） |

对照包：历史 `1357` 的 246 段（无 Bd、随后进了 247）。本固件 **B0+B1 同烧**：锁① + `Bd=0.0004`；相对 1357① 看晃幅是否下降。

### 6.2 本固件烧录记录

| 烧录 | 配置 | 结果 |
|------|------|------|
| **1422 B1** | LOCK + 绝对 `Bd·ω`=0.0004，LPF 5 Hz | **Fail**：相对 1357①，`spd_fb` std 48→118、ptp 230→395；浅刹地板命中 ~25%。绝对粘滞在非对称 iq_min 下放大极限环。 |
| **B1b（待烧）** | LOCK + **HP** `Bd·(ω−ω_lpf)`=0.002，LPF **0.35 Hz** | 对照 1357① / 1422：`ptp` 须降；地板命中勿再暴涨 |

**B1b Pass**

1. 仍钉 `246` ≥10 s，`min(ch2)≥−0.30`  
2. `mean(ch5)` ∈ [900, 1100]  
3. 相对 **1357①**：`ptp(ch5)` 降 ≥20%（或至少明显优于 1422）  
4. 浅刹地板命中率不明显差于 1357①（勿再 ~25%）  
5. 不失锁  

| 步骤 | 烧录包名 | open_seq | ptp(ch5) | mean(ch5) | min(Iq_ref) | 地板% | 结论 |
|------|----------|----------|----------|-----------|-------------|-------|------|
| 1357① 对照 | 1357 | 246 | ~230 | ~1003 | ≥−0.35 | ~0% | 基线 |
| B1 绝对 | 1422 | 246 | ~395 | ~1018 | −0.25 | ~25% | Fail |
| B1b HP | 1433 | 246 | 稳健 p5–p95~28 | ~1000 | ≥0 | 0% | **Pass** |
| Step2+3a 门控→iq_min=-0.6 | （待填） | 246→247 | | | ≥−0.6 | | |

**本烧录验收（门控 + 第一档权威）**

1. 先见 `246`，约 ≥2.5 s 后出现 `247`（门控通过）；永不出现 `248`  
2. `247` soak ≥5 s：`mean(ch5)`∈[900,1100]；稳健晃幅不明显差于 1433  
3. `min(ch2) ≥ −0.65`（允许到 −0.6，禁止深负）  
4. 不失锁；无 1357② 式抽振  

Fail：进不了 247（门限过严可再放宽）/ 一进 247 就炸 / 出现 ±8 级负流。

分析脚本可继续放在 `MDK-ARM/_analyze_*.py` 或 `tools/`；对比以同遥测布局、同爬升斜率为前提。
