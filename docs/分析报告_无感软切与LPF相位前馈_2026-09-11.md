# 分析报告：中高速无感软切与 LPF 相位前馈效果（2026-09-11）

**对象**：STM32G474RET6_MOTOR，profile `m1_speed_1000rpm`  
**工况**：有感爬升 → 1000 rpm 软切 OBS（Park=θ̂，速度反馈=观测速）  
**编码器角色**：监督（角差超限不回切；过流/掉速仍可踢）  
**主录波目录**：`VOFA+CSV/20260911/`  
**结论摘要**：速度环真正切入观测速后，经「耦合切断 + e-LPF 相位模型前馈 + 有感残差」后，**角差直流偏置由约 −10° 压到约 +0.6°**，OBS 可持续约 1 min；遗留问题为 **1/rev 转频纹波导致的周期性异响**，不是 PLL 失锁。

## 1. 目标与验收口径

| 目标 | 口径 |
|------|------|
| 软切 | ch11 进入 3.x（OBS），角用 θ̂ |
| 速度无感 | OBS 后速度 PI 实际吃观测速（非仅 VOFA） |
| 角质量 | 相对编码器 `err=θ̂−θ_enc`：均值接近 0，\|err\|p95 可接受 |
| 可维持 | OBS 可持续数十秒级 soak（编码器不因角差回切） |
| 迁移性 | 相位主项用模型前馈；常值 OFF 仅残差、可标定 |

VOFA×12（本实验）：

| ch | 含义 |
|----|------|
| 0 | speed_fb（OBS 时为滤波后观测速，与 PI 一致） |
| 1 | ω_ref |
| 2 | iq_ref |

## 2. 问题演进（按录包）

### 2.1 `1351` / `1402`：角切成功，速切未进 PI

- 软切可进入 OBS，角误差 p95 约 10–14°。
- **实现缺陷**：每拍先把 `s_speed_fb` 写成编码器，再跑外环；OBS 覆盖发生在 PI **之后** → 速度环仍有感，VOFA ch0 却显示观测速。
- `1402`：OBS 约 30 s；误用编码器掉速门限曾导致假 FALLBACK（已改为 OBS 看观测速）。
- 中段约 11 s 极限环：更像 Park(θ̂) 与机电耦合，当时 PI 仍跟编码器。

### 2.2 `1447`：速切进 PI 后 OBS 变短

- 修正 ISR 顺序后，OBS 仅约 **7.7 s** 即因 \|err\|→30° 回切。
- 进 OBS 时 fb 从编码器 ~1015 跳到观测 ~943；回切瞬间编码器可达 ~1200。
- **机理**：观测速偏低时，PI 把「显示转速」拧到 1000，真速被抬高 → Park/SMO 负担大 → 更快滑步。

### 2.3 `1504`：关角差回切做 soak

- `M1_OBS_SS_FALLBACK_ON_ERR_ENABLE=0`，OBS 约 **52 s**。
- 前 ~20 s：\|err\|p95≈9–12°，较好。
- ~30 s 后：进入 **±30°、约 94 Hz** 振荡（均值仍≈0）→ θ̂→速度环→iq→SMO 的耦合极限环。
- 结论：不是滑模面「不在 0°」，滑模面是电流误差；94 Hz 是闭环角振荡。

### 2.4 耦合切断后 `1526`

改动要点：

- 观测速进 PI 前 **25 Hz** 一阶 LPF（切入从编码器 bumpless）
- EMF-PLL Fn：60→**45 Hz**
- e-LPF 线性系数 k：1.5→**1.2**

效果：

- **94 Hz ±30° 模态消失**
- OBS 全程约 **58 s**，无 FALLBACK
- 角差 **均值稳在约 −10°**（锁相，非常值失锁）
- 残差频谱以 **16.6 Hz（1/rev）+ 33 Hz（2/rev）** 为主
- 听感上可出现规律异响，与转频一致

### 2.5 模型前馈 + 残差 `1548`（当前最佳）

改动要点：

```text
θ̂ = θ_pll − THETA_OFF − φ_ff
φ_ff = −atan(fe / fc)     // fc 为当前 e-LPF 截止
```

- `M1_EMF_LPF_PHASE_FF_ENABLE=1`
- 去掉原手调 `THETA_OFF=−0.4054`（避免与前馈双计）
- 用 `1526` 离线反推：仅前馈、OFF=0 时 mean(err) 会到 **+6.57°**
- 残差写入：`THETA_OFF = +0.1147 rad（+6.57°）`

| 指标 | 1526（无前馈） | 1548（前馈+残差，干净段 9–63.5 s） |
|------|----------------|-------------------------------------|
| err 均值 | **−10.0°** | **+0.59°** |
| \|err\| p95 | ~18.8° | **~15.0°** |
| fb 均值 | ~994.5 | ~993.6 |
| OBS | ~7–65 s | ~7–66 s |
| 主导交流 | 1/rev | 仍为 1/rev |
| 结尾 | 正常结束 | ~64 s 起手动碰电机 → 66.07 s FALLBACK（外扰） |

**离线预测与实机一致**：直流偏置被压到约 0°。

## 4. 机理小结

### 4.1 为何曾像「周期性失步」

- **1504 后半**：94 Hz 大幅角振荡 → 像反复失步；实为极限环。
- **1526/1548**：PLL **锁在均值附近**；规律感来自 **1/rev（16.6 Hz）** 纹波，不是丢周期（无大角度跳变）。

### 4.2 滑模面 vs 角误差

- 滑模面：`s = î − i`（安培），期望在 0 A 附近。
- VOFA ch3：电角误差，期望直流≈0、交流尽量小。
- 角直流偏置主要来自 **e-LPF 相位 + 残差**；前馈针对前者，常值 OFF 针对后者。

### 4.3 前馈是否随转速变

- `fc = clip(k·fe, min, max)` 在线性段：`φ ≈ −atan(1/k)` **几乎不随转速变**。
- 触顶/触底后：`φ = −atan(fe/fc)` **随转速变**。
- 1000 rpm、k=1.2 时 fe≈117、fc≈140，处于线性段。

### 4.4 残差为何不能写死给所有电机

`+0.1147 rad` 来自本机 `1526` 有感对照。换电机或大改 k/Fn 应重标：

```text
θ_off ← mean(err)   // 在「已开前馈」的稳态下
```

或产线/IF：`θ_off ← −mean(wrap(θ̂ − θ_ref))`。沿用的是流程，不是某一个角度常数。

## 5. 周期性异响说明

1548 干净段后半：\|err\|p95 与转速峰峰值缓慢变大（约 12°/70 rpm → 18°/120 rpm 量级），频谱仍为 1/rev。

**听感**：约 60 ms 一圈的规律异响 → 与转频转矩/转速纹波一致。  
**不是**：PLL 失锁、前馈失败、94 Hz 复发。

后续可选项（未做）：OBS 下略降速度 KI、观测速 LPF 再降、转速自适应陷波、机械动平衡排查。

## 6. 效果评价

| 项目 | 状态 |
|------|------|
| 角软切 OBS | ✅ |
| 速度环真切观测速 | ✅ |
| 假掉速回切 / 94 Hz 耦合 | ✅ 已抑制 |
| 角直流偏置 | ✅ 约 −10° → **+0.6°** |
| 长 soak（监督编码器） | ✅ 约 1 min 级 |
| 1/rev 异响与转速纹波 | ⚠️ 仍在，后半更明显 |
| ISR 尖峰（p95≫8000） | ⚠️ 仍在，另案 |
| 换电机通用 θ_off | ⚠️ 需标定流程，不可抄残差 |

**总体**：中高速「角+速」无感联调达到可演示、可 soak 的阶段性目标；工业上可迁移的相位主路径（模型前馈）已落地，残差走标定。下一阶段重点是 **转频纹波/异响** 与 **低速无感（IF/HFI）**，而非再纠结 −10° 手调。
