## 2. 架构约定（给 HFI 用的接口语义）

后续观测源（HFI / SMO）应遵守，避免再长「正转专用森林」：

| 约定 | 说明 |
|------|------|
| 阈值用 **`|ω|`** | 软切进入、巡航阶跃、门控误差均按绝对值 |
| **DIR 只乘转速目标** | `M1_IF_DIR_SIGN` 或运行时 `motor_if_set_target_rpm` |
| I/F / 交接 **Iq 保持 +|Iq|`** | 勿 `DIR × Iq_boot`（2121）；反转勿有符号 `e=ref−fb` 拧负（2127→`|ω|` PI） |
| 限权 | `out_min=−regen`，`out_max=+drive`（与转向无关） |
| 产品分工 | **低速/零速/重载 → HFI**；**中高速 → SMO**；交接走同一软切/外环 |

代码落点：`motor_if.c`（运行时目标）、`motor_outer_loop.c`（`|ω|` PI、DIR_SEQ、巡航）、`motor_current.c`（交接 / 滑行清观测）、`obs_soft_switch.c`。

### 2.1 DIR_SEQ 宏（profile）

| 宏 | 典型值 | 含义 |
|----|--------|------|
| `M1_IF_OBS_DIR_SEQ_ENABLE` | 1 | 正→滑行→反 |
| `M1_IF_DIR_SIGN` | +1 | 首腿正转；反转由运行时改目标 |
| `M1_IF_OBS_DIR_SEQ_FWD_HOLD_S` | 3 | 正转巡航① 后再松手 |
| `M1_IF_OBS_DIR_SEQ_COAST_MIN_S` | 2 | 松手后再判近零 |
| `M1_IF_OBS_DIR_SEQ_COAST_MAX_S` | 8 | ω̂ 假挂超时强制反起 |
| `M1_IF_OBS_DIR_SEQ_EMAG_STOP` | 0.55 | Iq=0 后 emag 噪声地板≈已停 |
| `open_seq` | 246 / 230 / 231 / 232 | 巡航① / 滑行 / 待反起 / 反转腿结束 |

DIR_SEQ 开时关 STEP/S3，锁①（浅刹）。

## 3. 明确欠账（SMO 回填，不挡 HFI）

1. `248` 满 ±Iq + 爬 PI（空轴极限环风险仍在）。  
2. ③ 地板命中与更大减速探针。  
3. 滑行/零速时 ω̂ 品质（假挂）；长期应观测器复位策略或停转置信，而非只靠超时。  
4. 交接抖品质、带载。  
5. 失锁降档 / sync loss。

## 4. HFI 开干入口（建议）

### 4.1 目标分层

| 阶段 | 目标 | 验收草案 |
|------|------|----------|
| H0 | 注入 + 解调出可用凸极角（堵转/近零） | θ̂ 稳定、噪声可量化 |
| H1 | 零速/低速力矩可控（开环或弱闭环） | 能缓慢转、不失控 |
| H2 | 低速速度环（仍 HFI 角/速） | 跟 `|ω_ref|` 数百 rpm 内 |
| H3 | HFI→SMO 软切 | 同一 `obs_soft_switch` / 外环；门限约数百～800 rpm 带 |

### 4.2 不要做的事

- 为 HFI 再写一套只认正转的外环。  
- 未通 H0/H1 就先抠 SMO 满 PI。  
- 低速重载指望 SMO（产品上本就不归 SMO）。

### 4.3 与现网衔接

- 外环：继续 `|ω|` + 分级 `regen/drive`。  
- 软切：增加「观测源 = HFI / SMO」状态，转速/置信门限切换，复用 BLEND。  
- I/F：可作为 HFI 未就绪时的备援爬升，或逐步被 HFI 零速起机替代。
