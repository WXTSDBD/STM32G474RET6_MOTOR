## 0 前置（必做，否则后面不可验证）

### 0.1 提交当前工作区

- `git status` 里源码改动 + 未跟踪 `defaults_obs.h` / `defaults_outer.h` 先提交；
- 跑 `python tools/pkg_snapshot.py --name <日期>_pre7step` 冻结基线。

### 0.2 三个脚本（放 `tools/`，stdlib，只读）

**A. `route_vs_profile.py`**（S1 前提）
```
输入：config/routes/r_*.c、8 份 profile 的 -dM 导出
输出：逐字段对照表 route 值 | profile 值 | 差异
判据：全部相等才允许 S1；不等则列出字段并停
```

**B. `dM_eval.py`**（S1/S4/S7 前提）
```
输入：-dM 文本 + 源文件
输出：每条 #if/#ifdef 的当前真假；死支区间行号（json + 人读）
支持：defined()、!、&&、||、比较运算、宏值替换
判据：能与手算抽查 10 条一致
```

**C. `count_if.py`**（每步收尾）
```
输出：#if 总数、按目录、M1_* 名字数、M1_* 分支内行数（就是本会话用的普查脚本）
```

> 已有工具直接复用：`tools/quickcheck.ps1`（单文件语法）、`tools/pkg_snapshot.py`（包）、`tools/macro_map.py`（宏归属）。

### 0.3 每步固定动作

```
1) -dM before（当前配置）
2) 改（一次只动一个文件/一族）
3) quickcheck 单文件 → Keil Rebuild 0E/0W
4) -dM after + hex.sha256 对比
5) count_if.py 记录 #if 数
6) pkg_snapshot 打包
7) 台账追加一行
```

## 1 S1 · 旧机制 + 标定链（−200，零台架）

### 范围
| 对象 | 现状 | 动作 |
|---|---|---|
| `config/bringup_modes/` 6 文件 | 45 个 `#if` | **整目录删** |
| `config/route_use_from_id.h` | 8 | 删（profile USE_* 不再需要） |
| `config/bringup_bench.h` | 16 | 删或并入 route |
| `config/profiles/*.profile.h`（8 份） | ~1,438 行 | 值核对后删 |
| `config/bringup_active.h` | `M1_BRINGUP_MODE`、`M1_EXP_BOOT_*` | 改成两个值：`M1_ACTIVE_ROUTE_ID`、`M1_BOOT_EXP_ID` |
| `config/motor_params_m1.h` | `M1_BRINGUP_MODE` 48 处、include 链 `:98-108` | 删条件与 include |
| `ident_module.c` 26 / `ident_flow.c` 18 / `speed_ident_module.c` 23 / `l_hfi_ident.c` 16 | 死支 | `dM_eval` 标出后删 |
| `deadband_id_cal.c` 31 / `deadband_flow.c` 15 / `deadband_id_cal.h` 9 | 死支 | 同上 |

### 顺序（不能反）
1. 跑 `route_vs_profile.py`，全部相等；
2. `motor_current_init()` 改：
   ```c
   exp_runner_select(M1_BOOT_EXP_ID);
   exp_runner_arm(ctx);
   ```
3. 删 bm_*/profiles/EXP_BOOT/route_use 链；
4. `dM_eval` 标死支 → 删（保留当前配方 PASS0/REV141 需要的分支）；
5. Rebuild + hex 对比。

### 判据
- **hex 逐字相同**（当前配置 route1 + REV141）；
- `-dM` 允许 bm/profile 宏消失，但 route 相关值不变（由 A 脚本证明）；
- PASS0 配方不丢：改 `M1_BOOT_EXP_ID=EXP_ID_CALIB_CHAIN` + route 9 能编译且行为可解释。

### 风险/回退
- 值缺失（某 profile 值 route 里没有）→ A 脚本报错即停，补齐 route 再继续；
- 回退：单包恢复。
