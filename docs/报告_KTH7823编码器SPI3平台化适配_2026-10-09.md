# 报告：KTH7823 @ SPI3 编码器平台化适配（台架冻结）

- **日期：** 2026-10-09  
- **对象：** STM32G474RET6_MOTOR · M1 角源由 SPI1+AS5047 切至 SPI3+KTH7823  
- **规划：** [`规划_KTH7823编码器SPI3适配_2026-10-08.md`](./规划_KTH7823编码器SPI3适配_2026-10-08.md)  
- **架构背景：** [`SPI编码器架构实现说明.md`](./SPI编码器架构实现说明.md)  
- **台架结论：** 有感热路径可冻结；出厂 NVM / COMMISSIONING 工程化后置（与参数辨识等同批做）

---

## 1. 结论（一页纸）

| 项 | 结论 |
|---|---|
| 平台化目标 | 用现有 `encoder_t` / `encoder_driver_t` / `encoder_spi_bus` 接 KTH，不重写 FOC |
| 台架有感 | **通过**：锁转子零偏 + 速度环 80/100/300/500 rpm 稳态可跟；ISR 余量充足 |
| 控制模型 | **未改**外环/速度 PI 公式；14→16 bit 在芯片层换算为 rad 后对环透明 |
| 「奇怪问题」 | 曾飞车 / 低速狂晃 / 「不转」——根因是 **机械角符号与实验形态**，干净速度环下 **未复现** |
| 出厂必做（后置） | `encoder_add`、`encoder_mech_sign` 写入 NVM + 自动判定；禁止靠板型硬编码长期顶替 |
| 架构再改 | **不必**；P6 注册表收口 / 文档菜谱为可选 tidy |

## 2. 改了什么（按层）

### 2.1 硬件 / Cube

- SPI3：**Mode3**，分频与 AS5047 同量级；DMA1 **Ch6 RX / Ch7 TX**；CS=**PA15**（空闲高）。  
- Flash CS（PD2）保持高，不进编码器事务。  
- AS5047（SPI1+PA4）驱动 **保留可编译**，`M1_ENCODER_SRC` 可切回。

### 2.2 L1 编码器薄层（平台化关键）

- `encoder_driver_t` 补齐芯片无关钩子：`raw_to_theta_el` / `blocking_read_angle` / `xfer_busy` 等。  
- `encoder_get_theta_el` **不再写死 AS5047 14bit**，转发 `drv->raw_to_theta_el`。  
- `encoder_cal` 走通用阻塞读 / idle，不强转 `as5047_ctx_t*`。  
- 静态注册表骨架：`Drivers/encoder/encoder_chip.{c,h}`（AS5047 / KTH7823 表项）；board 仍可用宏直绑。

### 2.3 L2 芯片驱动

| | AS5047（旧默认） | KTH7823（台架默认） |
|---|---|---|
| 路径 | `Drivers/as5047/` | `Drivers/kth7823/` |
| SPI | Mode1 · SPI1 | Mode3 · SPI3 |
| 热路径帧 | 双帧（读角命令 + NOP） | **单帧** MOSI=`0x0000` |
| raw | 14 bit，`2π/16384` | 16 bit，`2π/65536` |
| board | `board_encoder_m1.c` + `ops_spi1_fast` | `board_encoder_spi3.c` + `ops_generic_g4` |
| DMA ISR | Ch2 | Ch6 → `board_encoder_spi3_dma_isr` |

### 2.4 板级 / bringup

- `board_encoder_m1_setup()`：按 `M1_ENCODER_SRC` 选 SPI1+AS5047 或 SPI3+KTH。  
- `config/bringup_bench.h` 台架冻结（示例）：
  - `M1_ENCODER_SRC = KTH7823_SPI3`
  - `M1_ENCODER_OFFSET_RAD = 3.181572f`（Ud 锁转子标定）
  - `M1_ENCODER_MECH_SIGN = +1`
  - `M1_ENCODER_DIR_REV = 0`
  - `M1_RUN_ENCODER_CAL = 0`（标定完成后冻结 add）
- `main`：未跑在线 cal 时 `encoder_set_theta_el_offset(..., M1_ENCODER_OFFSET_RAD)`。

### 2.5 控制热路径（刻意少动）

电流环仍是：

```text
get_raw → θ_el = raw_to_theta_el(raw, pp, add)     → Park / SVPWM
        → θ_mech = MECH_SIGN × unwrap(raw) → PLL → ω → 速度/外环
末尾 encoder_kick()；DMA 完成回调锁存 raw
```

- **`M1_ENCODER_MECH_SIGN` 只乘机械角 / 速度反馈，不乘电角**（见 `motor_current.c` 注释）。  
- 外环算法、`m1_sensed_pos_mit` 默认增益与换芯前一致；诊断期间曾临时改成速度-only，**不属于平台化必需改动**。

### 2.6 未做（明确后置）

- 出厂 `encoder_mech_sign` / `encoder_add` **NVM 落盘与 COMMISSIONING 步骤**（规划 P8 / 部分 P5）。  
- 混装板 chip **probe**（P7）。  
- board 全面改为仅经 `encoder_chip_lookup` 绑定（P6 收口，可选）。  
- KTH 上 HFI / 无感重签收。

## 3. 台架签收摘要（2026-10-08～10-09）

### 3.1 零偏

- 锁转子改用 **Ud 锁**（避免 Uq 且 Ud=0 时 SVPWM 走 `θ+π/2` 的假锁）。  
- 稳态 add：**`3.181572 rad`**，冻结进 bringup；VOFA ch 曾核对全程不变。

### 3.2 速度环（干净形态：OUTER=0，仅速度环）

| 给定 rpm | 录波（示例） | 稳态观感 |
|---|---|---|
| 500 | `VOFA+CSV/20261009/vofa+202610082134.csv` | 稳，`w_std≈24`，`isr_delta` med≈4790 |
| 300 | `...2142.csv` | 稳，同级 |
| 100 | `...2148.csv` | 稳；FFT 主峰 ≈ **14×f_mech** |
| 80 | `...2155.csv` | 稳；14× 仍主峰，5–7× **未放大** |

- `isr_delta`（DWT cycle）全程远低于 20 kHz 预算（约 28 µs / 50 µs）→ **不是 SPI/ISR 读爆**。  
- 可烧录包目录：`MDK-ARM/_pkg/20261009_kth7823_speed*_diag/` 等。

### 3.3 纹波（非适配缺陷）

- 100 rpm：`f_mech≈1.67 Hz`，ω/iq 主峰 ≈ **23.4 Hz = 14×f_mech = 2×f_el**（极对数 7）。  
- 80 rpm：主峰跟随至 ≈ **18.7 Hz**，仍为 14×；相对幅值与 100 同级。  
- 解释：齿槽 / 二次电转矩纹波锁转频谐波；低速相对更显眼，**不是 16bit 换算错误**。

## 4. 「奇怪问题」：现象、根因、为何后来不复现

联调中段出现过三类「编码器好像坏了」的观感，**在干净配置下均未再复现**：

### 4.1 飞车（ω 冲到数千且常为负）

- **现象：** 电角已能出力甚至飞转，速度环却正反馈起飞。  
- **根因：** `MECH_SIGN` 与安装/raw 方向不一致 → **只翻了速度反馈、电角仍正确** → 「能转但飞」。  
- **处理：** 台架冻结 `MECH_SIGN=+1`（配合当前安装）；**产品侧必须出厂标定写入，不能长期手改宏。**

### 4.2 「不怎么转 / 像位置在 hold」

- **现象：** 恢复「旧 profile」后轴几乎不动，`w_ref≈0`。  
- **根因：** 旧档是 **OUTER_NEST + SIGNOFF 位姿时间表**，不是自由速度环；被误判为「换编码器后速度环废了」。  
- **处理：** 对照实验改回速度-only 后恢复正常巡航。

### 4.3 低速时快时慢（旧 80 rpm 波）

- **现象：** `vofa+202610082008` 一类：中位能跟、但 `w_std` 大、偶发倒转。  
- **后来：** 同增益、同电机、干净速度-only 下 **80/100 均稳**；FFT 显示主谐波为 14× 机械频，并非环模型突变。  
- **根因归纳：** 当时叠加了符号折腾、限流/外环乱改、实验形态不一致；**不是「14→16 后速度环不能用」**。

### 4.4 一句话

> 能飞转说明电角大体可用；飞车说明速度观测符号坏了；「不转」多半跑错了外环实验；干净速度环下适配问题不复现。

## 5. 出厂 / 机械侧必提醒（后置工程化清单）

以下与「参数辨识 + 出厂设置」同批做即可，但**不要丢**：

1. **机械角方向（最高优先级）**  
   - 磁环朝向、芯片安装旋转、联轴器翻面都会改 `sign(ω)`。  
   - 必须 COMMISSIONING：**低速限流速度阶跃** → 写 `encoder_mech_sign`（±1）进 NVM。  
   - **未写入有效 sign：禁止上速度/位置外环**（仅允许锁转子 / 开环诊断）。  
   - 注意：规划强调方向与芯片型号正交；**只翻 MECH_SIGN、不管 DIR/raw** 曾导致「iq 顶满几乎不转」类症状，出厂流程要写清「电角与机械角符号策略」。

2. **电角零偏 `encoder_add`**  
   - 换芯片 / 换磁环后 **AS5047 旧 add（如 2.10）无效**。  
   - 锁转子建议 **Ud 锁**（见 `encoder_cal.c`），结果写入 NVM，勿只靠 bringup 宏量产。

3. **磁钢与气隙**  
   - 台架 raw 扫满、idle 步进正常，未表现严重偏心；仍建议出厂检：raw 连续、无大面积粘滞、AGC/诊断寄存器（若启用）合理。

4. **SPI / 电气**  
   - KTH 必须 Mode3；CS 空闲高；与 Flash 片选隔离。  
   - 热路径连续单帧已够用；若将来改阻塞探测，可参考「触发 + 再读」双帧习惯，与 AS5047 双帧语义区分文档化。

5. **实验纪律（研发）**  
   - 换编码器对照：**只改角源 + 重标 add/sign**，不要顺手改速度增益/关外环/换 SIGNOFF。  
   - 录波保留 `ω / ω* / enc_raw / isr_delta`，便于区分「符号 / 形态 / 真 ISR」。

## 6. 冻结口径（2026-10-09）

**冻结：**

- KTH@SPI3 驱动与 board 绑定；  
- 台架 `add=3.181572`、`MECH_SIGN=+1`、`DIR_REV=0`；  
- 「有感速度环在 KTH 上可用」的结论。

**不冻结为产品最终态：**

- bringup 宏代替 NVM；  
- 未自动化的 mech_sign 判定。

**下一任务：** 可离开编码器线；出厂编码器段并入后续「出厂设置 + 辨识」工程化包。
