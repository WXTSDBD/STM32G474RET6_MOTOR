## 1. 先答：为什么 Iq 拉起来之后，速度又被拉下去？

「不知道原因」多半是把几种机制混成了一种观感。按证据拆开：

### 1.1 AUTH 掐掉 FEED（最常见「假坏」）

链路：质量旗 `qual_ok` → 才允许 `FEED_A` 常数 Iq。  
`x` 塌 / 假锁指纹出现 → AUTH 清零 → **Iq 指令被掐成 0** → 轴靠摩擦/负载减速停转。

| 现象 | 根因 | 代表 |
|------|------|------|
| 冻 θ̂ 探查后「突然转不动」 | 冻角 → 解调 `x` 塌 → AUTH 掐 FEED | 昨日 **0014**（C4aa），日报已写 |
| 不冻角则同 FEED 正常转 | 证明不是「0.8 A 带不动」 | **0022** |

**不是电机被神秘力拉停，是 FEED 权限被质量门收回。**

### 1.2 开环 FEED 对抗静摩擦不够（物理掉速）

C4p 台架卡已写：静摩擦曾报 ~1.5 A；FEED=0.5 先验「轻出力不掉锁」，**转不动可接受**。  
常数 Iq、无速度闭环时：加速段惯性冲起来 → 若有效转矩（含角偏 `cosδ`）≤ 摩擦/负载 → **自然减速停**。  
观感像「拉起来又掉」，其实是 **开环没有维持转速的闭环**。

### 1.3 假锁 + 速度环顶流（今天傍晚 FAIL 枪）

角在真 q（`|err|~90°`，`ε` 钉 ±90°，`x→0`）时：

- 有效转矩很差或方向错；  
- 有感/无感速度环看见「没到 ω\*」→ **Iq 顶满**；  
- 轴乱抖或几乎不转 → 更像卡死，而不是平稳掉速。

代表：**1739 / 1829 / 1911 / 1959 / 2235 / 2306**。

### 1.4 阶梯上限 / 热路径事故（「好好的 100 突然毁」）

| 机制 | 表现 | 代表 |
|------|------|------|
| 热路径塞 float/每拍 VH | 100 rpm 起就 Peg | 2210 等（已复盘） |
| 阶梯加档毁编译形态 | 低档本可过、一加表就垮 | 见热路径报告 |
| VH 乱抬 / 三档乱切 | 低速更差 | 2203/2223 |

这些不是「FEED 物理掉速」，是 **控制/代码形态** 把环弄坏。

### 1.5 小结（Iq 拉起→掉速）

| 原因 | 速度怎么掉 | 怎么认 |
|------|------------|--------|
| AUTH 掐 FEED | Iq→0，轴滑停 | ch9 阶跃掉 0，同时 `x`/质量旗变差 |
| 开环+静摩擦 | Iq 仍在，ω 慢慢掉 | Iq 不变、ω 衰减 |
| 假锁+速环 | Iq 顶满，ω≈0 或乱 | `|err|~90°`，ε 钉 90° |
| 热路径/VH | 低档就崩 | 与上一枪仅差表/编译 |

## 2. 今天实验地图（`VOFA+CSV/20260929`，27 包）

### 2.1 分类总表

| 类型 | CSV（时刻） | 结果 |
|------|-------------|------|
| QKICK/捕获残留 | 1226, 1235, 1355 | 非速环主线 |
| Park=θ̂ + **enc 速环** PASS | **1700, 1721, 1758, 1922, 1948, 2007, 2020, 2102, 2139** | **成立** |
| 能转但角长期差 | **1342** | 有感托着 100，`|err|~90°` 十余秒后才收回 |
| FAIL 顶流/卡死 | 1739, 1829, 1911, 1959, **2235**, **2306** | 假锁或 HFI-FB |
| VH/表/热路径变差 | 2203, 2210, 2223 | 改坏低速 |
| GATE51 上限 | 2102≤400 PASS / 500 起差；2139≤700 PASS / ~750  cliff | 有感 FB 下的物理/观测上限 |

### 2.2 PASS 枪（有感速环）角度事实——必须写进结论

以 **1700 / 1758 / 1948 / 2102** 为代表：

| RUN 时刻 | 典型现象 |
|----------|----------|
| 0–0.2 s | `|err|` 常到 **50–80°**，部分靴 `ε` 大量近 ±90° |
| 同时 | **`wenc` 已近目标 100**（有感 FB 在出力） |
| 0.5–1 s | `|err|→~6–12°`，`Iq→~0.26 A`，`whfi≈wenc` |

**结论：**  
「加速度环角就永久崩溃」**不成立**。  
有感速环下角**会先崩一下，但靠真运动恢复**。  
无感速环 FAIL 枪缺的是这条恢复通道。

### 2.3 GATE52（HFI 速度 FB）为何做不了——今天钉死

| 包 | 设定 | 结果 |
|----|------|------|
| **2235** | `SPEED_FB=pll_int`，ω\* 阶跃 100 | 首拍 Iq=11，`|err|~97°`，不转 |
| **2306** | 同上 + ω\*=0 hold + 斜坡 0→100 + Iq≤3.5 | **hold0 段角已死**；其后 Iq 钉 3.5，仍不转 |

代码要点（与录波一致）：

1. `enter_run`：清 `xy_lp`、`pll_int=0`，IDLE 无注入 → 冷解调。  
2. `SPEED_FB` 吃 `pll_int`；零速时 FB≈0 → 与 ω\* 形成巨大误差或噪声 Iq。  
3. Park=θ̂ 自指：假锁后 ε 在估计系自洽，真转子 ~90°。  
4. 有感 PASS 靠 **enc 真速** 把轴拉出盆地；HFI-FB 没有等价物。

斜坡**指令轨迹是对的**（2306 的 ω\* 曲线正常），失败在 **角捕获/假锁**，不在「没做斜坡」这一条 alone。

### 2.4 有感阶梯上限（GATE51）

- **2102**：≤400 可用，上 500 出问题（另有报告）。  
- **2139**：≤700 可用，~750 cliff。  
- 转起来后 **`whfi` 可贴 `wenc`** → 估速能力有；**不等于**能用该估速从零自举。
