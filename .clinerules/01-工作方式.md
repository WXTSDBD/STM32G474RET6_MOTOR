# 工作方式（教你怎么干活）

## 0. 你不是在探索，你是在施工

本仓库 17,000+ 文件 / 33 GB，但**你真正会碰的不到 300 个**。
剩下的是 `Drivers/`、`Middlewares/`、`MDK-ARM/` 里的厂商代码和构建产物。

- **禁止**："先把仓库摸一遍"。
- **必须**：先读 `90-导航.md` 和 `docs/README.md`。东西在哪，那里写着。

## 1. 开工三步（固定动作，不许跳）

1. 读 `docs/README.md`（文档总索引）
2. 读 `docs/联调实例_INDEX.md`（所有实验的签收状态 + 快速切换）
3. 读本轮相关的 `docs/规划_*.md` 或 `docs/方案_*.md`

**这三步没走完，不许改任何文件。** 主人的规矩就写在这三处，不看就是瞎干。

## 2. 读代码：先定位，再只读局部

```powershell
# 第一步：拿行号（一次就够）
rg -n "foc_pi_step" -g "*.c" -g "*.h" motor/ platform/ config/ bringup/

# 第二步：只读那一段
Get-Content "motor/motor_current.c" | Select-Object -Skip 210 -First 40
```

- **禁止**把整个 `.c` 读进来。你的上下文是 1M，但**中间的信息你会漏**——
  读得越多，越容易错过关键那一行。主人的文件动辄几百行，只读相关区段。

## 3. 改代码：先看原文，再写 SEARCH 块

- 写 SEARCH / REPLACE 之前，**必须已经亲眼看过待改的那几行原文**（按第 2 条）
- 凭记忆写锚点 = 缩进/空格不匹配 = 编辑失败 = **重烧一整轮**，很贵
- 一次只改 1~2 个变量。主人原话：**「一步一个脚印，一次改一两个变量就上」**
- 大改动**先写方案**进 `docs/`，等主人点头再动刀

## 4. 分析 CSV：用现成的库，别自己写解析

`tools/` 下已经有共用库：

| 文件 | 干什么 |
|------|--------|
| `tools/vofa_io.py` | 读 VOFA CSV |
| `tools/vofa_layout.py` | 通道布局（12 通道定义） |
| `tools/vofa_analyze_lib.py` | 分析常用函数 |

**禁止**再写一个新的 `csv.reader` 循环。先看一眼有什么现成的：

```powershell
rg -n "^def |^class " tools/vofa_io.py tools/vofa_analyze_lib.py
```

## 5. 改完就自检（最重要的一条）

**每改一次 `.c` / `.h`，做下一个动作之前先跑：**

```powershell
.\tools\quickcheck.ps1
```

约 **1.8 秒/文件**，出结果。这是 Cursor 有、而你本来没有的能力
（它能收到 IDE 回传的编译错误，你收不到）。详见 `02-自检.md`。

- 改了固件 → 自检绿了之后，交付前**还要**编到 `0 Error(s) 0 Warning(s)`（见 `10-交付前编译.md`）
- 动了脚本 → **必须真的跑过一次**，把真实输出贴出来
- **不许**说"应该没问题"、"理论上可以"、"估计能过"

## 6. 结论必须标来源

每条结论后面标它是哪一种：

| 标记 | 含义 |
|------|------|
| `【事实】` | 从文件 / 日志 / 实测输出**直接读到的** |
| `【推断】` | 你根据事实推的，**还没验证** |
| `【待验证】` | 需要台架 / 示波器 / 主人确认的 |

主人靠这个区分哪些能信、哪些还要查。**不许把推断写成事实。**

## 7. 报进度用固定格式

```
【现状】一句话
【做了什么】关键动作 + 结果
【发现】事实 / 推断 分开写
【下一步】要干什么
【需要主人】没有就写「无」
```

## 8. 不确定就问，不要猜

猜错要重烧一轮（20 秒 + 钱），问一句 5 秒。

**尤其这几个绝不能猜**：主人的意图、实验参数取值、哪个 CSV 是「金样」、
要不要动 git、要不要删除文件。

## 9. 长任务把 TODO 写进文件

超过 5 步的任务，先把清单写进当天的文件
（`docs/` 或 `VOFA+CSV/<日期>/`），每完成一步就改它。
**不要只记在脑子里**——你会忘，然后原地打转。

## 10. 一轮内不要重读同一个文件

读过的就记住。**不要为了"再确认一下"重读。**

## 11. 输出要截断

终端输出可能很长（日志、目录树）。一律加限制：

```powershell
Get-Content "..." -Tail 20
... | Select-Object -First 30
```

**不要把几万行灌进上下文**，那既慢又淹没有效信息。
