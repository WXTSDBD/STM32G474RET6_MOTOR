# 项目地图（找东西先看这里）

**不要 `Get-ChildItem -Recurse`。这张表就是地图。**

## 目录职责

| 目录 | 里面是什么 | 能不能改 |
|------|-----------|---------|
| `motor/` | FOC 算法与编排。**零 HAL / 零 LL / 零 `main.h`** | ✅ |
| `motor/observer/` | `emf_pll` `emf_smo` `emf_veq` `hfi_*` `observer_composite` `obs_soft_switch` `obs_angle` `obs_inj` | ✅ |
| `motor/ident/` | `rs_ident` `ld_lq_ident` `ident_flow` `ident_module` `ident_bode_freq_table.h` | ✅ |
| `motor/deadband/` | `deadband_geo` `deadband_id_cal` `deadband_lut_baked_m1` `deadband_service` | ✅（先读该目录 `DEADBAND_VERIFY.md`） |
| `motor/speed_ident/` | `speed_ident_flow` `speed_ident_module` | ✅ |
| `platform/` | Port 契约头（无 HAL）+ 芯片 backend。`*_stm32g4_reg.c` 可碰寄存器 | ✅ |
| `board/` | 板级实例与 ops 绑定：`board_axis_ports` `board_encoder_m1` | ✅ |
| `config/` | `bringup_active.h`（**唯一实验开关**）/ `motor_params_m1.h` / `hal_bridge.h` / `bsp_axes` / `profiles/` | ✅ |
| `bringup/` | 新业务代码的家：RTOS 任务、BSP、`math_tables`、`COMMUNICATION_FDCAN` | ✅ |
| `debug/` | `app_uart_dma_debug`（遥测）/ `dbg_monitor` | ✅ |
| `tools/` | Python 工具链（先看 `tools/README.md`） | ✅ |
| `tools/ident/` | 辨识 / Bode 专用脚本 | ✅ |
| `docs/` | 全部设计与联调文档 | ✅ 只加，不改旧稿 |
| `VOFA+CSV/<YYYYMMDD>/` | 当天录波 CSV + 当天分析脚本 | ✅ 加 |
| `Core/` | **CubeMX 生成** | ⚠️ 见 `40-CubeMX生成文件.md` |
| `Drivers/` `Middlewares/` | ST HAL / FreeRTOS 厂商代码 | ❌ 别碰 |
| `MDK-ARM/` | Keil 工程 + 构建产物 + `_pkg/` 交付包 | ⚠️ 只读（`_pkg/` 可加） |

## 三个关键入口

| 入口 | 作用 |
|------|------|
| `config/bringup_active.h` | 选实验模式的**唯一**地方（`M1_BRINGUP_MODE`） |
| `config/profiles/*.profile.h` | 各实验参数档：`m1_if_100rpm` / `m1_hfi_standstill` / `m1_obs_veq_1000rpm` / `m1_speed_1000rpm` / `m1_flux_id_1000rpm` / `m1_bode_id_fc1000` / `m1_sensed_pos_mit` |
| `config/motor_params_m1.h` | 电机参数 |

## 文档命名约定（自己写文档时照抄）

前缀：`规划_` / `方案_` / `施工_` / `验证方案_` / `分析报告_` / `验收报告_` /
`总结_` / `签收_` / `联调日报_` / `结档_` / `backlog_`

格式：`<前缀>_<主题>_<YYYY-MM-DD>.md`，放 `docs/`。

**文件后缀日期 + 前缀**：主人靠这个扫文件列表就知道每篇是什么、什么时候写的。

## 常用搜索模板（复制改改就行）

```powershell
# 找某个符号在哪定义/使用
rg -n "obs_soft_switch" -g "*.c" -g "*.h" motor/ platform/ config/ bringup/ board/

# 找某个宏在哪定义
rg -n "#define M1_BRINGUP_MODE\b" -g "*.h" config/

# 找某个 profile 被谁用
rg -n "m1_if_100rpm" -g "*.h" -g "*.c" config/ motor/ bringup/

# 列当天录波
rg --files "VOFA+CSV/20261006"

# 看有哪些实验模式
rg -n "M1_BRINGUP_MODE_[A-Z_]+" config/ | Select-Object -First 40
```
