# 方案：无感代码收口施工（一步一测，2026-10-05）

**对象**：在 [规划_无感代码收口与接口冻结_2026-10-05.md](./规划_无感代码收口与接口冻结_2026-10-05.md) v1.2 口径下，把代码收到能冻的状态。  
**主人验证**：每步烧录后跑 **GATE 141 快速正反转**（`bringup_active.h`：观测到 ±1500 rpm 再保持 0.5 s 换向，5 轮；发布/注入跟 |ω|）。  
**全程锁定**：`M1_HFI_GATE=141`、HFI standstill profile。本方案 **不改算法、不改 GATE、不改 PI**。  
**施工默认**（规划已写死的）：Composite 一个对象；ops **两相位**（pre-park → Park → post-park）；inj 为 observer **之外**的 NULL 槽。

## 0. 怎么用这份方案

1. **一步只做一列表里的事**，编过、烧上、正反转过了再开下一步。  
2. 每步留下：`rebuild_log` 末尾 `0 Error`、一条 VOFA CSV、一句「5 轮换向是否完整」。坏了用上一步 hex 回退，不要在坏包上继续拆。  
3. 电流环里这三行的 **相对次序禁止改**（规划 §6.3，改了 F7 必挂）：

```text
hfi_sqwave_on_angle(...)           /* 相位 1 */
theta_park = hfi_sqwave_park_theta(...)   /* 可被 pub/handoff 覆盖，但须仍在 Park 之前 */
… sincos + Park …
hfi_sqwave_on_current(id, iq, iα, iβ)     /* 相位 2，吃本拍 dq */
```

4. 规划 §4.1（SMO/VEQ/PLL 的 `update` 要不要 `theta_enc` 对照）**拖到 P8**。P0–P7 保持现有 `emf_*_update(..., theta_enc, ...)`。  
   **不是同一题**：P6 的 `obs_pre_park(theta_enc, dt)` 只是转发今天的 `hfi_sqwave_on_angle(theta_enc_park, dt)`，不构成 §4.1 拍板。

实测口径（施工单必须认）：`motor_current.c` 全文件 **51** 种 `hfi_sqwave_*`，其中 **`motor_current_tick` 内 42 种**。P6 最多收 3 个角相位入口，P7 最多收 3 个电压相入口，tick 里还剩 **36** 种直呼，外加 init/握手 setter 等不在 tick 的符号。

## 1. 正反转怎么判「没坏」

GATE 141 相对 138：到速后再停 0.5 s 才翻。台架上看这几条即可，不必每步做离线脚本。

| 看什么 | 没坏 | 坏了（停，回退） |
|--------|------|------------------|
| 能跑完约 5 轮 +/−1500 | 换向次数对上，无卡死 | 中途停转、飞车、过流保护狂进 |
| 换向前 |ω| | 到 ±1500 附近再翻 | 远没到就翻，或到了不翻 |
| Park / 电流 | 换向时 Iq 跟指令、无持续顶满 | Id/Iq 炸、啸叫、桥臂异常 |
| 调试口 | VOFA 不断流、无 HardFault | 复位、DMA 卡死、链接都没过 |

**P0 必须先录一条金样 CSV**（通道表按你现在 GATE 141 的 12ch）。后面 P5 起结构一动，除「没坏」以外还要能对照金样：语义没改的通道不应整段变形。

### P6 — 两相位薄封装（角路径外壳，**不是** F5 收完）

tick 内 42 种 `hfi_sqwave_*`。本步 **只冻 3 个角入口**：

```c
void obs_pre_park(float theta_enc, float dt); /* 转发 on_angle；theta_enc 是今日 HFI 相位 1 输入，≠ §4.1 */
float obs_get_theta(void);                    /* 转发 park_theta + 现有 3467–3490 覆盖 */
void obs_post_park(float id, float iq, float ia, float ib); /* 转发 on_current */
```

`motor_current_tick` 的 **角路径** 改成只调这三个 + 中间 sincos/Park。tick 内其余 **39** 种 `hfi_sqwave_*` 仍允许直呼；P7 再收电压 3 个后剩 **36**。

SMO 的 `emf_*_update` 仍在电压之后（4127/4145/4165），不要塞进 `obs_pre_park`。  
pub/hand 对 `theta_park` 的覆盖必须仍在 sincos **之前**（3468–3469 / 3486 / 3489）。

**过（实指标，不是「电流环只认两相位」）**：

- 正反转 + 金样。  
- **本步只冻上述 3 个角入口**。  
- 附录列出 tick 内其余入口，**明确放到 P8 之后**（P7 只再收电压 3 个）。  
- 本步 **不等于 F5**。

### P7 — inj 电压相（§6.3 A 的一半）

**本步只冻电压相 3 入口**（PI 之后，约 3896 / 3912 / 3924）：

- `override_voltage`、`get_inj`、`get_inj_ab`

**本步不搬（给定相，PI 之前）**：

- `ctx->id_ref/iq_ref = hfi_sqwave_get_id_ref/get_iq_ref`（3606–3607；另有 3653、3704）  
- `ctx->omega_ref = hfi_sqwave_get_speed_ref_rpm`（3612 等）  
- `hfi_hand_rotate_current_pi`（3808）仍改 id/iq 积分——这是 P5 搬走的函数，**调用点留在 tick**

因此 P7 过后 **include HFI 私头仍然成立**。完整「电流环不认 `hfi_sqwave_*`」是 P8 收完 36 入口的事。

若要把给定相提前收：另开 `hfi_cmd_ops_t`（pre-PI），**不要**塞进电压 inj 表，且须单独一包正反转，勿与 P7 电压相混烧。

**禁止**：inj 写进角度 ops。  
**过**：正反转；|ω| 跟注入还在；VOFA Ud_inj 类通道不能变 0。此时角 3 + 电压 3 = **六入口已冻**，其余 36 仍直呼。

### L6 — 扫描余项怎么少步收（141 过线后再开，可选）

**每刀**：Keil 0 Error → 拷 hex 到 `MDK-ARM/_pkg/20261005_<刀>/` → GATE 141 CSV。141 上应变 Code≈68444 的刀可不烧，仍建议一眼正反转。
