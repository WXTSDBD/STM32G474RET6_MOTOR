## 2 目标形态

```
定义处一行 OBSERVE(x)
   → 链接期 .obs_tab（name + 绝对地址 + size）
   → 任务侧 obs_find("x") 解析成地址
   → 会话 obs_session_t{ addr[], n, decim } 双缓冲
   → ISR 帧边界原子换表，只做 4B 拷贝
   → 现有 snapshot 环 → 任务组帧 → DMA 发送
```

帧格式（保持 VOFA+ 兼容）：

```
[ seq f32 ][ ch0 f32 ] … [ chN-1 f32 ][ 00 00 80 7F ]
   ↑ 复用现有 4B 前缀        ↑ n≤12         ↑ JustFloat 尾
```

- `seq` 是 float32 帧序号（0…2^24-1 回绕，float 精确）；丢帧 = 离线脚本看 seq 跳变；
- 预设 id 不进流：变更时由控制口发一行，PC 侧记住；
- 尾 4B 保留，**不引入 2B 头**（会破坏 4B 对齐，VOFA 读成乱数）。

### 带宽预算（6 Mbaud ≈ 600 kB/s，建议 n×f ≤ 80 kSa/s）

| 配置 | 帧长 | 速率 | 占用 |
|---|---:|---:|---:|
| 4ch @ 20 kHz | 4+16+4 = 24 B | 480 kB/s | 80% ⚠ |
| **8ch @ 10 kHz** | 4+32+4 = 40 B | 400 kB/s | 67% ✅ |
| **12ch @ 5 kHz** | 4+48+4 = 56 B | 280 kB/s | 47% ✅ |
| 12ch @ 10 kHz | 56 B | 560 kB/s | 93% ❌ |

## 3 数据结构

```c
/* motor/telemetry/obs_reg.h */
typedef struct {
    const char *name;   /* 名字只在表里，不进数据流 */
    void       *addr;   /* 变量地址（Cortex-M 无 PIE，可存绝对地址） */
    uint16_t    size;   /* 1/2/4 */
    uint8_t     type;   /* OBS_U8/U16/F32 */
} obs_entry_t;

#define OBS_F32 0u
#define OBS_U32 1u

/* 登记：放在变量定义之后；static/全局变量才允许 */
#define OBSERVE(v) \
    const obs_entry_t obs_##v \
    __attribute__((used, section(".obs_tab"))) = \
        { #v, (void *)&(v), sizeof(v), OBS_F32 }

/* 结构体成员/自定义名字 */
#define OBSERVE_AS(nm, v) \
    const obs_entry_t obs_##v \
    __attribute__((used, section(".obs_tab"))) = \
        { nm, (void *)&(v), sizeof(v), OBS_F32 }

typedef struct {
    const volatile uint32_t *addr[12];  /* 选中的通道地址 */
    uint8_t  n;                          /* 1..12 */
    uint8_t  decim;                      /* 采样分频（1=每拍，2=每2拍…） */
    uint32_t seq;                        /* 帧序号 */
} obs_session_t;

/* 任务侧 API（只在任务/2 kHz 外环调用） */
uint8_t  obs_count(void);
const obs_entry_t *obs_entry_at(uint8_t i);
const obs_entry_t *obs_find(const char *name);
uint8_t  obs_session_set(const char *names[], uint8_t n, uint8_t decim); /* 0=接受 */
uint8_t  obs_session_names(char *buf, uint16_t len);                     /* LIST 用 */
void     obs_sample(float vals[12]);   /* ISR 调用，内部先判 pending */
```

## 4 链接期实现（Keil AC6 / armclang）

```text
; MDK-ARM/*.sct —— 放在 ER_IROM1 之后，同时把 ER_IROM1 尺寸相应缩小
ER_OBS_TAB +0 {
    *(.obs_tab)
}
```
- uvprojx → Linker → Misc controls 加：`--keep=*(.obs_tab)`（否则 `--gc-sections` 会把无人引用的表项删光）；
- 取表边界：
```c
extern const obs_entry_t Image$$ER_OBS_TAB$$Base;
extern const obs_entry_t Image$$ER_OBS_TAB$$Limit;
```
- **红线**：`Ropi/Rwpi = 0`（可重定位/位置无关必须关），否则表里的绝对地址无效；
- 每项 **12 B flash**；100 条 ≈ 1.2 KB，可接受；
- 只允许登记 **static/全局变量**，局部变量会悬空；4 B 对齐。

## 5 ISR 与切换时序

```
任务：obs_session_set(names…) → 填非活动槽 → pending=1
ISR（帧首）：if (pending) { active ^= 1; pending=0; seq=0; }
ISR（帧末）：for (i=0;i<n;i++) vals[i] = (float)*addr[i];
             vals[?] = seq++;            /* 前缀 */
             写 snapshot 环（满则 drop++）
任务：从 snapshot 环组帧 → DMA 发
```

- `pending` 是单字节，一次写/一次读，天然原子；
- 换表**只在帧边界**，一帧内 addr[] 不变；
- ISR 里**不查表、不 strcmp、不格式化**；
- 20 kHz 只做解引用 + 4B 拷贝，约 4–6 cycle/通道。

### 与旧链路的差异

| 项 | 旧 | 新 |
|---|---|---|
| 取值 | 12 个 getter 函数指针 | 直接地址数组（快、简单） |
| 通道集合 | 编译期 layout 表 | 运行期按名字解析 |
| 丢帧 | 无 seq | seq 跳变可检 |
| 切换 | `telem_set_layout()`（预设） | 任意名字组合（并保留预设） |

## 6 控制口选择（CLI 落地时才启用；本轮见 §10）

### 6.1 方案 A：两端口（推荐）

| 用途 | G474 现网 | AT32F456 新板 |
|---|---|---|
| 遥测 | LPUART1 / RS485 6 Mbps | USART3(PA6/7) / RS485 **5 Mbps** |
| CLI | USART1 115200（当前业务 0 引用，空闲） | USART2 **全双工**（PA2/PA3）115200 |

- 优点：CLI 独立于遥测链路，总线挂了仍可调试；VOFA 完全不受影响；实现最简单；
- 代价：AT32 上多占 1 个脚（PA3）——用 LED 3→1、HALL 6→2 腾出的脚补。

### 6.2 方案 B：单口复用（引脚实在不够时的备选）

同一 UART、同一波特率、半双工 RS485 同时承载遥测与命令。两个难点：

1. **VOFA JustFloat 是纯 float 流**：混入文本会错位，必须“整段切走”；
2. **半双工**：设备发遥测时主机不能发命令，否则总线碰撞。

做法（转义/模式切换）：

```
遥测模式：只发 [seq][ch…][tail]，VOFA 正常
  每 500 ms 停发 1 ms 切收（监听窗口）
  窗口内收到转义 AA 55 AA 55 → 回 OK CLI，进入命令模式（暂停遥测）
命令模式：纯文本行；OBS RUN 或 2 s 超时 → 回遥测模式
```

- 代价：协议复杂、VOFA 短暂断流、命令最坏 500 ms 延迟；
- 收益：省 1 个脚；
- **默认不用**，仅在 AT32 引脚不够时启用（届时把默认改成 B，并在 `70_平台_AT32.md` 记录）。

### 6.3 命令表（A/B 通用）

| 命令 | 作用 | 应答 |
|---|---|---|
| `OBS LIST` | 列出已登记变量与当前会话 | `OK n=… names=…` |
| `OBS SET ia,ib,iq,id` | 设置新会话（最多 12 个） | `OK` / `ERR unknown:xx` |
| `OBS RATE 2` | 设置 decim（1/2/4） | `OK` / `ERR bandwidth` |
| `OBS OFF` | 停发（保留串口） | `OK` |
| `OBS INFO` | 输出 drop/seq/带宽/版本 | `OK …` |
| `OBS RUN` | 仅方案 B：退出命令模式、恢复遥测 | `OK` |

- RX 用 **1 字节中断**（DMA1 满，命令很短）；任务里拼行、解析；
- 带宽守门：`n × (20kHz/decim) ≤ 80 kSa/s`，超限回 `ERR bandwidth`；
- 无主机时：NVM 预设 id → 开机用预设名字列表建会话；exp 段表可在运行期切换（不落盘）。

## 7 迁移步骤与验收

| 步 | 内容 | 验收 |
|---|---|---|
| **S1** 登记 | `obs_reg.h/.c` + `.sct` 段 + `--keep` + 先登记 5 个变量（`ctx.iq`/`ctx.id`/`ctx.ia`/`isr_delta`/`fault_code`）+ `OBS LIST` | map 有 `ER_OBS_TAB` 且 size=12N；`obs_find("iq")` 非 NULL；0E/0W |
| **S2** 会话 | 双缓冲 + `pending` + `obs_sample()` 替换 `telem_table_fill()`；帧前缀改 seq；USART1 命令 | 运行中 `OBS SET` 1–2 帧生效；VOFA 通道变化；ISR p50 退化 ≤3% |
| **S3** 收口 | `telem_table.c` 6 张 layout → 预设名字表；删 `isr_telem` 14 个 `#if`；`telem_ops_t.layout_id` → `preset_id` 并接 route | `#if` −14；旧 12ch 与新版逐通道一致；`_pkg` |

**明确不做**：记录模式（写 RAM 再回传）、多帧缓冲、主机 GUI——不排期、不开 S4。

### 每步固定动作
1. `-dM`/size 对比；2. 0E/0W；3. map 检查段尺寸；4. `_pkg`；5. 失败单包回退。

## 8 风险与对策

| 风险 | 对策 |
|---|---|
| `.obs_tab` 被链接器 GC | `used` + scatter `--keep=*(.obs_tab)` + map 核对 |
| scatter 与 `ER_IROM1` 重叠 | 插入后同步缩小 `ER_IROM1`，编译报 overlap 即回退 |
| 绝对地址失效 | 确认 `Ropi/Rwpi=0`；换工程时检查 |
| 登记局部变量 → 悬空 | 宏只允许 static/全局；`_Static_assert` 检查 size≤4 |
| ISR 预算恶化 | 先 8 通道，DWT 测 p50/p99；超预算降 decim |
| 多字段半套更新 | 单写者纪律 + 关键组（id/iq）写序；必要时 seq 校验 |
| VOFA 解析错位 | 帧长固定 `4+4n+4`；不加非 4B 头 |
| 控制口干扰遥测 | 独立 USART1；命令解析在任务，ISR 不碰 |

## 10 本轮范围修订（2026-10-31）：只做示波器，不做 CLI

用户确认：**最终**要让遥测与 CLI 复用在同一条链路、把示波器做成 CLI 的一个功能组；但**本轮只做示波器，CLI 暂不实现**。

因此本轮：

- **不新增控制口、不动串口引脚、不写命令解析器**；
- 会话切换先由两个“非 CLI”入口驱动：
  1. **NVM 预设**：开机 `preset_id → 名字列表 → obs_session_set()`；
  2. **exp 段表**：新增 `EXP_ACT_SET_OBS`（p0=preset_id），在段边界切会话——与现有实验框架一致，可复现、可回放；
- `obs_session_set(names[], n, decim)` 是**唯一入口**；将来 CLI 只是它的文本包装（`OBS SET/LIST/RATE`），与遥测复用同一条串口；
- §6 的两端口/单口复用方案**保留为未来 CLI 的设计**，落地 CLI 时再定 A/B。

**本轮 S2 验收改为**：用 exp 段表在一次运行中切换一次会话（例如 12ch@5k → 8ch@10k），VOFA 曲线通道随之变化，**不需要主机发命令**。
