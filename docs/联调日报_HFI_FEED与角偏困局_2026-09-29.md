另：曾试 ω\* 指令前馈 → 静差/空转，**已关**（C4u，仅留 W_MAX=1100）。

### 3.2 探查路径（重要纠偏）

1. **冻角枪（41/0014）**：RUN 内钉死 θ̂ → `x` 塌 → AUTH 清 FEED → **「动不了」是自扰**，不是 0.8 A 带不动。  
2. **纯观察（42/0022）**：控制≡C4x，只换 VOFA，**不冻角** → FEED≈97%，能转，角偏可量化。

### 3.3 0022（GATE42）核心数（认识以本表为准）

| 窗 | Iq | rpm | θ_err | eps | y |
|----|-----|-----|-------|-----|---|
| LOG（Iq≈0） | 0 | ~0 | **~−13°** | ~0 | **~0** |
| FEED 后段稳态 | 0.79 | ~330 | **~−22°** | **~+3.6°** | **~+0.019** |
| FEED 刚起（低速） | 0.79 | &lt;50 | ~−38° | ~+6.5° | ~+0.029 |

要点：

- **大头偏置在 Iq=0 时已存在**（~−13°）；FEED 只再挪约 **9°** → **不能**据此断言「电流是主因」。  
- 解调 eps 仅数度、真偏 −22° → 至少说明 **PLL 已把解调误差收小**，不是还欠 20° 没追完。  
- 转速↑，|θ_err| 从加速段 ~−40° **收到** ~−22° 地板 → **不能**说「越快越歪」；也不能说「速度是因」（时间与转速相关，未做同速对照）。  
- cos20°≈0.94 → 解释「偏着也能转」，不解释偏置来源。

## 4. 困局与假说（按证据强度）

### 4.1 已站得住的否定（高置信）

| 否定项 | 依据 |
|--------|------|
| **不是「PLL 动态太差 / 跟速滞后」为主因** | 稳态 eps≪\|θ_err\|；ω̂ 可贴 enc；更快时角偏反而收到地板（与带宽滞后叙事相反） |
| **不是冻角/AUTH 导致「电机坏了」** | 0014 掐 FEED；0022 同控制不冻则正常转 |
| **不是必须先 \|θ_err\|&lt;12° 才能转** | 2141/0022 偏置下空载 FEED 仍转 |
| **「高速 HFI 变差才切 SMO」不套本台 FEED 现象** | 本台 FEED 下更快略准；切 SMO 另有理由 |

### 4.2 站得住脚的假说（有数据、未证实）

**H1 — 静差为主，负载/转速为次（目前最贴数据）**  
- 主张：偏置地板 ≈ **固定（或缓变）分量 ~10°+**，叠加 FEED/加速时的较小增量与瞬态。  
- 支持：LOG −13° vs FEED 稳态 −22°；加速段 −38° 后回收。  
- 未证：固定分量来自 enc 零点、凸极相对磁钢、还是解调链路相位。  
- 若成立：下一步应专攻 **Iq=0 长泡偏置**，而不是加电流扫。

**H2 — 锁的是解调零点，不是「真 d 跟踪误差」（中高置信）**  
- 主张：闭环大致满足 `y≈0` / eps 小；θ_err 大 ⇒ **零点定义相对 enc 有偏**（凸极轴≠enc 电角度轴，和/或解调相位把「零」标歪了）。  
- 支持：0022 中 eps~+3.6° 对 −22°；LOG 时 y≈0 仍有 −13°。  
- 未证：偏在电机物理（凸极 vs 磁钢）还是实现（符号/半周对齐/滤波群时延）。  
- 若成立：改 PLL 增益无效；要动 **轴系/解调定义** 或接受与 enc 的固定差。

**H3 — 加速段另有瞬态误差（中置信）**  
- 主张：刚 FEED、低速时 −35°～−40° 主要是 **阶跃出力 + PLL/解调过渡**，不是稳态规律。  
- 支持：同靴后段收到 −22°；与「全程随转速线性恶化」不符。  
- 未证：瞬态时长、是否与 AUTH/斜坡有关。  
- 若成立：验收看 **FEED 后半窗**，勿用起步 1 s 判死。

**H4 — 电流/电枢反应只解释「增量」而非地板（低～中置信，弱）**  
- 主张：Iq 最多解释 LOG→FEED 那约 **~9°**，解释不了 −13° 地板。  
- 支持：带载不带载差不多；历史「Iq 线性」曾被高估。  
- **反对强结论**：未做同转速「有 Iq / 无 Iq（滑行）」严格对照；1.8 A 包也未证明增量按 Iq 比例涨。  
- 故：**不作为主假说**；仅保留为「可能的边角」。

**H5 — 速度本身不是主因（与 H1/H3 一致）**  
- 主张：未见「ω↑ → \|θ_err\|↑」；所见「ω↑ 略收」更像过瞬态。  
- 支持：rpm 分箱与时间相关；静置已有大偏置。  
- 未证：同 Iq、不同恒速平台的纯速度扫描。

### 4.3 明确证据不足、今日不采信为主因的说法

- 「带流凸极漂移 ≈ 全部 −20°」——**过度归因**，与 Iq=0 已有 −13° 冲突。  
- 「改观测方程就能消偏」——根因未拆开前属赌博。  
- 「标定 f(Iq) 即根因修复」——地板可能与 Iq 无关时，表会拟合噪声。

### 4.4 工程困局（与根因无关、仍成立）

- P1 开环 FEED：**功能可签（能转）**；角偏 **不作 &lt;12° 门禁**。  
- P3 HFI 速度环：2110 已挂；风险是 **闭环放大 ω̂/Iq**，不依赖「已证实是负载角」。  
- 交接 SMO：本机 @1000 均值 ~+0.6°、p95~15°（既有签收）；作为中高速出路仍合理。

### 4.5 本阶段明确不做

- 用 `|θ_err|<12°` 卡 FEED/起转  
- 冻角 + AUTH 同开  
- 恢复 ω\* 指令前馈  
- 未做 Iq=0 静差专项前：大改观测方程 / Iq 补偿表当主路径  
- 直接重开 P3 复刻 2110
